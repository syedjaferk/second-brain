<p class="wp-block-paragraph">Load balancing distributes client requests across multiple servers to ensure high availability and reliability. One of the simplest load balancing algorithms is <strong>Random Load Balancing</strong>, which selects a backend server randomly for each client request.</p><p class="wp-block-paragraph">Although this approach does not consider server load or other metrics, it can be effective for less critical applications or when the goal is to achieve simplicity.</p><h3 class="wp-block-heading">What is Random Load Balancing?</h3><p class="wp-block-paragraph"><strong>Random Load Balancing</strong> assigns incoming requests to a randomly chosen server from the available pool of servers. This method is straightforward and ensures that requests are distributed in a non-deterministic manner, which may work well for environments with equally capable servers and minimal concerns about server load or state.</p><figure class="wp-block-image size-large"><img alt="" class="wp-image-1466" data-recalc-dims="1" decoding="async" height="840" loading="lazy" src="https://i0.wp.com/parottasalna.com/wp-content/uploads/2024/09/load-balancing-algorithms2.png?resize=1600%2C840&amp;ssl=1" width="1600"/></figure><h3 class="wp-block-heading">Step-by-Step Implementation with Docker</h3><h4 class="wp-block-heading">Step 1: Create Dockerfiles for Each Flask Application</h4><p class="wp-block-paragraph">We’ll use the same three Flask applications (<code>app1.py</code>, <code>app2.py</code>, and <code>app3.py</code>) as in previous examples.</p><p class="wp-block-paragraph"><strong>Flask App 1 –</strong> (app.py)</p><pre class="wp-block-syntaxhighlighter-code">from flask import Flaskapp = Flask(__name__)@app.route("/")def home():    return "Hello from Flask App 1!"@app.route("/data")def data():    return "Data from Flask App 1!"if __name__ == "__main__":    app.run(host="0.0.0.0", port=5001)</pre><p class="wp-block-paragraph"><strong>Flask App 2 – </strong>(app.py)</p><pre class="wp-block-syntaxhighlighter-code">from flask import Flaskapp = Flask(__name__)@app.route("/")def home():    return "Hello from Flask App 2!"@app.route("/data")def data():    return "Data from Flask App 2!"if __name__ == "__main__":    app.run(host="0.0.0.0", port=5002)</pre><p class="wp-block-paragraph"><strong>Flask App 3 – </strong>(app.py)</p><pre class="wp-block-syntaxhighlighter-code">from flask import Flaskapp = Flask(__name__)@app.route("/")def home():    return "Hello from Flask App 3!"@app.route("/data")def data():    return "Data from Flask App 3!"if __name__ == "__main__":    app.run(host="0.0.0.0", port=5003)</pre><h4 class="wp-block-heading">Step 2: Create Dockerfiles for Each Flask Application</h4><p class="wp-block-paragraph">Create Dockerfiles for each of the Flask applications:</p><ul class="wp-block-list"><li><strong>Dockerfile for Flask App 1 (<code>Dockerfile.app1</code>)</strong>:</li></ul><pre class="wp-block-syntaxhighlighter-code"># Use the official Python image from Docker HubFROM python:3.9-slim# Set the working directory inside the containerWORKDIR /app# Copy the application file into the containerCOPY app1.py .# Install Flask inside the containerRUN pip install Flask# Expose the port the app runs onEXPOSE 5001# Run the applicationCMD ["python", "app1.py"]</pre><ul class="wp-block-list"><li><strong>Dockerfile for Flask App 2 (<code>Dockerfile.app2</code>)</strong>:</li></ul><pre class="wp-block-syntaxhighlighter-code">FROM python:3.9-slimWORKDIR /appCOPY app2.py .RUN pip install FlaskEXPOSE 5002CMD ["python", "app2.py"]</pre><ul class="wp-block-list"><li><strong>Dockerfile for Flask App 3 (<code>Dockerfile.app3</code>)</strong>:</li></ul><pre class="wp-block-syntaxhighlighter-code">FROM python:3.9-slimWORKDIR /appCOPY app3.py .RUN pip install FlaskEXPOSE 5003CMD ["python", "app3.py"]</pre><h4 class="wp-block-heading">Step 3: Create a Dockerfile for HAProxy</h4><p class="wp-block-paragraph">HAProxy Configuration file, </p><pre class="wp-block-syntaxhighlighter-code">global    log stdout format raw local0    daemondefaults    log     global    mode    http    option  httplog    option  dontlognull    timeout connect 5000ms    timeout client  50000ms    timeout server  50000msfrontend http_front    bind *:80    default_backend serversbackend servers    balance random    random draw 2    server server1 app1:5001 check    server server2 app2:5002 check    server server3 app3:5003 check</pre><p class="wp-block-paragraph"><strong>Explanation:</strong></p><ul class="wp-block-list"><li>The <code>balance random</code> directive tells HAProxy to use the Random load balancing algorithm.</li><li>The <code>random draw 2</code> setting makes HAProxy select 2 servers randomly and choose the one with the least number of connections. This adds a bit of load awareness to the random choice.</li><li>The <code>server</code> directives define the backend servers and their ports.</li></ul><p class="wp-block-paragraph"></p><h4 class="wp-block-heading">Step 4: Create a Dockerfile for HAProxy</h4><p class="wp-block-paragraph">Create a Dockerfile for HAProxy (<code>Dockerfile.haproxy</code>):</p><pre class="wp-block-syntaxhighlighter-code"># Use the official HAProxy image from Docker HubFROM haproxy:latest# Copy the custom HAProxy configuration file into the containerCOPY haproxy.cfg /usr/local/etc/haproxy/haproxy.cfg# Expose the port for HAProxyEXPOSE 80</pre><h4 class="wp-block-heading">Step 5: Create a <code>docker-compose.yml</code> File</h4><p class="wp-block-paragraph">To manage all the containers together, create a <code>docker-compose.yml</code> file:</p><pre class="wp-block-syntaxhighlighter-code">version: '3'services:  app1:    build:      context: .      dockerfile: Dockerfile.app1    container_name: flask_app1    ports:      - "5001:5001"  app2:    build:      context: .      dockerfile: Dockerfile.app2    container_name: flask_app2    ports:      - "5002:5002"  app3:    build:      context: .      dockerfile: Dockerfile.app3    container_name: flask_app3    ports:      - "5003:5003"  haproxy:    build:      context: .      dockerfile: Dockerfile.haproxy    container_name: haproxy    ports:      - "80:80"    depends_on:      - app1      - app2      - app3</pre><p class="wp-block-paragraph"><strong>Explanation:</strong></p><ul class="wp-block-list"><li>The <code>docker-compose.yml</code> file defines the services (<code>app1</code>, <code>app2</code>, <code>app3</code>, and <code>haproxy</code>) and their respective configurations.</li><li>HAProxy depends on the three Flask applications to be up and running before it starts.</li></ul><h4 class="wp-block-heading">Step 6: Build and Run the Docker Containers</h4><p class="wp-block-paragraph">Run the following command to build and start all the containers:</p><pre class="wp-block-syntaxhighlighter-code">docker-compose up --build</pre><p class="wp-block-paragraph">This command builds Docker images for all three Flask apps and HAProxy, then starts them.</p><h4 class="wp-block-heading">Step 7: Test the Load Balancer</h4><p class="wp-block-paragraph">Open your browser or use <code>curl</code> to make requests to the HAProxy server:</p><pre class="wp-block-syntaxhighlighter-code">curl http://localhost/curl http://localhost/data</pre><p class="wp-block-paragraph"><strong>Observation:</strong></p><ul class="wp-block-list"><li>With Random Load Balancing, each request should randomly hit one of the three backend servers.</li><li>Since the selection is random, you may not see a predictable pattern; however, the requests should be evenly distributed across the servers over a large number of requests.</li></ul><h4 class="wp-block-heading">Conclusion</h4><p class="wp-block-paragraph">By implementing Random Load Balancing with HAProxy, we’ve demonstrated a simple way to distribute traffic across multiple servers without relying on complex metrics or state information. While this approach may not be ideal for all use cases, it can be useful in scenarios where simplicity is more valuable than fine-tuned load distribution.</p>
