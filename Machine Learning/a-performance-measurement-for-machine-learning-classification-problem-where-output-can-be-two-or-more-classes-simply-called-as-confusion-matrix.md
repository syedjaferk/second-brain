<p class="wp-block-paragraph"></p><p class="wp-block-paragraph">In Machine Learning, the problem of classification involves predicting the categorical class label to which the query data point belongs. And the confusion matrix is a tabular representation of the classification model’s performance.</p><p class="wp-block-paragraph"></p><figure class="wp-block-image size-large"><img alt="" class="wp-image-4629" data-recalc-dims="1" decoding="async" height="340" loading="lazy" src="https://i0.wp.com/parottasalna.com/wp-content/uploads/2025/11/image-3.png?resize=462%2C340&amp;ssl=1" width="462"/></figure><p class="wp-block-paragraph"></p><p class="wp-block-paragraph">This tutorial will help you understand the confusion matrix and the various metrics that you can calculate from the confusion matrix.</p><p class="wp-block-paragraph">We’ll start by explaining what classification is, the types of classification problems, and how to interpret the confusion matrix for a <strong>binary classification</strong> problem.</p><p class="wp-block-paragraph"></p><h3 class="wp-block-heading" id="heading-what-is-classification"><a href="https://syedjaferk.hashnode.dev/confusion-matrix-in-machine-learning-everything-you-need-to-know#heading-what-is-classification"></a></h3><h2 class="wp-block-heading" id="heading-what-is-classification">What is Classification ?</h2><figure class="wp-block-image size-large"><img alt="" class="wp-image-4630" data-recalc-dims="1" decoding="async" height="400" loading="lazy" src="https://i0.wp.com/parottasalna.com/wp-content/uploads/2025/11/image-4.png?resize=447%2C400&amp;ssl=1" width="447"/></figure><p class="wp-block-paragraph"></p><p class="wp-block-paragraph">It is a Supervised Learning task where output is having defined labels(discrete value). For example in above figure, Output – Purchased has defined labels i.e. 0 or 1; 1 means the customer will purchase and 0 means that customer won’t purchase.</p><p class="wp-block-paragraph">The goal here is to predict discrete values belonging to a particular class and evaluate them on the basis of accuracy. It can be either binary or multi-class classification. In binary classification, the model predicts either 0 or 1; yes or no but in the case of multi-class classification, the model predicts more than one class.</p><p class="wp-block-paragraph">Example: Classifying groceries and vegetables bought from the market in to two classes.</p><p class="wp-block-paragraph"></p><figure class="wp-block-image size-large"><img alt="" class="wp-image-4631" data-recalc-dims="1" decoding="async" height="227" loading="lazy" src="https://i0.wp.com/parottasalna.com/wp-content/uploads/2025/11/image-5.png?resize=593%2C227&amp;ssl=1" width="593"/></figure><p class="wp-block-paragraph"></p><p class="wp-block-paragraph">Below is a Naive Bayes Classifier algorithms working. (At this point, dont think about the circles, just see how its been classifying. )</p><p class="wp-block-paragraph"></p><figure class="wp-block-image size-large"><img alt="" class="wp-image-4632" data-recalc-dims="1" decoding="async" height="359" loading="lazy" src="https://i0.wp.com/parottasalna.com/wp-content/uploads/2025/11/image-6.png?resize=451%2C359&amp;ssl=1" width="451"/></figure><p class="wp-block-paragraph">In essence, classification algorithms aim at answering the question,</p><blockquote class="wp-block-quote is-layout-flow wp-block-quote-is-layout-flow"><p class="wp-block-paragraph">“Given labeled training data points, what’s the class label of a previously unseen test, or query data point?”</p></blockquote><p class="wp-block-paragraph"></p><p class="wp-block-paragraph">A classification problem could be as simple as classifying a given image as that of a cat or a dog.</p><p class="wp-block-paragraph">Or it could be as complex as examining brain scans to detect the presence or absence of tumors.</p><p class="wp-block-paragraph"></p><p class="wp-block-paragraph">In binary classification, the class labels 1 and 0 are used.</p><p class="wp-block-paragraph">Suppose you’re given a large dataset of student loans containing features such as the name of the university, tuition and employment details.</p><p class="wp-block-paragraph">You’d like to predict whether or not a new student with a specific tuition fee and employment status will default on the student loan. Notice how you’re trying to answer the question “Will the student default on the loan?”—and the answer is either a ‘Yes’ or a ‘No’.</p><p class="wp-block-paragraph">You might as well think of other examples, say, identifying spam emails – the answers in this case are ‘Spam’ or ‘Not Spam’.</p><p class="wp-block-paragraph">In these examples,</p><ul class="wp-block-list"><li>the answers ‘Yes’, ‘Spam’ indicate relevant classes, and in practice are encoded as class 1, and</li><li>the answers ‘No’ and ‘Not Spam’ are encoded as class 0.</li></ul><p class="wp-block-paragraph">Using disease diagnosis as another example, if the problem is to detect the presence of a disease: label 1 indicates that the patient has the disease; and label 0 indicates the absence of the disease.</p><p class="wp-block-paragraph">This classification problem where the data points belong to one of the two classes is called binary classification. And we’ll build on binary classification in this tutorial.</p><p class="wp-block-paragraph"></p><p class="wp-block-paragraph"></p><p class="wp-block-paragraph">You can also have classification problems where you have more than two classes, called multiclass classification.</p><p class="wp-block-paragraph">For instance, classifying an email as ‘Spam’ or ‘Not Spam’ is a binary classification problem, whereas, categorizing emails as ‘School’, ‘Work’ or ‘Personal’ is a multiclass classification problem.</p><p class="wp-block-paragraph">Now that you’ve gained an understanding of the types of classification, let’s proceed to understand the confusion matrix.</p><p class="wp-block-paragraph">We will see the explanation of multiclass confusion matrix towards the end. First we see the working of binary class confusion matrix .</p><p class="wp-block-paragraph"></p><p class="wp-block-paragraph"></p><h2 class="wp-block-heading" id="heading-general-structure-of-the-confusion-matrix">General Structure of the Confusion Matrix</h2><p class="wp-block-paragraph">The general structure of the confusion matrix for binary classification is shown below</p><figure class="wp-block-image size-large"><img alt="" class="wp-image-4635" data-recalc-dims="1" decoding="async" height="987" loading="lazy" src="https://i0.wp.com/parottasalna.com/wp-content/uploads/2025/11/image-7.png?resize=1393%2C987&amp;ssl=1" width="1393"/></figure><p class="wp-block-paragraph"></p><figure class="wp-block-image size-large"><img alt="" class="wp-image-4637" data-recalc-dims="1" decoding="async" height="227" loading="lazy" src="https://i0.wp.com/parottasalna.com/wp-content/uploads/2025/11/image-8.png?resize=850%2C227&amp;ssl=1" width="850"/></figure><h4 class="wp-block-heading" id="heading-1-true-positive-tp"><a href="https://syedjaferk.hashnode.dev/confusion-matrix-in-machine-learning-everything-you-need-to-know#heading-1-true-positive-tp"></a></h4><p class="wp-block-paragraph"></p><h2 class="wp-block-heading"><a href="https://syedjaferk.hashnode.dev/confusion-matrix-in-machine-learning-everything-you-need-to-know#heading-how-to-calculate-evaluation-metrics-from-confusion-matrix"></a></h2><p class="wp-block-paragraph">It provides accurate insight into how correctly the model has classified the classes depending upon the data fed or how the classes are misclassified.</p><p class="wp-block-paragraph"></p>
