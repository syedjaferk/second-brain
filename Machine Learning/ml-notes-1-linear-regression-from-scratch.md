One is predictor or independent variable and other is response or dependent variable. It looks for statistical relationship but not deterministic relationship. </p><p class="wp-block-paragraph">Relationship between two variables is said to be deterministic if one variable can be accurately expressed by the other.</p><p class="wp-block-paragraph"><strong>For example</strong>, </p><p class="wp-block-paragraph">Using temperature in degree Celsius it is possible to accurately predict Fahrenheit. Statistical relationship is not accurate in determining relationship between two variables. For example, relationship between height and weight.</p><figure class="wp-block-image size-large"><img alt="" class="wp-image-2866" data-recalc-dims="1" decoding="async" height="648" loading="lazy" src="https://i0.wp.com/parottasalna.com/wp-content/uploads/2025/01/0_qg8dixntabh7qrxq.gif?resize=864%2C648&amp;ssl=1" width="864"/></figure><p class="wp-block-paragraph">The core idea is to obtain a line that best fits the data. The best fit line is the one for which total prediction error (all data points) are as small as possible. Error is the distance between the point to the regression line.</p><p class="wp-block-paragraph"></p><p class="wp-block-paragraph"><strong>1. </strong>Consider the below dataset, </p><pre class="wp-block-syntaxhighlighter-code">height = [150, 160, 155, 173, 180, 169]weight = [48, 63, 60, 67, 72, 66]</pre><figure class="wp-block-image size-large"><img alt="" class="wp-image-2867" data-recalc-dims="1" decoding="async" height="525" loading="lazy" src="https://i0.wp.com/parottasalna.com/wp-content/uploads/2025/01/image-88.png?resize=1172%2C525&amp;ssl=1" width="1172"/></figure><p class="wp-block-paragraph"></p><p class="wp-block-paragraph"><strong>2. </strong>Now, the user is giving a new height – 165 of a person.
