<p class="wp-block-paragraph"></p><h2 class="wp-block-heading has-large-font-size">Introduction</h2><p class="wp-block-paragraph">Stress testing is a critical aspect of performance testing that evaluates how a system performs under extreme loads. Unlike load testing, which simulates expected user traffic, stress testing pushes a system beyond its limits to identify breaking points and measure recovery capabilities.</p><p class="wp-block-paragraph">In this blog, we will explore stress testing using <strong>K6</strong>, an open-source load testing tool, with <strong>detailed explanations and full examples</strong> to help you implement stress testing effectively.</p><p class="wp-block-paragraph"></p><h2 class="wp-block-heading has-large-font-size">Why Stress Testing?</h2><p class="wp-block-paragraph">Stress testing helps you</p><ul class="wp-block-list"><li>Identify the maximum capacity of your system.</li><li>Detect potential failures and bottlenecks.</li><li>Measure system stability and recovery under high loads.</li><li>Ensure infrastructure can handle unexpected spikes in traffic.</li></ul><p class="wp-block-paragraph"></p><h2 class="wp-block-heading has-large-font-size">Setting Up K6 for Stress Testing</h2><p class="wp-block-paragraph"></p><h3 class="wp-block-heading has-medium-font-size">Installing K6</h3><pre class="wp-block-syntaxhighlighter-code"># macOSbrew install k6  # Ubuntu/Debiansudo apt install k6  # Using Dockerdocker pull grafana/k6  </pre><p class="wp-block-paragraph"></p><h3 class="wp-block-heading has-medium-font-size">Understanding Stress Testing Scenarios</h3><p class="wp-block-paragraph">K6 provides various <strong>executors</strong> to simulate different traffic patterns. For stress testing, we mainly use</p><ol class="wp-block-list"><li><strong>ramping-vus</strong> – Gradually increases virtual users to a high level.</li><li><strong>constant-vus</strong> – Maintains a fixed high number of virtual users.</li><li><strong>spike</strong> – Simulates a sudden surge in traffic.</li></ol><p class="wp-block-paragraph"></p><h2 class="wp-block-heading has-large-font-size">Example 1: Basic Stress Test with Ramping VUs</h2><p class="wp-block-paragraph">This script gradually increases the number of virtual users, holds a peak load, and then reduces it.</p><p class="wp-block-paragraph"></p><pre class="wp-block-syntaxhighlighter-code">import http from 'k6/http';import { sleep } from 'k6';export let options = {  stages: [    { duration: '1m', target: 100 }, // Ramp up to 100 users in 1 min    { duration: '3m', target: 100 }, // Stay at 100 users for 3 min    { duration: '1m', target: 0 },   // Ramp down to 0 users  ],};export default function () {  let res = http.get('https://test-api.example.com');  sleep(1);}</pre><p class="wp-block-paragraph"></p><h3 class="wp-block-heading has-medium-font-size">Explanation</h3><ul class="wp-block-list"><li>The test starts with 0 users and ramps up to <strong>100 users</strong> in <strong>1 minute</strong>.</li><li>Holds <strong>100 users</strong> for <strong>3 minutes</strong>.</li><li>Gradually <strong>reduces load</strong> to <strong>0 users</strong>.</li><li>The <code>sleep(1)</code> function helps simulate real user behavior between requests.</li></ul><p class="wp-block-paragraph"></p><h2 class="wp-block-heading has-large-font-size">Example 2: Constant High Load Test</h2><p class="wp-block-paragraph">This test maintains a consistently high number of virtual users.</p><pre class="wp-block-syntaxhighlighter-code">import http from 'k6/http';import { sleep } from 'k6';export let options = {  vus: 200, // 200 virtual users  duration: '5m', // Run the test for 5 minutes};export default function () {  http.get('https://test-api.example.com');  sleep(1);}</pre><p class="wp-block-paragraph"></p><h3 class="wp-block-heading has-medium-font-size">Explanation</h3><ul class="wp-block-list"><li><strong>200 virtual users</strong> are constantly hitting the endpoint for <strong>5 minutes</strong>.</li><li>Helps evaluate system performance under <strong>sustained high traffic</strong>.</li></ul><p class="wp-block-paragraph"></p><h2 class="wp-block-heading has-large-font-size">Example 3: Spike Testing (Sudden Traffic Surge)</h2><p class="wp-block-paragraph">This test simulates a <strong>sudden spike</strong> in traffic, followed by a drop.</p><pre class="wp-block-syntaxhighlighter-code">import http from 'k6/http';import { sleep } from 'k6';export let options = {  stages: [    { duration: '10s', target: 10 },  // Start with 10 users    { duration: '10s', target: 500 }, // Spike to 500 users    { duration: '10s', target: 10 },  // Drop back to 10 users  ],};export default function () {  http.get('https://test-api.example.com');  sleep(1);}</pre><p class="wp-block-paragraph"></p><h3 class="wp-block-heading has-medium-font-size">Explanation</h3><ul class="wp-block-list"><li>Starts with <strong>10 users</strong>.</li><li>Spikes suddenly to <strong>500 users</strong> in <strong>10 seconds</strong>.</li><li>Drops back to <strong>10 users</strong>.</li><li>Helps determine how the system handles <strong>sudden surges in traffic</strong>.</li></ul><p class="wp-block-paragraph"></p><h2 class="wp-block-heading has-large-font-size">Analyzing Test Results</h2><p class="wp-block-paragraph">After running the tests, K6 provides detailed statistics</p><pre class="wp-block-syntaxhighlighter-code">checks..................: 100.00% ✓ 5000 ✗ 0http_req_duration......: avg=300ms min=200ms max=2000mshttp_reqs..............: 5000 requestsvus_max................: 500</pre><p class="wp-block-paragraph"></p><h3 class="wp-block-heading has-medium-font-size">Key Metrics to Analyze</h3><ul class="wp-block-list"><li><strong>http_req_duration</strong> → Measures response time.</li><li><strong>vus_max</strong> → Maximum concurrent virtual users.</li><li><strong>http_reqs</strong> → Total number of requests.</li><li><strong>errors</strong> → Number of failed requests.</li></ul><p class="wp-block-paragraph"></p><p class="wp-block-paragraph">Stress testing is vital to <strong>ensure application stability and scalability</strong>. Using K6, we can simulate different stress scenarios like <strong>ramping load, constant high load, and spikes</strong> to identify system weaknesses before they affect users.</p>
