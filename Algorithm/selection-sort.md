<p class="wp-block-paragraph">The selection sort algorithm sorts an array by iteratively finding the <strong>minimum</strong> (for ascending order) / <strong>maximum</strong> (for descending order) element from the unsorted part and putting it at the beginning of the array.</p><p class="wp-block-paragraph">The algorithm will be considering two subarrays in a given array.</p><ol class="wp-block-list"><li>The subarray which is already sorted.</li><li>Remaining subarray which is unsorted.</li></ol><p class="wp-block-paragraph">In every iteration of selection sort, the minimum element (considering ascending order)/ the maximum element (considering descending order) from the unsorted subarray is picked and moved to the sorted subarray. The movement is the process of swapping the minimum element with the current element.</p><h3 class="wp-block-heading" id="heading-how-selection-sort-works">How selection sort works ?</h3><p class="wp-block-paragraph">We will see the implementation of sorting in ascending order.</p><p class="wp-block-paragraph">Consider the array : 29,10,14,37,14</p><figure class="wp-block-image size-large"><img alt="" class="wp-image-1171" data-recalc-dims="1" decoding="async" height="42" loading="lazy" src="https://i0.wp.com/parottasalna.com/wp-content/uploads/2024/08/image-60.png?resize=551%2C42&amp;ssl=1" width="551"/></figure><h4 class="wp-block-heading" id="heading-first-iteration">First Iteration</h4><p class="wp-block-paragraph">Initially the val of <strong>min_index</strong> is 0. The element at the min_index is 29.</p><p class="wp-block-paragraph">Then we can iterate over the rest of the array to find if there are any element which are minimum than the element at min_index.</p><figure class="wp-block-image"><img alt="first pass - selection sort" class="wp-image-1177" data-recalc-dims="1" decoding="async" height="270" loading="lazy" src="https://i0.wp.com/parottasalna.com/wp-content/uploads/2024/08/image.jpeg?resize=564%2C270&amp;ssl=1" width="564"/></figure><p class="wp-block-paragraph">By iterating, we found 10 is the minimum element present in the array. Thus, replace 29 with 10. After one iteration 10, which happens to be the least value in the array, tends to appear in the first position of the sorted list.</p><figure class="wp-block-image"><img alt="after first pass - selection sort" class="wp-image-1182" data-recalc-dims="1" decoding="async" height="299" loading="lazy" src="https://i0.wp.com/parottasalna.com/wp-content/uploads/2024/08/image-1-3.jpeg?resize=556%2C299&amp;ssl=1" width="556"/></figure><h4 class="wp-block-heading" id="heading-second-iteration"><a href="https://syedjaferk.hashnode.dev/selection-sort-algorithm#heading-second-iteration"></a></h4><h4 class="wp-block-heading" id="heading-second-iteration">Second Iteration</h4><p class="wp-block-paragraph">Now the value of <strong>min_index</strong> will be incremented by 1. So now it will be <strong>min_index = 1</strong> . Then we can iterate over the rest of the array to find if the there are any element which are minimum than the element at min_index.</p><figure class="wp-block-image"><img alt="second pass" class="wp-image-1180" data-recalc-dims="1" decoding="async" height="283" loading="lazy" src="https://i0.wp.com/parottasalna.com/wp-content/uploads/2024/08/image-1-2.jpeg?resize=570%2C283&amp;ssl=1" width="570"/></figure><p class="wp-block-paragraph">By iterating, we found 14 is the minimum element present in the array. Thus, swap 29 with 14.</p><figure class="wp-block-image"><img alt="image.png" class="wp-image-1185" data-recalc-dims="1" decoding="async" height="297" loading="lazy" src="https://i0.wp.com/parottasalna.com/wp-content/uploads/2024/08/image-4.jpeg?resize=561%2C297&amp;ssl=1" width="561"/></figure><h4 class="wp-block-heading" id="heading-third-iteration"><a href="https://syedjaferk.hashnode.dev/selection-sort-algorithm#heading-third-iteration"></a></h4><h4 class="wp-block-heading" id="heading-third-iteration">Third Iteration</h4><p class="wp-block-paragraph">We can repeat the same process till the entire array is sorted.</p><p class="wp-block-paragraph">Now the value of <strong>min_index</strong> will be incremented by 1. So now it will be <strong>min_index = 2</strong> . Then we can iterate over the rest of the array to find if the there are any element which are minimum than the element at min_index.</p><figure class="wp-block-image"><img alt="third pass" class="wp-image-1178" data-recalc-dims="1" decoding="async" height="275" loading="lazy" src="https://i0.wp.com/parottasalna.com/wp-content/uploads/2024/08/image-1.jpeg?resize=553%2C275&amp;ssl=1" width="553"/></figure><p class="wp-block-paragraph">By iterating, we found 14 is the minimum element present in the array. Thus, swap 29 with 14.</p><figure class="wp-block-image"><img alt="after third pass" class="wp-image-1186" data-recalc-dims="1" decoding="async" height="291" loading="lazy" src="https://i0.wp.com/parottasalna.com/wp-content/uploads/2024/08/image-4-1.jpeg?resize=558%2C291&amp;ssl=1" width="558"/></figure><h4 class="wp-block-heading" id="heading-fourth-iteration"><a href="https://syedjaferk.hashnode.dev/selection-sort-algorithm#heading-fourth-iteration"></a></h4><h4 class="wp-block-heading" id="heading-fourth-iteration">Fourth Iteration</h4><p class="wp-block-paragraph">Now the value of <strong>min_index</strong> will be incremented by 3. So now it will be <strong>min_index = 3</strong> . Then we can iterate over the rest of the array to find if the there are any element which are minimum than the element at min_index.</p><figure class="wp-block-image"><img alt="fourth pass" class="wp-image-1181" data-recalc-dims="1" decoding="async" height="284" loading="lazy" src="https://i0.wp.com/parottasalna.com/wp-content/uploads/2024/08/image-2.jpeg?resize=571%2C284&amp;ssl=1" width="571"/></figure><p class="wp-block-paragraph">By iterating, we found 29 is the minimum element present in the array. Thus, swap 29 with 37.</p><figure class="wp-block-image"><img alt="after fourth pass" class="wp-image-1179" data-recalc-dims="1" decoding="async" height="283" loading="lazy" src="https://i0.wp.com/parottasalna.com/wp-content/uploads/2024/08/image-1-1.jpeg?resize=556%2C283&amp;ssl=1" width="556"/></figure><h4 class="wp-block-heading" id="heading-its-done"><a href="https://syedjaferk.hashnode.dev/selection-sort-algorithm#heading-its-done"></a></h4><h4 class="wp-block-heading" id="heading-its-done">Its Done.</h4><p class="wp-block-paragraph">After 4th iteration, the entire array is sorted.</p><figure class="wp-block-image"><img alt="selection sort completed" class="wp-image-1183" data-recalc-dims="1" decoding="async" height="133" loading="lazy" src="https://i0.wp.com/parottasalna.com/wp-content/uploads/2024/08/image-1-4.jpeg?resize=579%2C133&amp;ssl=1" width="579"/></figure><p class="wp-block-paragraph">So we can define the approach like,</p><ul class="wp-block-list"><li>Initialize minimum value(min_index) to location 0</li><li>Traverse the array to find the minimum element in the array</li><li>While traversing if any element smaller than min_index is found then swap both the values.</li><li>Then, increment min_index to point to next element</li><li>Repeat until array is sorted</li></ul><h3 class="wp-block-heading" id="heading-code"><a href="https://syedjaferk.hashnode.dev/selection-sort-algorithm#heading-code"></a></h3><h3 class="wp-block-heading" id="heading-code">Code</h3><pre class="wp-block-syntaxhighlighter-code">def selection_sort(array, size):        for itr in range(size):        min_index = itr        for ctr in range(itr + 1, size):            if array[ctr] &lt; array[min_index]:                min_index = ctr        array[itr], array[min_index] = array[min_index], array[itr] arr = [29,10,14,37,14]size = len(arr)selection_sort(arr, size)print(arr)</pre><h3 class="wp-block-heading" id="heading-complexity-analysis">Complexity analysis</h3><h4 class="wp-block-heading" id="heading-time-complexity">Time Complexity</h4><p class="wp-block-paragraph">The sort complexity is used to express the number of execution times it takes to sort the list. The implementation has two loops. The outer loop which picks the values one by one from the list is executed n times where n is the total number of values in the list. The inner loop, which compares the value from the outer loop with the rest of the values, is also executed n times where n is the total number of elements in the list.</p><p class="wp-block-paragraph">Therefore, the number of executions is (n * n), which can also be expressed as O(n2).</p><ol class="wp-block-list"><li><strong>Worst case</strong> – this is where the list provided is in descending order. The algorithm performs the maximum number of executions which is expressed as [Big-O] O(n2)</li><li><strong>Best case</strong> – this occurs when the provided list is already sorted. The algorithm performs the minimum number of executions which is expressed as [Big-Omega] Ω(n2)</li><li><strong>Average case</strong> – this occurs when the list is in random order. The average complexity is expressed as [Big-theta] Θ(n2)</li></ol><figure class="wp-block-image"><img alt="Time Complexity - selection sort" class="wp-image-1184" data-recalc-dims="1" decoding="async" height="98" loading="lazy" src="https://i0.wp.com/parottasalna.com/wp-content/uploads/2024/08/image-3.jpeg?resize=618%2C98&amp;ssl=1" width="618"/></figure><h4 class="wp-block-heading" id="heading-space-complexity"><a href="https://syedjaferk.hashnode.dev/selection-sort-algorithm#heading-space-complexity"></a></h4><h4 class="wp-block-heading" id="heading-space-complexity">Space Complexity</h4><p class="wp-block-paragraph">Since selection sort is an inplace sorting algorithm, it has a space complexity of O(1) as it requires one temporal variable used for swapping values.</p><h3 class="wp-block-heading" id="heading-is-selection-sort-algorithm-stable"><a href="https://syedjaferk.hashnode.dev/selection-sort-algorithm#heading-is-selection-sort-algorithm-stable"></a></h3><h3 class="wp-block-heading" id="heading-is-selection-sort-algorithm-stable">Is Selection sort algorithm stable ?</h3><p class="wp-block-paragraph">The default implementation is not stable. However it can be made stable. But it can be achived using stable selection sort.</p><h3 class="wp-block-heading" id="heading-is-selection-sort-algorithm-in-place">Is Selection Sort Algorithm in-place?</h3><p class="wp-block-paragraph">Yes, it does not require extra space.</p><h3 class="wp-block-heading" id="heading-when-to-use-selection-sort">When to use selection sort ?</h3><ol class="wp-block-list"><li>Selection sort can be good at checking if everything is already sorted 😂.</li><li>It is also good to use when <strong>memory space is limited</strong>. This is because unlike other sorting algorithms, selection sort doesn’t go around swapping things until the very end, resulting in <strong>less temporary storage space</strong> used.</li><li>When a simple sorting implementation is desired</li><li>When the array to be sorted is relatively small</li></ol><h3 class="wp-block-heading" id="heading-when-to-avoid-selection-sort">When to avoid selection sort ?</h3><ol class="wp-block-list"><li>The array to be sorted has a large number of elements</li><li>The array is nearly sorted</li><li>You want a faster run time and memory is not a concern.</li></ol><h3 class="wp-block-heading" id="heading-summary">Summary</h3><ol class="wp-block-list"><li>Selection sort is an in-place comparison algorithm that is used to sort a random list into an ordered list. It has a time complexity of O(n2)</li><li>The list is divided into two sections, sorted and unsorted. The minimum value is picked from the unsorted section and placed into the sorted section.</li><li>This thing is repeated until all items have been sorted.</li><li>The time complexity measures the number of steps required to sort the list.</li><li>The worst-case time complexity happens when the list is in descending order. It has a time complexity of [Big-O] O(n2)</li><li>The best-case time complexity happens when the list is already in ascending order. It has a time complexity of [Big-Omega] O(n2)</li><li>The average-case time complexity happens when the list is in random order. It has a time complexity of [Big-theta] O(n2)</li><li>The selection sort is best used when you have a small list of items to sort, the cost of swapping values does not matter, and checking of all the values is mandatory.</li><li>The selection sort does not perform well on huge lists</li></ol><h3 class="wp-block-heading" id="heading-bonus-section"><a href="https://syedjaferk.hashnode.dev/selection-sort-algorithm#heading-bonus-section"></a></h3><h3 class="wp-block-heading" id="heading-bonus-section">Bonus Section</h3><p class="wp-block-paragraph"><strong>For the bigger array, how selection sort will work with insertion sort ?</strong></p><p class="wp-block-paragraph">The size of the array involved is rarely of much consequence. The real question is the speed of comparison vs. copying. The time a selection sort will win is when a comparison is a lot faster than copying. Just for example, let’s assume two fields: a single int as a key, and another megabyte of data attached to it. In such a case, comparisons involve only that single int, so it’s really fast, but copying involves the entire megabyte, so it’s almost certainly quite a bit slower.</p><p class="wp-block-paragraph">Since the selection sort does a lot of comparisons, but relatively few copies, this sort of situation will favor it.</p><h3 class="wp-block-heading" id="heading-problems-to-try"></h3>
