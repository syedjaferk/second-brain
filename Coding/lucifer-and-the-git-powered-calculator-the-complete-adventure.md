<p class="wp-block-paragraph">In losangels , a young coder named <strong>Lucifer</strong> set out on a mission to build his very own calculator. Along the way, he learned how to use Git, a powerful tool that would help him track his progress and manage his code. Here’s the complete story of how Lucifer built his calculator, step by step, with the power of Git.</p><h4 class="wp-block-heading"><strong>Step 1: Setting Up the Project with <code>git init</code></strong></h4><p class="wp-block-paragraph">Lucifer started by creating a new directory for his project and initializing a Git repository. This was like setting up a magical vault to store all his coding adventures.</p><pre class="wp-block-syntaxhighlighter-code">mkdir MagicCalculatorcd MagicCalculatorgit init</pre><p class="wp-block-paragraph">This command created the <code>.git</code> directory inside the <code>MagicCalculator</code> folder, where Git would keep track of everything.</p><h4 class="wp-block-heading"><strong>Step 2: Configuring His Identity with <code>git config</code></strong></h4><p class="wp-block-paragraph">Before getting too far, Lucifer needed to make sure Git knew who he was. He configured his username and email address, so every change he made would be recorded in his name.</p><pre class="wp-block-syntaxhighlighter-code">git config --global user.name "Lucifer"git config --global user.email "lucifer@codeville.com"</pre><h4 class="wp-block-heading"><strong>Step 3: Writing the Addition Function and Staging It with <code>git add</code></strong></h4><p class="wp-block-paragraph">Lucifer began his calculator project by writing a simple function to add two numbers. He created a new Python file named <code>main.py</code> and added the following code,</p><pre class="wp-block-syntaxhighlighter-code"># main.pydef add(x, y):    return x + y# Simple test to ensure it's workingprint(add(5, 3))  # Output should be 8</pre><p class="wp-block-paragraph">Happy with his progress, Lucifer used the <code>git add</code> command to stage his changes. This was like preparing the code to be saved in Git’s memory.</p><pre class="wp-block-syntaxhighlighter-code">git add main.py</pre><h4 class="wp-block-heading"><strong>Step 4: Committing the First Version with <code>git commit</code></strong></h4><p class="wp-block-paragraph">Next, Lucifer made his first commit. This saved the current state of his project, along with a message describing what he had done.</p><pre class="wp-block-syntaxhighlighter-code">git commit -m "Added addition function"</pre><p class="wp-block-paragraph">Now, Git had recorded the addition function as the first chapter in the history of Lucifer’s project.</p><h4 class="wp-block-heading"><strong>Step 5: Adding More Functions and Committing Them</strong></h4><p class="wp-block-paragraph">Lucifer continued to add more functions to his calculator. First, he added subtraction,</p><pre class="wp-block-syntaxhighlighter-code"># main.pydef add(x, y):    return x + ydef subtract(x, y):    return x - y# Simple testsprint(add(5, 3))       # Output: 8print(subtract(5, 3))  # Output: 2</pre><p class="wp-block-paragraph">He then staged and committed the subtraction function,</p><pre class="wp-block-syntaxhighlighter-code">git add main.pygit commit -m "Added subtraction function"</pre><p class="wp-block-paragraph">Lucifer added multiplication and division next,</p><pre class="wp-block-syntaxhighlighter-code"># main.pydef add(x, y):    return x + ydef subtract(x, y):    return x - ydef multiply(x, y):    return x * ydef divide(x, y):    if y != 0:        return x / y    else:        return "Cannot divide by zero!"# Simple testsprint(add(5, 3))       # Output: 8print(subtract(5, 3))  # Output: 2print(multiply(5, 3))  # Output: 15print(divide(5, 3))    # Output: 1.666...print(divide(5, 0))    # Output: Cannot divide by zero!</pre><p class="wp-block-paragraph">Again, he staged and committed these changes,</p><pre class="wp-block-syntaxhighlighter-code">git add main.pygit commit -m "Added multiplication and division functions"</pre><h4 class="wp-block-heading"><strong>Step 6: Branching Out with <code>git branch</code> and <code>git checkout</code></strong></h4><p class="wp-block-paragraph">Lucifer had an idea to add a feature that would let users choose which operation to perform. However, he didn’t want to risk breaking his existing code. So, he created a new branch to work on this feature.</p><pre class="wp-block-syntaxhighlighter-code">git branch operation-choicegit checkout operation-choice</pre><p class="wp-block-paragraph">Now on the <code>operation-choice</code> branch, Lucifer wrote the code to let users select an operation, </p><pre class="wp-block-syntaxhighlighter-code"># main.pydef add(x, y):    return x + ydef subtract(x, y):    return x - ydef multiply(x, y):    return x * ydef divide(x, y):    if y != 0:        return x / y    else:        return "Cannot divide by zero!"def calculator():    print("Select operation:")    print("1. Add")    print("2. Subtract")    print("3. Multiply")    print("4. Divide")    choice = input("Enter choice (1/2/3/4): ")    num1 = float(input("Enter first number: "))    num2 = float(input("Enter second number: "))    if choice == '1':        print(f"{num1} + {num2} = {add(num1, num2)}")    elif choice == '2':        print(f"{num1} - {num2} = {subtract(num1, num2)}")    elif choice == '3':        print(f"{num1} * {num2} = {multiply(num1, num2)}")    elif choice == '4':        print(f"{num1} / {num2} = {divide(num1, num2)}")    else:        print("Invalid input")# Run the calculatorcalculator()</pre><h4 class="wp-block-heading"><strong>Step 7: Merging the Feature into the Main Branch</strong></h4><p class="wp-block-paragraph">After testing his new feature and making sure it worked, Lucifer was ready to merge it back into the main branch. He switched back to the <code>main</code> branch and merged the changes</p><pre class="wp-block-syntaxhighlighter-code">git checkout maingit merge operation-choice</pre><p class="wp-block-paragraph">With this, the feature was successfully added to his calculator project.</p><h4 class="wp-block-heading"><strong>Conclusion: Lucifer’s Git-Powered Calculator</strong></h4><p class="wp-block-paragraph">By the end of his adventure, Lucifer had built a fully functional calculator and learned how to use Git to manage his code. His calculator could add, subtract, multiply, and divide, and even let users choose which operation to perform.</p><p class="wp-block-paragraph">Thanks to Git, Lucifer’s project was well-organized, and he had a complete history of all the changes he made. He knew that if he ever needed to revisit an old version or experiment with new features, Git would be there to help.</p><p class="wp-block-paragraph">Lucifer’s calculator project was a success, and with his newfound Git skills, he felt ready to take on even bigger challenges in the future.</p>
