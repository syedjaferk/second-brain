<h3 class="wp-block-heading" id="heading-introduction">Introduction</h3><p class="wp-block-paragraph">Have you ever thought of what is that ? when developers discuss like add a server; we need to scale up; we can scale down; implement a load balancer to equally share the request. In this blog post, we can go from basic methodologies in designing a solution where we equally distribute the request to the <strong>n servers</strong> in a distributed system.</p><h3 class="wp-block-heading" id="heading-what-is-hash-function">What is Hash Function ?</h3><p class="wp-block-paragraph">A hash function is a function that maps one piece of data typically describing some kind of object, often of arbitrary size to another piece of data, typically an integer, known as <strong>hash code</strong>, or simply <strong>hash</strong>.</p><p class="wp-block-paragraph">Lets create a simple hash function to take ip and give an integer back,</p><pre class="wp-block-syntaxhighlighter-code">def hash_the_value(value):    value = value.replace(".", "")    value = int(value)    return value % 12 # This can be any constant numbersample_ips = [    '192.168.0.18',    '192.168.0.19',    '192.168.3.38']for sample_ip in sample_ips:    hash_value = hash_the_value(sample_ip)    print(sample_ip, hash_value)</pre><figure class="wp-block-image size-large"><img alt="" class="wp-image-285" data-recalc-dims="1" decoding="async" height="353" loading="lazy" src="https://i0.wp.com/parottasalna.com/wp-content/uploads/2024/06/image-41.png?resize=1366%2C353&amp;ssl=1" width="1366"/></figure><p class="wp-block-paragraph">Till now, we have seen what is an hash function. Now let’s see the problem.</p><p class="wp-block-paragraph"></p><h3 class="wp-block-heading">Problem Description</h3><p class="wp-block-paragraph">Consider we are having our application installed in 4 servers. Now we want to split the requests between these 4 servers almost equally, so that every servers are equally loaded (more efficient).</p><figure class="wp-block-image size-large"><img alt="" class="wp-image-287" data-recalc-dims="1" decoding="async" height="492" loading="lazy" src="https://i0.wp.com/parottasalna.com/wp-content/uploads/2024/06/image-42.png?resize=919%2C492&amp;ssl=1" width="919"/></figure><h3 class="wp-block-heading" id="heading-naive-solution">Naive Solution</h3><p class="wp-block-paragraph">We need to split the request to different servers; so we need to have some distribution logic We can define the distribution logic (Load Balancer) like below,</p><p class="wp-block-paragraph">Logic:</p><blockquote class="wp-block-quote is-layout-flow wp-block-quote-is-layout-flow"><p class="wp-block-paragraph">hash_of_ip = hash_the_value(ip) # our python function at top<br/>total_server = 4<br/>server_no_to_hit = hash_of_ip % total_server</p></blockquote><p class="wp-block-paragraph">Now let’s see with a single request,</p><figure class="wp-block-image size-large"><img alt="" class="wp-image-288" data-recalc-dims="1" decoding="async" height="504" loading="lazy" src="https://i0.wp.com/parottasalna.com/wp-content/uploads/2024/06/image-43.png?resize=915%2C504&amp;ssl=1" width="915"/></figure><p class="wp-block-paragraph">Now lets see with multiple requests,</p><figure class="wp-block-image size-large"><img alt="" class="wp-image-289" data-recalc-dims="1" decoding="async" height="510" loading="lazy" src="https://i0.wp.com/parottasalna.com/wp-content/uploads/2024/06/image-44.png?resize=936%2C510&amp;ssl=1" width="936"/></figure><h3 class="wp-block-heading" id="heading-problems">Problems</h3><p class="wp-block-paragraph">This seems to be solve the problem right. Do you see any problem here ?</p><ul class="wp-block-list"><li>What will happen if i removed a server ?</li><li>What will happen if i added one server ?</li></ul><p class="wp-block-paragraph">At both of the scenarios, our hash value for a particular will be changing which may lead to hoping to another server. Let’s witness the change.</p><h3 class="wp-block-heading" id="heading-adding-a-new-server">Adding a new server</h3><p class="wp-block-paragraph">Initially we had 4 servers, now we add one more. So now totally we will have 5 servers.</p><figure class="wp-block-image size-large"><img alt="" class="wp-image-291" data-recalc-dims="1" decoding="async" height="521" loading="lazy" src="https://i0.wp.com/parottasalna.com/wp-content/uploads/2024/06/image-45.png?resize=949%2C521&amp;ssl=1" width="949"/></figure><h4 class="wp-block-heading" id="heading-ip-192168018">P: 192.168.0.18</h4><p class="wp-block-paragraph">Previous</p><p class="wp-block-paragraph">total_server = 4<br/>hash_of_ip = 6<br/>server_to_hit = hash_of_ip % total_server = 6 % 4 = 2</p><p class="wp-block-paragraph">After adding one server</p><p class="wp-block-paragraph">total_server = 5<br/>hash_of_ip = 6<br/>server_to_hit = hash_of_ip % total_server = 6 % 5 = 1</p><p class="wp-block-paragraph">It changed from <strong>server 2</strong> to <strong>server 1</strong>.</p><h4 class="wp-block-heading" id="heading-ip-192168019">IP: 192.168.0.19</h4><p class="wp-block-paragraph">Previous</p><p class="wp-block-paragraph">total_server = 4<br/>hash_of_ip = 7<br/>server_to_hit = hash_of_ip % total_server = 7 % 4 = 3</p><p class="wp-block-paragraph">After adding one server</p><p class="wp-block-paragraph">total_server = 5<br/>hash_of_ip = 7<br/>server_to_hit = hash_of_ip % total_server = 7 % 5 = 2</p><p class="wp-block-paragraph">It changed from <strong>server 3</strong> to <strong>server 1</strong>.</p><h4 class="wp-block-heading" id="heading-ip-192168338">IP: 192.168.3.38</h4><p class="wp-block-paragraph">Previous</p><p class="wp-block-paragraph">total_server = 4<br/>hash_of_ip = 2<br/>server_to_hit = hash_of_ip % total_server = 2 % 4 = 2</p><p class="wp-block-paragraph">After adding one server</p><p class="wp-block-paragraph">total_server = 5<br/>hash_of_ip = 2<br/>server_to_hit = hash_of_ip % total_server = 2 % 5 = 2</p><p class="wp-block-paragraph">It remains same.</p><h3 class="wp-block-heading" id="heading-when-simple-hashing-breaks">When simple hashing breaks</h3><ul class="wp-block-list"><li>When we add or removed a server we need to do a lot of shuffling and data transfers.</li><li>The cost of shuffling the data is huge and its not efficient with auto scaling.</li></ul><h3 class="wp-block-heading" id="heading-the-need-of-stable-solution"><a href="https://parottasalna.hashnode.dev/why-do-we-need-to-maintain-same-hash-in-load-balancer#heading-the-need-of-stable-solution"></a></h3><h3 class="wp-block-heading" id="heading-the-need-of-stable-solution">The Need of stable solution</h3><p class="wp-block-paragraph">Now we need to think about a hash algorithm which is consistent at almost all the time. So the birth of consistent hashing evolved. We will see more about consistent hashing in upcoming posts.</p><p class="wp-block-paragraph"></p>
