<p class="wp-block-paragraph"></p><p class="wp-block-paragraph">Yesterday, i came to know about SBOM, from my friend Prasanth Baskar. Let’s say you’re building a website. </p><p class="wp-block-paragraph">You decide to use a popular open-source tool to handle user logins. Here’s the catch, </p><ul class="wp-block-list"><li>That library uses another library to store data.</li></ul><ul class="wp-block-list"><li>That tool depends on another library to handle passwords.</li></ul><p class="wp-block-paragraph">Now, if one of those libraries has a bug or security issue, how do you even know it’s there? In this blog, i will jot down my understanding on SBOM with Trivy.</p><p class="wp-block-paragraph"></p><h2 class="wp-block-heading">What is SBOM ?</h2><p class="wp-block-paragraph">A <strong>Software Bill of Materials (SBOM)</strong> is a list of everything that makes up a piece of software.</p><p class="wp-block-paragraph">Think of it as, </p><ul class="wp-block-list"><li>A <strong>shopping list</strong> for all the tools, libraries, and pieces used to build the software.</li><li>A <strong>recipe card</strong> showing what’s inside and how it’s structured.<br/><br/></li></ul><p class="wp-block-paragraph">For software, this means, </p><ul class="wp-block-list"><li><strong>Components</strong>: These are the “ingredients,” such as open-source libraries, frameworks, and tools.</li><li><strong>Versions</strong>: Just like you might want to know if the cake uses almond flour or regular flour, knowing the version of a software component matters.</li><li><strong>Licenses</strong>: Did the baker follow the rules for the ingredients they used? Software components also come with licenses that dictate how they can be used.</li></ul><p class="wp-block-paragraph"></p><h2 class="wp-block-heading">So How come its Important ?</h2><p class="wp-block-paragraph">1. <strong>Understanding What You’re Using</strong></p><p class="wp-block-paragraph">When you download or use software, especially something complex, you often don’t know what’s inside. An SBOM helps you understand what components are being used are they secure? Are they trustworthy?<br/></p><p class="wp-block-paragraph">2. <strong>Finding Problems Faster</strong></p><p class="wp-block-paragraph">If someone discovers that a specific ingredient is bad—like flour with bacteria in it—you’d want to know if that’s in your cake. Similarly, if a software library has a security issue, an SBOM helps you figure out if your software is affected and needs fixing.</p><p class="wp-block-paragraph">For example, </p><p class="wp-block-paragraph">When the <strong><a href="https://www.appknox.com/blog/log4j-vulnerability-and-the-importance-of-sbom-in-software-supply-chain-security">Log4j vulnerability</a></strong> made headlines, companies that had SBOMs could quickly identify whether they used Log4j and take action.<br/></p><p class="wp-block-paragraph">3. <strong>Building Trust</strong></p><p class="wp-block-paragraph">Imagine buying food without a label or list of ingredients. </p><p class="wp-block-paragraph">You’d feel doubtful, right ? Similarly, an SBOM builds trust by showing users exactly what’s in the software they’re using.<br/></p><p class="wp-block-paragraph">4. <strong>Avoiding Legal Trouble</strong></p><p class="wp-block-paragraph">Some software components come with specific rules or licenses about how they can be used. An SBOM ensures these rules are followed, avoiding potential legal headaches.</p><p class="wp-block-paragraph"></p><h2 class="wp-block-heading">How to Create an SBOM?</h2><p class="wp-block-paragraph">For many developers, creating an SBOM manually would be impossible because modern software can have hundreds (or even thousands!) of components.</p><p class="wp-block-paragraph">Thankfully, there are <strong>tools</strong> that automatically create SBOMs. Examples include,</p><ul class="wp-block-list"><li><strong>Trivy</strong>: A lightweight tool to generate SBOMs and find vulnerabilities.</li><li><strong>CycloneDX</strong>: A popular SBOM format supported by many tools <a href="https://cyclonedx.org/">https://cyclonedx.org/</a></li><li><strong>SPDX</strong>: Another format designed to make sharing SBOMs easier <a href="https://spdx.dev/">https://spdx.dev/</a></li></ul><p class="wp-block-paragraph">These tools can scan your software and automatically list out every component, its version, and its dependencies.</p><p class="wp-block-paragraph">We will see example on generating a SBOM file for nginx using trivy.</p><p class="wp-block-paragraph"></p><h2 class="wp-block-heading">How Trivy Works ?</h2><figure class="wp-block-image size-large"><img alt="" class="wp-image-3045" data-recalc-dims="1" decoding="async" height="499" loading="lazy" src="https://i0.wp.com/parottasalna.com/wp-content/uploads/2025/01/image-103.png?resize=857%2C499&amp;ssl=1" width="857"/></figure><p class="wp-block-paragraph"></p><p class="wp-block-paragraph">On running trivy scan, </p><p class="wp-block-paragraph">1. It downloads Trivy DB including vulnerability information. </p><figure class="wp-block-image size-large"><img alt="" class="wp-image-3047" data-recalc-dims="1" decoding="async" height="255" loading="lazy" src="https://i0.wp.com/parottasalna.com/wp-content/uploads/2025/01/image-104.png?resize=1915%2C255&amp;ssl=1" width="1915"/></figure><ol class="wp-block-list"><li></li></ol><p class="wp-block-paragraph">2. Pull Missing layers in cache.</p><figure class="wp-block-image size-large"><img alt="" class="wp-image-3049" data-recalc-dims="1" decoding="async" height="120" loading="lazy" src="https://i0.wp.com/parottasalna.com/wp-content/uploads/2025/01/image-105.png?resize=1915%2C120&amp;ssl=1" width="1915"/></figure><p class="wp-block-paragraph">3. Analyze layers and stores information in cache. </p><p class="wp-block-paragraph">4. Detect security issues and write to SBOM file. </p><p class="wp-block-paragraph"></p><blockquote class="wp-block-quote is-layout-flow wp-block-quote-is-layout-flow"><p class="wp-block-paragraph">Note: a <strong>CVE</strong> refers to a <strong>Common Vulnerabilities and Exposures</strong> identifier. A CVE is a unique code used to catalog and track publicly known security vulnerabilities and exposures in software or systems.</p></blockquote><p class="wp-block-paragraph"></p><h2 class="wp-block-heading">How to Generate SBOMs with Trivy</h2><p class="wp-block-paragraph"></p><p class="wp-block-paragraph"><strong>Step 1: Install Trivy</strong> <strong>in Ubuntu</strong></p><pre class="wp-block-syntaxhighlighter-code">sudo apt-get install wget gnupgwget -qO - https://aquasecurity.github.io/trivy-repo/deb/public.key | gpg --dearmor | sudo tee /usr/share/keyrings/trivy.gpg &gt; /dev/nullecho "deb [signed-by=/usr/share/keyrings/trivy.gpg] https://aquasecurity.github.io/trivy-repo/deb generic main" | sudo tee -a /etc/apt/sources.list.d/trivy.listsudo apt-get updatesudo apt-get install trivy</pre><p class="wp-block-paragraph"></p><p class="wp-block-paragraph">More on Installation: <a href="https://github.com/aquasecurity/trivy/blob/main/docs/getting-started/installation.md">https://github.com/aquasecurity/trivy/blob/main/docs/getting-started/installation.md</a></p><p class="wp-block-paragraph"></p><p class="wp-block-paragraph"><strong>Step 2: Generate an SBOM</strong></p><p class="wp-block-paragraph">Trivy allows you to create SBOMs in formats like CycloneDX or SPDX.</p><pre class="wp-block-syntaxhighlighter-code">trivy image --format cyclonedx --output sbom.json nginx:latest</pre><p class="wp-block-paragraph"></p><p class="wp-block-paragraph">It generates the SBOM file. </p><figure class="wp-block-image size-large"><img alt="" class="wp-image-3052" data-recalc-dims="1" decoding="async" height="780" loading="lazy" src="https://i0.wp.com/parottasalna.com/wp-content/uploads/2025/01/image-106.png?resize=1915%2C780&amp;ssl=1" width="1915"/></figure><p class="wp-block-paragraph"></p><p class="wp-block-paragraph">It can be incorporated into Github CI/CD.</p>
