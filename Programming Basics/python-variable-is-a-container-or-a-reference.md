<p class="wp-block-paragraph">Unlike other programming languages, in Python, variable is not a container but just a reference or a name/label to the object.</p><blockquote class="wp-block-quote is-layout-flow wp-block-quote-is-layout-flow"><p class="wp-block-paragraph">Caution: This post deals with memory management, which might confuse you if you are a beginner. Read at your own risk.</p></blockquote><p class="wp-block-paragraph">Let’s dive deep into it, </p><p class="wp-block-paragraph">To understand how python handles variable storage and references involves several key concepts,</p><h3 class="wp-block-heading"><strong>Objects &amp; References:</strong> </h3><p class="wp-block-paragraph">In python, everything is an object and variables are references to these objects. To check if an item is an object, we can use the isinstance() function.</p><figure class="wp-block-image size-large"><img alt="" class="wp-image-563" data-recalc-dims="1" decoding="async" height="468" loading="lazy" src="https://i0.wp.com/parottasalna.com/wp-content/uploads/2024/07/image-40.png?resize=2720%2C468&amp;ssl=1" width="2720"/></figure><p class="wp-block-paragraph">This will give, </p><figure class="wp-block-image size-large"><img alt="" class="wp-image-565" data-recalc-dims="1" decoding="async" height="136" loading="lazy" src="https://i0.wp.com/parottasalna.com/wp-content/uploads/2024/07/image-41.png?resize=682%2C136&amp;ssl=1" width="682"/></figure><p class="wp-block-paragraph">Now we can see that everything in python is an object. </p><p class="wp-block-paragraph">Let’s try to prove, </p><p class="wp-block-paragraph"><em>When you create a variable (label), it holds a reference (a pointer) to the memory location where the actual object is stored.</em></p><p class="wp-block-paragraph">To validate this we need to check the size of the objects and the address of the objects. We can use </p><ul class="wp-block-list"><li>id() function to check the address of the object</li><li>getsizeof() method from sys module to find the size of the object. </li></ul><p class="wp-block-paragraph">Let us take an example, </p><pre class="wp-block-syntaxhighlighter-code">age = 26 </pre><p class="wp-block-paragraph">26 is the Numeric object which is stored in some memory address.</p><pre class="wp-block-syntaxhighlighter-code">import sysage = 26print("Address of 26 (Numeric Object)", id(26))print("Address of age", id(age))print("Size of reference:", sys.getsizeof(x))  # Size of the reference</pre><figure class="wp-block-image size-large"><img alt="" class="wp-image-568" data-recalc-dims="1" decoding="async" height="229" loading="lazy" src="https://i0.wp.com/parottasalna.com/wp-content/uploads/2024/07/image-42.png?resize=1203%2C229&amp;ssl=1" width="1203"/></figure><p class="wp-block-paragraph">Here we can see the address of both the age and 26 are same. Its because the numeric object 26 is stored in the memory address (140593168368656) and its been referenced to age. </p><p class="wp-block-paragraph">Okay, So where does the variable gets stored, </p><p class="wp-block-paragraph">Python maintains namespaces, which are dictionaries that map variable names to objects. The process of associating a variable name with an object is called binding. When you assign a value to a variable, you are binding the variable name to an object in the namespace.</p><p class="wp-block-paragraph">Variable names are stored in namespaces (which are dictionaries). </p><p class="wp-block-paragraph">For example, </p><ul class="wp-block-list"><li>local variables are stored in a dictionary specific to the function</li><li>global variables are stored in the module’s dictionary, and so on.</li></ul><pre class="wp-block-syntaxhighlighter-code">import sysx = 10print("Size of reference:", sys.getsizeof(x))  # Size of the referencelocal_namespace = locals()print("Namespace:", local_namespace)  # Shows the local namespacefor key, value in local_namespace.items():  print(key, value)</pre><figure class="wp-block-image size-large"><img alt="" class="wp-image-571" data-recalc-dims="1" decoding="async" height="644" loading="lazy" src="https://i0.wp.com/parottasalna.com/wp-content/uploads/2024/07/image-43.png?resize=1291%2C644&amp;ssl=1" width="1291"/></figure><p class="wp-block-paragraph">In the above code, we can see the variable x is stored in the namespace, which is a reference to the object 10. Both x and 10 will have the same address. </p><figure class="wp-block-image size-large"><img alt="" class="wp-image-573" data-recalc-dims="1" decoding="async" height="192" loading="lazy" src="https://i0.wp.com/parottasalna.com/wp-content/uploads/2024/07/image-44.png?resize=612%2C192&amp;ssl=1" width="612"/></figure><p class="wp-block-paragraph">So, now we can say that variables in python is not a container but a label to the object. </p><h3 class="wp-block-heading">So now what is the size of an variable ?</h3><p class="wp-block-paragraph">In Python, you can get the size of the reference (pointer) itself using the <code>sys.getsizeof()</code> function. However, <code>sys.getsizeof()</code> typically returns the size of the object that the reference points to, not the size of the reference itself.</p><p class="wp-block-paragraph">Python does not provide a direct way to get the size of just the reference (pointer). This is because Python abstracts away the details of memory management and does not expose low-level details like the size of pointers directly to the user. </p><p class="wp-block-paragraph">The size of a reference (pointer) is typically determined by the architecture of the system (e.g., 4 bytes on a 32-bit system, 8 bytes on a 64-bit system).</p><p class="wp-block-paragraph">But we can try to get a rough estimate of the size, </p><pre class="wp-block-syntaxhighlighter-code">import sysdef get_reference_size():    # Create an object and get its size    obj = 123        # Create a list to hold references to the object    reference_list = [obj] * 1000        # Get the size of the list with references    size_of_reference_list = sys.getsizeof(reference_list)    print("size_of_reference_list", size_of_reference_list)        # Calculate the size of one reference    size_of_empty_list = sys.getsizeof([])    size_of_one_reference = (size_of_reference_list - size_of_empty_list) / 1000        return size_of_one_referenceprint("Estimated size of one reference (pointer):", get_reference_size(), "bytes")</pre><figure class="wp-block-image size-large"><img alt="" class="wp-image-580" data-recalc-dims="1" decoding="async" height="68" loading="lazy" src="https://i0.wp.com/parottasalna.com/wp-content/uploads/2024/07/image-46.png?resize=877%2C68&amp;ssl=1" width="877"/></figure><p class="wp-block-paragraph">In the above code, we created a list of 1000 values (i.e 1000 times 123). </p><p class="wp-block-paragraph">As per documentation, </p><blockquote class="wp-block-quote is-layout-flow wp-block-quote-is-layout-flow"><p class="wp-block-paragraph">Some objects contain references to other objects; these are called <em>containers</em>. Examples of containers are tuples, lists and dictionaries. <a href="https://docs.python.org/3/reference/datamodel.html">https://docs.python.org/3/reference/datamodel.html</a></p></blockquote><p class="wp-block-paragraph">So the list object contains the reference to the other objects. So here it contains 1000 references to the value 123.</p><p class="wp-block-paragraph">And then we are trying to calculate the size of the list of references and then dividing by the total number to get the size of the singe reference (or pointer or label).</p><p class="wp-block-paragraph"> Now, the size of a single variable it 8 bytes (Note: It depends on the system architecture.)</p><h3 class="wp-block-heading">Inference:</h3><ul class="wp-block-list"><li>Variables are not the containers.</li><li>Variables are just the labels to the objects. Variables and the variable name are same.</li><li>There is no type for the variables. If we use type(variable) it gives the type of the object which it refers to. </li><li>Variables are stored in the namespace.</li><li>Variables are having the size which varies based on the architecture. It might be 4 bytes or 8 bytes. </li></ul><p class="wp-block-paragraph"></p>
