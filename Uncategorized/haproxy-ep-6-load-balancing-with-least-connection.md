<p class="wp-block-paragraph">Load balancing is crucial for distributing incoming network traffic across multiple servers, ensuring optimal resource utilization and improving application performance. One of the simplest and most popular load balancing algorithms is <strong>Round Robin</strong>. In this blog, we’ll explore how to implement Least Connection load balancing using Flask as our backend application and HAProxy as our load balancer.</p><h4 class="wp-block-heading">What is Least Connection Load Balancing?</h4><p class="wp-block-paragraph"><strong>Least Connection Load Balancing</strong> is a dynamic algorithm that distributes requests to the server with the fewest active connections at any given time. This method ensures that servers with lighter loads receive more requests, preventing any single server from becoming a bottleneck.</p><figure class="wp-block-image size-large"><img alt="" class="wp-image-1444" data-recalc-dims="1" decoding="async" height="840" loading="lazy" src="https://i0.wp.com/parottasalna.com/wp-content/uploads/2024/09/load-balancing-algorithms.png?resize=1600%2C840&amp;ssl=1" width="1600"/></figure><h3 class="wp-block-heading">Step-by-Step Implementation with Docker</h3><h4 class="wp-block-heading">Step 1: Create Dockerfiles for Each Flask Application</h4><p class="wp-block-paragraph">We’ll create three separate Dockerfiles, one for each Flask app.</p><p class="wp-block-paragraph"><strong>Flask App 1 (app1.py)</strong> – Introduced Slowness by adding sleep</p><pre class="wp-block-syntaxhighlighter-code">from flask import Flaskimport timeapp = Flask(__name__)@app.route("/")def hello():    time.sleep(5)    return "Hello from Flask App 1!"if __name__ == "__main__":    app.run(host="0.0.0.0", port=5001)</pre><p class="wp-block-paragraph"><strong>Flask App 2 (app2.py)</strong></p><pre class="wp-block-syntaxhighlighter-code">from flask import Flaskapp = Flask(__name__)@app.route("/")def hello():    return "Hello from Flask App 2!"if __name__ == "__main__":    app.run(host="0.0.0.0", port=5002)</pre><p class="wp-block-paragraph"><strong>Flask App 3 (app3.py)</strong> – Introduced Slowness by adding sleep. </p><pre class="wp-block-syntaxhighlighter-code">from flask import Flaskimport timeapp = Flask(__name__)@app.route("/")def hello():    time.sleep(5)    return "Hello from Flask App 3!"if __name__ == "__main__":    app.run(host="0.0.0.0", port=5003)</pre><p class="wp-block-paragraph">Each Flask app listens on a different port (5001, 5002, 5003).</p><h4 class="wp-block-heading">Step 2: Dockerfiles for each flask application</h4><p class="wp-block-paragraph"><strong>Dockerfile for Flask App 1 (Dockerfile.app1)</strong></p><pre class="wp-block-syntaxhighlighter-code"># Use the official Python image from the Docker HubFROM python:3.9-slim# Set the working directory inside the containerWORKDIR /app# Copy the current directory contents into the container at /appCOPY app1.py .# Install Flask inside the containerRUN pip install Flask# Expose the port the app runs onEXPOSE 5001# Run the applicationCMD ["python", "app1.py"]</pre><p class="wp-block-paragraph"><strong>Dockerfile for Flask App 2 (Dockerfile.app2)</strong></p><pre class="wp-block-syntaxhighlighter-code">FROM python:3.9-slimWORKDIR /appCOPY app2.py .RUN pip install FlaskEXPOSE 5002CMD ["python", "app2.py"]</pre><p class="wp-block-paragraph"><strong>Dockerfile for Flask App 3 (Dockerfile.app3)</strong></p><pre class="wp-block-syntaxhighlighter-code">FROM python:3.9-slimWORKDIR /appCOPY app3.py .RUN pip install FlaskEXPOSE 5003CMD ["python", "app3.py"]</pre><h4 class="wp-block-heading">Step 3: Create a configuration for HAProxy</h4><pre class="wp-block-syntaxhighlighter-code">global    log stdout format raw local0    daemondefaults    log     global    mode    http    option  httplog    option  dontlognull    timeout connect 5000ms    timeout client  50000ms    timeout server  50000msfrontend http_front    bind *:80    default_backend serversbackend servers    balance leastconn    server server1 app1:5001 check    server server2 app2:5002 check    server server3 app3:5003 check</pre><p class="wp-block-paragraph"><strong>Explanation:</strong></p><ul class="wp-block-list"><li><strong><code>frontend http_front</code></strong>: Defines the entry point for incoming traffic. It listens on port 80.</li><li><strong><code>backend servers</code></strong>: Specifies the servers HAProxy will distribute traffic evenly the three Flask apps (<code>app1</code>, <code>app2</code>, <code>app3</code>). The <code>balance leastconn</code> directive sets the Least Connection for load balancing.</li><li><strong><code>server</code> directives</strong>: Lists the backend servers with their IP addresses and ports. The <code>check</code> option allows HAProxy to monitor the health of each server.</li></ul><h4 class="wp-block-heading">Step 4: Create a Dockerfile for HAProxy</h4><p class="wp-block-paragraph">Create a Dockerfile for HAProxy (Dockerfile.haproxy)</p><pre class="wp-block-syntaxhighlighter-code"># Use the official HAProxy image from Docker HubFROM haproxy:latest# Copy the custom HAProxy configuration file into the containerCOPY haproxy.cfg /usr/local/etc/haproxy/haproxy.cfg# Expose the port for HAProxyEXPOSE 80</pre><h4 class="wp-block-heading">Step 5: Create a Dockercompose file</h4><p class="wp-block-paragraph">To manage all the containers together, create a <code>docker-compose.yml</code> file</p><pre class="wp-block-syntaxhighlighter-code">version: '3'services:  app1:    build:      context: .      dockerfile: Dockerfile.app1    container_name: flask_app1    ports:      - "5001:5001"  app2:    build:      context: .      dockerfile: Dockerfile.app2    container_name: flask_app2    ports:      - "5002:5002"  app3:    build:      context: .      dockerfile: Dockerfile.app3    container_name: flask_app3    ports:      - "5003:5003"  haproxy:    build:      context: .      dockerfile: Dockerfile.haproxy    container_name: haproxy    ports:      - "80:80"    depends_on:      - app1      - app2      - app3</pre><p class="wp-block-paragraph"><strong>Explanation:</strong></p><ul class="wp-block-list"><li>The <code>docker-compose.yml</code> file defines four services: <code>app1</code>, <code>app2</code>, <code>app3</code>, and <code>haproxy</code>.</li><li>Each Flask app is built from its respective Dockerfile and runs on its port.</li><li>HAProxy is configured to wait (<code>depends_on</code>) for all three Flask apps to be up and running.</li></ul><h4 class="wp-block-heading">Step 6: Build and Run the Docker Containers</h4><p class="wp-block-paragraph">Run the following commands to build and start all the containers:</p><pre class="wp-block-syntaxhighlighter-code"># Build and run the containersdocker-compose up --build</pre><p class="wp-block-paragraph">This command will build Docker images for all three Flask apps and HAProxy and start them up in the background.</p><p class="wp-block-paragraph">You should see the responses alternating between “Hello from Flask App 1!”, “Hello from Flask App 2!”, and “Hello from Flask App 3!” as HAProxy uses the Round Robin algorithm to distribute requests.</p><h4 class="wp-block-heading">Step 7: Test the Load Balancer</h4><p class="wp-block-paragraph">Open your browser or use a tool like <code>curl</code> to make requests to the HAProxy server:</p><pre class="wp-block-syntaxhighlighter-code">curl http://localhost</pre><p class="wp-block-paragraph">You should see responses cycling between “Hello from Flask App 1!”, “Hello from Flask App 2!”, and “Hello from Flask App 3!” according to the Least Connection strategy.</p>
