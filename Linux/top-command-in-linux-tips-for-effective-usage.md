<p class="wp-block-paragraph"></p><p class="wp-block-paragraph">The <code>top</code> command in Linux is a powerful utility that provides realtime information about system performance, including CPU usage, memory usage, running processes, and more. </p><p class="wp-block-paragraph">It is an essential tool for system administrators to monitor system health and manage resources effectively.</p><figure class="wp-block-image size-large"><img alt="" class="wp-image-3797" data-recalc-dims="1" decoding="async" height="1011" loading="lazy" src="https://i0.wp.com/parottasalna.com/wp-content/uploads/2025/02/image-38.png?resize=1864%2C1011&amp;ssl=1" width="1864"/></figure><h2 class="wp-block-heading has-large-font-size">1. Basic Usage</h2><p class="wp-block-paragraph">Simply running <code>top</code> without any arguments displays an interactive screen showing system statistics and a list of running processes:</p><pre class="wp-block-syntaxhighlighter-code">$ top</pre><p class="wp-block-paragraph"></p><h2 class="wp-block-heading has-large-font-size">2. Understanding the <code>top</code> Output</h2><p class="wp-block-paragraph">The <code>top</code> interface is divided into multiple sections</p><p class="wp-block-paragraph"></p><h3 class="wp-block-heading has-medium-font-size">Header Section</h3><p class="wp-block-paragraph">This section provides an overview of the system status, including uptime, load averages, and system resource usage.</p><ul class="wp-block-list"><li><strong>Uptime and Load Average</strong> – Displays how long the system has been running and the average system load over the last 1, 5, and 15 minutes.</li><li><strong>Task Summary</strong> – Shows the number of processes in various states:<ul class="wp-block-list"><li><strong>Running</strong> – Processes actively executing on the CPU.</li><li><strong>Sleeping</strong> – Processes waiting for an event or resource.</li><li><strong>Stopped</strong> – Processes that have been paused.</li><li><strong>Zombie</strong> – Processes that have completed execution but still have an entry in the process table. These occur when the parent process has not yet read the exit status of the child process. Zombie processes do not consume system resources but can clutter the process table if not handled properly.</li></ul></li><li><strong>CPU Usage</strong> – Breaks down CPU utilization into different categories:<ul class="wp-block-list"><li><strong>us (User Space)</strong> – CPU time spent on user processes.</li><li><strong>sy (System Space)</strong> – CPU time spent on kernel operations.</li><li><strong>id (Idle)</strong> – Time when the CPU is not being used.</li><li><strong>wa (I/O Wait)</strong> – Time spent waiting for I/O operations to complete.</li><li><strong>st (Steal Time)</strong> – CPU cycles stolen by a hypervisor in a virtualized environment.</li></ul></li><li><strong>Memory Usage</strong> – Shows the total, used, free, and available RAM.</li><li><strong>Swap Usage</strong> – Displays total, used, and free swap memory, which is used when RAM is full.</li></ul><p class="wp-block-paragraph"></p><h3 class="wp-block-heading has-medium-font-size">Process Table</h3><p class="wp-block-paragraph">The table below the header lists active processes with details such as:</p><ul class="wp-block-list"><li><strong>PID</strong> – Process ID, a unique identifier for each process.</li><li><strong>USER</strong> – The owner of the process.</li><li><strong>PR</strong> – Priority of the process, affecting its scheduling.</li><li><strong>NI</strong> – Nice value, which determines how favorable the process scheduling is.</li><li><strong>VIRT</strong> – The total virtual memory used by the process.</li><li><strong>RES</strong> – The actual RAM used by the process.</li><li><strong>SHR</strong> – The shared memory portion.</li><li><strong>S</strong> – Process state:<ul class="wp-block-list"><li><code>R</code> – Running</li><li><code>S</code> – Sleeping</li><li><code>Z</code> – Zombie</li><li><code>T</code> – Stopped</li></ul></li><li><strong>%CPU</strong> – The percentage of CPU time used.</li><li><strong>%MEM</strong> – The percentage of RAM used.</li><li><strong>TIME+</strong> – The total CPU time consumed by the process.</li><li><strong>COMMAND</strong> – The command that started the process.</li></ul><p class="wp-block-paragraph"></p><h2 class="wp-block-heading has-large-font-size">3. Interactive Commands</h2><p class="wp-block-paragraph">While running <code>top</code>, various keyboard shortcuts allow dynamic interaction:</p><ul class="wp-block-list"><li><strong>q</strong> – Quit <code>top</code>.</li><li><strong>h</strong> – Display help.</li><li><strong>k</strong> – Kill a process by entering its PID.</li><li><strong>r</strong> – Renice a process (change priority).</li><li><strong>z</strong> – Toggle color/monochrome mode.</li><li><strong>M</strong> – Sort by memory usage.</li><li><strong>P</strong> – Sort by CPU usage.</li><li><strong>T</strong> – Sort by process runtime.</li><li><strong>1</strong> – Toggle CPU usage breakdown for multi-core systems.</li><li><strong>u</strong> – Filter processes by a specific user.</li><li><strong>s</strong> – Change update interval.</li></ul><p class="wp-block-paragraph"></p><h2 class="wp-block-heading has-large-font-size">4. Command-Line Options</h2><p class="wp-block-paragraph">The <code>top</code> command supports various options for customization:</p><ul class="wp-block-list"><li><strong>-b</strong> (Batch mode): Used for scripting to display output in a non-interactive mode.<code>$ top -b -n 1</code><code>-n</code> specifies the number of iterations before exit.</li><li><strong>-o FIELD</strong> (Sort by a specific field):<code>$ top -o %CPU</code>Sorts by CPU usage.</li><li><strong>-d SECONDS</strong> (Refresh interval):<code>$ top -d 3</code>Updates the display every 3 seconds.</li><li><strong>-u USERNAME</strong> (Show processes for a specific user):<code>$ top -u john</code></li><li><strong>-p PID</strong> (Monitor a specific process):<code>$ top -p 1234</code></li></ul><p class="wp-block-paragraph"></p><h2 class="wp-block-heading has-large-font-size">5. Customizing <code>top</code> Display</h2><h3 class="wp-block-heading has-medium-font-size">Persistent Customization</h3><p class="wp-block-paragraph">To save custom settings, press <strong>W</strong> while running <code>top</code>. This saves the configuration to <code>~/.toprc</code>.</p><h3 class="wp-block-heading has-medium-font-size">Changing Column Layout</h3><ul class="wp-block-list"><li>Press <strong>f</strong> to toggle the fields displayed.</li><li>Press <strong>o</strong> to change sorting order.</li><li>Press <strong>X</strong> to highlight sorted columns.</li></ul><p class="wp-block-paragraph"></p><h2 class="wp-block-heading has-large-font-size">6. Alternative to <code>top</code>: <code>htop</code>, btop</h2><p class="wp-block-paragraph">For a more user-friendly experience, <code>htop</code> is an alternative:</p><pre class="wp-block-syntaxhighlighter-code">$ sudo apt install htop  # Debian-based$ sudo yum install htop  # RHEL-based$ htop</pre><p class="wp-block-paragraph">It provides a visually rich interface with color coding and easy navigation.</p><p class="wp-block-paragraph"></p>
