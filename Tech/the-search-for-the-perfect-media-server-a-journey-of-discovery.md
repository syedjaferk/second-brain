<p class="wp-block-paragraph">Dinesh, an avid movie collector and music lover, had a growing problem. His laptop was bursting at the seams with countless movies, albums, and family photos. Every time he wanted to watch a movie or listen to her carefully curated playlists, he had to sit around his laptop. And if he wanted to share something with his friends, it meant copying with USB drives or spending hours transferring files.</p><figure class="wp-block-embed is-type-video is-provider-youtube wp-block-embed-youtube wp-embed-aspect-16-9 wp-has-aspect-ratio"><div class="wp-block-embed__wrapper"><span class="embed-youtube" style="text-align:center; display: block;"><iframe allowfullscreen="true" class="youtube-player" height="360" sandbox="allow-scripts allow-same-origin allow-popups allow-presentation allow-popups-to-escape-sandbox" src="https://www.youtube.com/embed/wRPZ940ClJo?version=3&amp;rel=1&amp;showsearch=0&amp;showinfo=1&amp;iv_load_policy=1&amp;fs=1&amp;hl=en-US&amp;autohide=2&amp;wmode=transparent" style="border:0;" width="640"></iframe></span></div></figure><p class="wp-block-paragraph">One Saturday evening, after yet another struggle to connect his laptop to his smart TV via a mess of cables, Dinesh decided it was time for a change. He needed a solution that would let his access all his media from any device in his house – phone, tablet, and TV. He needed a media server.</p><p class="wp-block-paragraph">Dinesh fired up his browser and began his search: “How to stream media to all my devices.” He gone through the results – Plex, Jellyfin, Emby… Each option seemed promising but felt too complex, requiring subscriptions or heavy installations.</p><p class="wp-block-paragraph">Frustrated, Dinesh thought, “There must be something simpler. I don’t need all the bells and whistles; I just want to access my files from anywhere in my house.” He refined her search: “lightweight media server for Linux.”</p><p class="wp-block-paragraph">There it was – <strong>MiniDLNA</strong>. Described as a simple, lightweight DLNA server that was easy to set up and perfect for home use, MiniDLNA (also known as ReadyMedia) seemed to be exactly what Dinesh needed.</p><p class="wp-block-paragraph"></p><p class="wp-block-paragraph"><strong>MiniDLNA (also known as ReadyMedia)</strong> is a lightweight, simple server for streaming media (like videos, music, and pictures) to devices on your network. It is compatible with various DLNA/UPnP (Digital Living Network Alliance/Universal Plug and Play) devices such as smart TVs, media players, gaming consoles, etc.</p><h3 class="wp-block-heading">How to Use MiniDLNA</h3><p class="wp-block-paragraph">Here’s a step-by-step guide to setting up and using MiniDLNA on a Linux based system.</p><h4 class="wp-block-heading">1. <strong>Install MiniDLNA</strong></h4><p class="wp-block-paragraph">To get started, you need to install MiniDLNA. The installation steps can vary slightly depending on your operating system.</p><p class="wp-block-paragraph"><strong>For Debian/Ubuntu-based systems:</strong></p><pre class="wp-block-syntaxhighlighter-code">sudo apt updatesudo apt install minidlna</pre><p class="wp-block-paragraph"><strong>For Red Hat/CentOS-based systems:</strong></p><p class="wp-block-paragraph">First, enable the EPEL repository,</p><pre class="wp-block-syntaxhighlighter-code">sudo yum install epel-release</pre><p class="wp-block-paragraph">Then, install MiniDLNA,</p><pre class="wp-block-syntaxhighlighter-code">sudo yum install minidlna</pre><h4 class="wp-block-heading">2. <strong>Configure MiniDLNA</strong></h4><p class="wp-block-paragraph">Once installed, you need to configure MiniDLNA to tell it where to find your media files.</p><figure class="wp-block-image size-large"><img alt="" class="wp-image-1339" data-recalc-dims="1" decoding="async" height="1004" loading="lazy" src="https://i0.wp.com/parottasalna.com/wp-content/uploads/2024/09/image.png?resize=1915%2C1004&amp;ssl=1" width="1915"/></figure><p class="wp-block-paragraph">a. <strong>Open the MiniDLNA configuration file in a text editor</strong></p><pre class="wp-block-syntaxhighlighter-code">sudo nano /etc/minidlna.conf</pre><p class="wp-block-paragraph">b. <strong>Configure the following parameters:</strong></p><ul class="wp-block-list"><li><strong><code>media_dir</code></strong>:  Set this to the directories where your media files (music, pictures, and videos) are stored. You can specify different media types for each directory.</li></ul><pre class="wp-block-syntaxhighlighter-code">media_dir=A,/path/to/music  # 'A' is for audiomedia_dir=V,/path/to/videos # 'V' is for videomedia_dir=P,/path/to/photos # 'P' is for pictures</pre><ul class="wp-block-list"><li><strong><code>db_dir=</code></strong>: The directory where the database and cache files are stored.</li></ul><pre class="wp-block-syntaxhighlighter-code">db_dir=/var/cache/minidlna</pre><ul class="wp-block-list"><li><strong><code>log_dir=</code></strong>: The directory where log files are stored.</li></ul><pre class="wp-block-syntaxhighlighter-code">log_dir=/var/log/minidlna</pre><ul class="wp-block-list"><li><strong><code>friendly_name=</code></strong>: The name of your media server. This will appear on your DLNA devices.</li></ul><pre class="wp-block-syntaxhighlighter-code">friendly_name=Laptop SJ</pre><ul class="wp-block-list"><li><strong><code>notify_interval=</code></strong>: The interval in seconds that MiniDLNA will notify clients of its presence. The default is <code>900</code> (15 minutes).</li></ul><pre class="wp-block-syntaxhighlighter-code">notify_interval=900</pre><p class="wp-block-paragraph">c. <strong>Save and close the file (<code>Ctrl + X</code>, <code>Y</code>, <code>Enter</code> in Nano).</strong></p><h4 class="wp-block-heading">3. Start the MiniDLNA Service</h4><p class="wp-block-paragraph">After configuration, start the MiniDLNA service</p><pre class="wp-block-syntaxhighlighter-code">sudo systemctl start minidlna</pre><p class="wp-block-paragraph">To enable it to start at boot,</p><pre class="wp-block-syntaxhighlighter-code">sudo systemctl enable minidlna</pre><h4 class="wp-block-heading">4. <strong>Rescan Media Files</strong></h4><p class="wp-block-paragraph">To make MiniDLNA scan your media files and add them to its database, you can force a rescan with</p><pre class="wp-block-syntaxhighlighter-code">sudo minidlnad -R</pre><h4 class="wp-block-heading">5. <strong>Access Your Media on DLNA/UPnP Devices</strong></h4><p class="wp-block-paragraph">Now, your MiniDLNA server should be up and running. You can access your media from any DLNA-compliant device on your network:</p><ul class="wp-block-list"><li>On your Smart TV, look for the “Media Server” or “DLNA” option in the input/source menu.</li><li>On a Windows PC, go to <code>This PC</code> or <code>Network</code> and find your DLNA server under “Media Devices.”</li><li>On Android, use a media player app like VLC or BubbleUPnP to find your server.</li></ul><h4 class="wp-block-heading">6. <strong>Check Logs and Troubleshoot</strong></h4><p class="wp-block-paragraph">If you encounter any issues, you can check the logs for more information</p><pre class="wp-block-syntaxhighlighter-code">sudo tail -f /var/log/minidlna/minidlna.log</pre><h3 class="wp-block-heading">To setup for a single user</h3><p class="wp-block-paragraph">Disable the global daemon</p><pre class="wp-block-syntaxhighlighter-code">sudo service minidlna stopsudo update-rc.d minidlna disable</pre><p class="wp-block-paragraph">Create the necessary local files and directories as regular user and edit the configuration</p><pre class="wp-block-syntaxhighlighter-code">mkdir -p ~/.minidlna/cachecd ~/.minidlnacp /etc/minidlna.conf .$EDITOR minidlna.conf</pre><p class="wp-block-paragraph">Configure as you would globally above but these definitions need to be defined locally</p><pre class="wp-block-syntaxhighlighter-code">db_dir=/home/$USER/.minidlna/cachelog_dir=/home/$USER/.minidlna </pre><p class="wp-block-paragraph">To start the daemon locally</p><pre class="wp-block-syntaxhighlighter-code">minidlnad -f /home/$USER/.minidlna/minidlna.conf -P /home/$USER/.minidlna/minidlna.pid</pre><p class="wp-block-paragraph">To stop the local daemon</p><pre class="wp-block-syntaxhighlighter-code">xargs kill &lt;/home/$USER/.minidlna/minidlna.pid</pre><p class="wp-block-paragraph">To rebuild the database,</p><pre class="wp-block-syntaxhighlighter-code">minidlnad -f /home/$USER/.minidlna/minidlna.conf -R</pre><blockquote class="wp-block-quote is-layout-flow wp-block-quote-is-layout-flow"><p class="wp-block-paragraph">For more info: <a href="https://help.ubuntu.com/community/MiniDLNA">https://help.ubuntu.com/community/MiniDLNA</a></p></blockquote><h3 class="wp-block-heading">Additional Tips</h3><ul class="wp-block-list"><li><strong>Firewall Rules</strong>: Ensure that your firewall settings allow traffic on the MiniDLNA port (<code>8200</code> by default) and UPnP (typically port <code>1900</code> for UDP).</li><li><strong>Update Media Files</strong>: Whenever you add or remove files from your media directory, run <code>minidlnad -R</code> to update the database.</li><li><strong>Multiple Media Directories</strong>: You can have multiple <code>media_dir</code> lines in your configuration if your media is spread across different folders.</li></ul><p class="wp-block-paragraph">To set up <strong>MiniDLNA</strong> with <strong>VLC Media Player</strong> so you can stream content from your MiniDLNA server, follow these steps:</p><p class="wp-block-paragraph"></p><p class="wp-block-paragraph">Let’s see how to use this in VLC </p><h3 class="wp-block-heading">On Machine</h3><h4 class="wp-block-heading">1. <strong>Install VLC Media Player</strong></h4><p class="wp-block-paragraph">Make sure you have VLC Media Player installed on your device. If not, you can download it from the <a data-proofer-ignore="" href="#">official VLC website</a>.</p><h4 class="wp-block-heading">2. <strong>Open VLC Media Player</strong></h4><p class="wp-block-paragraph">Launch VLC Media Player on your computer.</p><h4 class="wp-block-heading">3. <strong>Open the UPnP/DLNA Network Stream</strong></h4><ol class="wp-block-list"><li><strong>Go to the “View” Menu:</strong><ul class="wp-block-list"><li>On the VLC menu bar, click on <code>View</code> and then <code>Playlist</code> or press <code>Ctrl + L</code> (Windows/Linux) or <code>Cmd + Shift + P</code> (Mac).</li></ul></li><li><strong>Locate Your DLNA Server:</strong><ul class="wp-block-list"><li>In the left sidebar, you will see an option for <code>Local Network</code>.</li><li>Click on <code>Universal Plug'n'Play</code> or <code>UPnP</code>.</li><li>VLC will search for available DLNA/UPnP servers on your network.</li></ul></li><li><strong>Select Your MiniDLNA Server:</strong><ul class="wp-block-list"><li>After a few moments, your MiniDLNA server should appear under the <code>UPnP</code> section.</li><li>Click on your server name (e.g., <code>My DLNA Server</code>).</li></ul></li><li><strong>Browse and Play Media:</strong><ul class="wp-block-list"><li>You will see the folders you configured (e.g., <code>Music</code>, <code>Videos</code>, <code>Pictures</code>).</li><li>Navigate through the folders and double-click on a media file to start streaming.</li></ul></li></ol><h4 class="wp-block-heading">4. <strong>Alternative Method: Open Network Stream</strong></h4><p class="wp-block-paragraph">If you know the IP address of your MiniDLNA server, you can connect directly:</p><ol class="wp-block-list"><li><strong>Open Network Stream:</strong><ul class="wp-block-list"><li>Click on <code>Media</code> in the menu bar and select <code>Open Network Stream...</code> or press <code>Ctrl + N</code> (Windows/Linux) or <code>Cmd + N</code> (Mac).</li></ul></li><li><strong>Enter the URL:</strong><ul class="wp-block-list"><li>Enter the URL of your MiniDLNA server in the format <code>http://[Server IP]:8200</code>.</li><li>Example: <code>http://192.168.1.100:8200</code>.</li></ul></li><li><strong>Click “Play”:</strong><ul class="wp-block-list"><li>Click on the <code>Play</code> button to start streaming from your MiniDLNA server.</li></ul></li></ol><h4 class="wp-block-heading">5. <strong>Tips for Better Streaming Experience</strong></h4><ul class="wp-block-list"><li><strong>Ensure the Server is Running:</strong> Make sure the MiniDLNA server is running and the media files are correctly indexed.</li><li><strong>Network Stability:</strong> A stable local network connection is necessary for smooth streaming. Use a wired connection if possible or ensure a strong Wi-Fi signal.</li><li><strong>Firewall Settings:</strong> Ensure that the firewall on your server allows traffic on port <code>8200</code> (or the port specified in your MiniDLNA configuration).</li></ul><p class="wp-block-paragraph"></p><h3 class="wp-block-heading">On Android</h3><p class="wp-block-paragraph">To set up and stream content from <strong>MiniDLNA</strong> using an <strong>Android app</strong>, you will need a DLNA/UPnP client app that can discover and stream media from DLNA servers. Several apps are available for this purpose, such as <strong>VLC for Android</strong>, <strong>BubbleUPnP</strong>, <strong>Kodi</strong>, and others. Here’s how to use VLC for Android and BubbleUPnP, two popular choices</p><h3 class="wp-block-heading">Using VLC for Android</h3><ol class="wp-block-list"><li><strong>Install VLC for Android:</strong><ul class="wp-block-list"><li>Download and install the VLC app from the <a data-proofer-ignore="" href="#">Google Play Store</a>.</li></ul></li><li><strong>Open VLC for Android:</strong><ul class="wp-block-list"><li>Launch the VLC app on your Android device.</li></ul></li><li><strong>Access the Local Network:</strong><ul class="wp-block-list"><li>Tap on the <strong>menu button</strong> (three horizontal lines) in the upper-left corner of the screen.</li><li>Select <strong>Local Network</strong> from the sidebar menu.</li></ul></li><li><strong>Find Your MiniDLNA Server:</strong><ul class="wp-block-list"><li>VLC will automatically search for DLNA/UPnP servers on your local network. After a few moments, your MiniDLNA server should appear in the list.</li><li>Tap on the name of your MiniDLNA server (e.g., <code>My DLNA Server</code>).</li></ul></li><li><strong>Browse and Play Media:</strong><ul class="wp-block-list"><li>You will see your media folders (e.g., <code>Music</code>, <code>Videos</code>, <code>Pictures</code>) as configured in your MiniDLNA setup.</li><li>Navigate to the desired folder and tap on any media file to start streaming.</li></ul></li></ol><h3 class="wp-block-heading">Additional Tips</h3><ul class="wp-block-list"><li><strong>Ensure MiniDLNA is Running:</strong> Make sure your MiniDLNA server is properly configured and running on your local network.</li><li><strong>Check Network Connection:</strong> Ensure your Android device is connected to the same local network (Wi-Fi) as the MiniDLNA server.</li><li><strong>Firewall Settings:</strong> If you are not seeing the MiniDLNA server in your app, ensure that the server’s firewall settings allow DLNA/UPnP traffic.</li></ul><h3 class="wp-block-heading">Some Problems That you may face </h3><ol class="wp-block-list"><li><code>minidlna.service: Main process exited, code=exited, status=255/EXCEPTION - check the logs. Mostly its due to an instance already running on port 8200. Kill that and reload the db. </code> <code>lsof -i :8200 will give PID. and </code>`kill -9 &lt;PID&gt;` will kill the process.</li><li>If the media files is not refreshing, then try <code>minidlnad -f /home/$USER/.minidlna/minidlna.conf -R or </code>`sudo minidlnad -R`</li></ol>
