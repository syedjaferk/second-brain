<p class="wp-block-paragraph"></p><p class="wp-block-paragraph">The <strong>standard hashing algorithm</strong> is inefficient while processing network queries. This traditional technique presupposes that we have a set number of servers and that all mapping locations are known in advance.</p><p class="wp-block-paragraph">This scenario is particularly troublesome in distributed systems when several users request multiple servers. <strong>If some servers fail, then mapping the work to new servers involves a huge and intensive calculation</strong>, which is wasteful and reduces the service’s throughput while increasing the application’s latency.</p><p class="wp-block-paragraph"></p><h2 class="wp-block-heading" id="heading-consistent-hashing">Consistent Hashing</h2><p class="wp-block-paragraph">Consistent Hashing is a <strong>distributed</strong> <strong>hashing</strong> scheme that operates <strong>independently of the number of servers or objects in a distributed hash table</strong> by assigning them a position on an <strong>abstract circle, or hash ring</strong>.</p><p class="wp-block-paragraph">This allows servers and things to scale without affecting the overall system. So the hash table is independent of the number of servers available to minimize key relocation when scale changes occur.</p><p class="wp-block-paragraph"></p><h2 class="wp-block-heading" id="heading-assumptions-for-understanding-the-concept">Assumptions for understanding the concept</h2><ol class="wp-block-list"><li>We are considering 4 servers Server 0, Server 1, Server 2, and Server 3 with the hash value of 0, 90, 180, and 270 respectively.</li><li>We will be using 360 to find the position of the server in the ring. In the real world, it can be any number.</li></ol><p class="wp-block-paragraph"></p><h2 class="wp-block-heading" id="heading-explanation">Explanation</h2><p class="wp-block-paragraph">Consider a circle or a ring, which will have 360 deg. Now we can place the servers based on their hash value modulo 360. So,</p><ul class="wp-block-list"><li><strong>Server 0</strong> will be placed at hash(server 0) % 360 = 0 % 360 = 0</li><li><strong>Server 1</strong> will be placed at hash(server 1) % 360 = 90 % 360 = 90</li><li><strong>Server 2</strong> will be placed at hash(server 2) % 360 = 180 % 360 = 180</li><li><strong>Server 3</strong> will be placed at hash(server 3) % 360 = 270 % 360 = 270</li></ul><p class="wp-block-paragraph"></p><p class="wp-block-paragraph">Now the ring will look like this,</p><p class="wp-block-paragraph"></p><figure class="wp-block-image size-large"><img alt="" class="wp-image-4556" data-recalc-dims="1" decoding="async" height="536" loading="lazy" src="https://i0.wp.com/parottasalna.com/wp-content/uploads/2025/10/image.png?resize=954%2C536&amp;ssl=1" width="954"/></figure><p class="wp-block-paragraph"></p><h2 class="wp-block-heading">Scenario 1 – Request Coming In</h2><p class="wp-block-paragraph">Now considering a request R1 is coming, now we need to redirect this request to one of the available servers. The hash of the request R1 is 40. Visually we can see 40 is in between server 0 and server 1. (Technically we need to apply binary search). The next available server to 40 (hash of R1) is Server 1. So we can redirect this request to server 1.</p><figure class="wp-block-image size-large"><img alt="" class="wp-image-4557" data-recalc-dims="1" decoding="async" height="532" loading="lazy" src="https://i0.wp.com/parottasalna.com/wp-content/uploads/2025/10/image-1.png?resize=951%2C532&amp;ssl=1" width="951"/></figure><p class="wp-block-paragraph">Now considering a request R2 is coming, now we need to redirect this request to one of the available servers. The hash of the request R2 is 60. Visually we can see 60 is in between server 0 and server 1. (Technically we need to apply binary search). The next available server to 60 (hash of R2) is Server 1. So we can redirect this request to server 1.</p><p class="wp-block-paragraph"></p><figure class="wp-block-image size-large"><img alt="" class="wp-image-4558" data-recalc-dims="1" decoding="async" height="534" loading="lazy" src="https://i0.wp.com/parottasalna.com/wp-content/uploads/2025/10/image-2.png?resize=956%2C534&amp;ssl=1" width="956"/></figure><p class="wp-block-paragraph"></p><h2 class="wp-block-heading">Scenario 2 : Adding a new server</h2><h4 class="wp-block-heading" id="heading-scenario-2-andgt-adding-a-new-server"></h4><p class="wp-block-paragraph">Now we are going to add a new server S4. Assume the hash value of this server S4 is 50, it will be placed in between S0 and S1.</p><figure class="wp-block-image size-large"><img alt="" class="wp-image-4560" data-recalc-dims="1" decoding="async" height="529" loading="lazy" src="https://i0.wp.com/parottasalna.com/wp-content/uploads/2025/10/image-3.png?resize=955%2C529&amp;ssl=1" width="955"/></figure><p class="wp-block-paragraph">But we also need to check on one thing, (ie), in Scenario 1 we discussed about R1 (with the hash value of 40) is been placed in Server S1. Since we are going to introduce S4, the Request R1 (hash value of 40) needs to be placed in Server S4 – based on binary insertion.</p><p class="wp-block-paragraph"></p><figure class="wp-block-image size-large"><img alt="" class="wp-image-4561" data-recalc-dims="1" decoding="async" height="488" loading="lazy" src="https://i0.wp.com/parottasalna.com/wp-content/uploads/2025/10/image-4.png?resize=927%2C488&amp;ssl=1" width="927"/></figure><p class="wp-block-paragraph"></p><p class="wp-block-paragraph">Server 4 will need to query the next available server, whether any request less than the hash value is present. If it’s present we need to move the data related to the request.</p><p class="wp-block-paragraph"></p><figure class="wp-block-image size-large"><img alt="" class="wp-image-4563" data-recalc-dims="1" decoding="async" height="498" loading="lazy" src="https://i0.wp.com/parottasalna.com/wp-content/uploads/2025/10/image-5.png?resize=891%2C498&amp;ssl=1" width="891"/></figure><p class="wp-block-paragraph"></p><p class="wp-block-paragraph">So this is how it goes,</p><ol class="wp-block-list"><li>S4 will query S1, Do you have any requests with my range ?</li><li>If there are any requests they would be shared from S1 to S4.</li></ol><p class="wp-block-paragraph">After data transfer,</p><p class="wp-block-paragraph"></p><figure class="wp-block-image size-large"><img alt="" class="wp-image-4564" data-recalc-dims="1" decoding="async" height="523" loading="lazy" src="https://i0.wp.com/parottasalna.com/wp-content/uploads/2025/10/image-6.png?resize=874%2C523&amp;ssl=1" width="874"/></figure><p class="wp-block-paragraph"></p><h2 class="wp-block-heading">Scenario 3 : Deleting a server</h2><p class="wp-block-paragraph">Currently, the hash ring with servers will look like this,</p><figure class="wp-block-image size-large"><img alt="" class="wp-image-4566" data-recalc-dims="1" decoding="async" height="527" loading="lazy" src="https://i0.wp.com/parottasalna.com/wp-content/uploads/2025/10/image-7.png?resize=945%2C527&amp;ssl=1" width="945"/></figure><p class="wp-block-paragraph"></p><p class="wp-block-paragraph">Server 1 is to be deleted and the contents of the server will be moved to the next available server; in our case it’s S2.</p><p class="wp-block-paragraph"></p><figure class="wp-block-image size-large"><img alt="" class="wp-image-4567" data-recalc-dims="1" decoding="async" height="528" loading="lazy" src="https://i0.wp.com/parottasalna.com/wp-content/uploads/2025/10/image-8.png?resize=945%2C528&amp;ssl=1" width="945"/></figure><p class="wp-block-paragraph"></p><p class="wp-block-paragraph">Now we can see the request details of R2 (with the hash value of 60) are present in the S1, So this value is to be moved to S2.</p><p class="wp-block-paragraph">After deletion,</p><p class="wp-block-paragraph"></p><figure class="wp-block-image size-large"><img alt="" class="wp-image-4568" data-recalc-dims="1" decoding="async" height="522" loading="lazy" src="https://i0.wp.com/parottasalna.com/wp-content/uploads/2025/10/image-9.png?resize=942%2C522&amp;ssl=1" width="942"/></figure><p class="wp-block-paragraph"></p><p class="wp-block-paragraph">This is how consistent hashing works at a basic level. In this blog post, we haven’t considered the scenarios of a server crash. That’s a whole different topic.</p>
