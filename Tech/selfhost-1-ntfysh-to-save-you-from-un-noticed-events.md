<p class="wp-block-paragraph">Alex Pandian was the system administrator for a tech company, responsible for managing servers, maintaining network stability, and ensuring that everything ran smoothly. </p><figure class="wp-block-image size-large"><img alt="" class="wp-image-802" data-recalc-dims="1" decoding="async" height="614" loading="lazy" src="https://i0.wp.com/parottasalna.com/wp-content/uploads/2024/08/image-4.png?resize=923%2C614&amp;ssl=1" width="923"/></figure><p class="wp-block-paragraph">With many scripts running daily and long-running processes that needed monitoring, Alex was constantly flooded with notifications.</p><p class="wp-block-paragraph"><strong>Alex Pandian</strong>: “Every day, I have to gothrough dozens of emails and alerts just to find the ones that matter,” </p><p class="wp-block-paragraph">Alex muttered while sipping coffee in the server room. </p><p class="wp-block-paragraph"><strong>Alex Pandian</strong>: “There must be a better way to streamline all this information.”</p><p class="wp-block-paragraph">Despite using several monitoring tools, the notifications from these systems were scattered and overwhelming. Alex needed a more efficient method to receive alerts only when crucial events occurred, such as script failures or the completion of resource-intensive tasks.</p><p class="wp-block-paragraph">Determined to find a better system, Alex began searching online for a tool that could help consolidate and manage notifications. </p><p class="wp-block-paragraph">After reading through countless forums and reviews, Alex stumbled upon a discussion about <strong><a href="https://ntfy.sh">ntfy.sh</a></strong>, a service praised for its simplicity and flexibility.</p><p class="wp-block-paragraph">“This looks promising,” Alex thought, excited by the ability to publish and subscribe to notifications using a straightforward, topic-based system. <strong>The idea of having notifications sent directly to a phone or desktop without needing complex configurations was exactly what Alex was looking for.</strong></p><p class="wp-block-paragraph">Alex decided to consult with Sam, a fellow system admin known for their expertise in automation and monitoring.</p><p class="wp-block-paragraph"><strong>Alex Pandian</strong>: “Hey Sam, have you ever used ntfy.sh?”</p><p class="wp-block-paragraph"><strong>Sam</strong>: “Absolutely, It’s a lifesaver for managing notifications. How do you plan to use it?”</p><p class="wp-block-paragraph"><strong>Alex Pandian</strong>: “I’m thinking of using it for real-time alerts on script failures and long-running commands, Can you show me how it works?”</p><p class="wp-block-paragraph"><strong>Sam</strong>: “Of course,” </p><p class="wp-block-paragraph">with a smile, eager to guide Alex through setting up ntfy.sh to improve workflow efficiency.</p><p class="wp-block-paragraph"></p><p class="wp-block-paragraph">Together, Sam and Alex began configuring ntfy.sh for Alex’s environment. They focused on setting up topics and integrating them with existing systems to ensure that important notifications were delivered promptly.</p><h3 class="wp-block-heading">Step 1: Identifying Key Topics</h3><p class="wp-block-paragraph">Alex identified the main areas where notifications were needed:</p><ul class="wp-block-list"><li><strong>script-failures</strong>: To receive alerts whenever a script failed.</li><li><strong>command-completions</strong>: To notify when long-running commands finished.</li><li><strong>server-health</strong>: For critical server health alerts.</li></ul><h3 class="wp-block-heading">Step 2: Subscribing to Topics</h3><p class="wp-block-paragraph">Sam showed Alex how to subscribe to these topics using ntfy.sh on a mobile device and desktop. This ensured that Alex would receive notifications wherever they were, without having to constantly check email or dashboards.</p><pre class="wp-block-syntaxhighlighter-code"># Subscribe to topicsntfy subscribe script-failuresntfy subscribe command-completionsntfy subscribe server-health</pre><h3 class="wp-block-heading">Step 3: Automating Notifications</h3><p class="wp-block-paragraph">Sam explained how to use bash scripts and <code>curl</code> to send notifications to ntfy.sh whenever specific events occurred.</p><p class="wp-block-paragraph">“For example, if a script fails, you can automatically send an alert to the ‘script-failures’ topic,” Sam demonstrated.</p><pre class="wp-block-syntaxhighlighter-code"># Notify on script failure./backup-script.sh || curl -d "Backup script failed!" ntfy.sh/script-failures</pre><p class="wp-block-paragraph">Alex was impressed by the simplicity and efficiency of this approach. “I can automate all of this?” Alex asked.</p><p class="wp-block-paragraph">“Definitely,” Sam replied. “You can integrate it with cron jobs, monitoring tools, and more. It’s a great way to keep track of important events without getting bogged down by noise.”</p><p class="wp-block-paragraph">With the basics in place, Alex began applying ntfy.sh to various real-world scenarios, streamlining the notification process and improving overall efficiency.</p><h3 class="wp-block-heading">Monitoring Script Failures</h3><p class="wp-block-paragraph">Alex set up automated alerts for critical scripts that ran daily, ensuring that any failures were immediately reported. This allowed Alex to address issues quickly, minimizing downtime and improving system reliability.</p><pre class="wp-block-syntaxhighlighter-code"># Notify on critical script failure./critical-task.sh || curl -d "Critical task script failed!" ntfy.sh/script-failures</pre><h3 class="wp-block-heading">Tracking Long-Running Commands</h3><p class="wp-block-paragraph">Whenever Alex initiated a long-running command, such as a server backup or data migration, notifications were sent upon completion. This enabled Alex to focus on other tasks without constantly checking on progress.</p><pre class="wp-block-syntaxhighlighter-code"># Notify on long-running command completionlong-command &amp;&amp; curl -d "Long command completed successfully." ntfy.sh/command-completions</pre><h3 class="wp-block-heading">Server Health Alerts</h3><p class="wp-block-paragraph">To monitor server health, Alex integrated ntfy.sh with existing monitoring tools, ensuring that any critical issues were immediately flagged.</p><pre class="wp-block-syntaxhighlighter-code"># Send server health alertcurl -d "Server CPU usage is critically high!" ntfy.sh/server-health</pre><p class="wp-block-paragraph">As with any new tool, there were challenges to overcome.
