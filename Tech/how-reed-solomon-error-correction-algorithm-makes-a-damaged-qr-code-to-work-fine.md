<h3 class="wp-block-heading" id="heading-amused-at">Amused At</h3><p class="wp-block-paragraph">Due to fever and cold i went to Ayurvedic medicine store. During the payment , i asked him QR code for digital payment. The QR code sheet is pretty damaged.</p><figure class="wp-block-image size-large"><img alt="" class="wp-image-141" data-recalc-dims="1" decoding="async" height="1080" loading="lazy" src="https://i0.wp.com/parottasalna.com/wp-content/uploads/2024/06/image-10.png?resize=1080%2C1080&amp;ssl=1" width="1080"/></figure><p class="wp-block-paragraph">Before scanning i thought it wouldn’t work. But to my surprise it worked after straightening the torn part. How could it work ?</p><h3 class="wp-block-heading" id="heading-on-googling"><a href="https://parottasalna.com/how-reed-solomon-error-correction-algorithm-makes-a-damaged-qr-code-to-work-fine#heading-on-googling"></a>On Googling …</h3><p class="wp-block-paragraph">A QR code (short for Quick Response code) is an array of black and white squares or pixels set in a grid that stores data for a machine to read. A smartphone or camera can quickly process the information contained in a QR code’s specific arrangement of pixels, making it a convenient way to store and access data.</p><h3 class="wp-block-heading" id="heading-how-do-qr-codes-work"><strong>How do QR codes work?</strong></h3><p class="wp-block-paragraph">QR codes work by arranging a series of black and white pixels into a unique pattern that encodes a string of data. When scanned, the pattern of the qcode can be translated into human-readable information.</p><p class="wp-block-paragraph">If you know how to scan a barcode using a laser-reader, you already know how to scan a QR code — the only real difference is the type of device used to read the code. But unlike barcodes’ linear arrangement, QR codes can store much more data, because they’re written both vertically and horizontally.</p><p class="wp-block-paragraph">All QR codes have a standard structure that makes information readable. Let’s break it down:</p><ul class="wp-block-list"><li><strong>Quiet Zone:</strong> The empty white border around the outside of a QR code.</li><li><strong>Hinder pattern:</strong> The three black squares in the bottom-left, top-left, and top-right corners.</li><li><strong>Alignment pattern:</strong> A small square near the bottom-right corner, which ensures the QR code can be read, even if it’s skewed or at an angle.</li><li><strong>Timing pattern:</strong> An L-shaped line that helps to identify individual squares within the whole code, making it possible for a damaged QR code to be read.</li><li><strong>Version information:</strong> Identifies which version of the QR code is being read.</li><li><strong>Data cells:</strong> The rest of the QR code communicates the actual information — the URL, phone number, or other data.</li></ul><figure class="wp-block-image size-large"><img alt="" class="wp-image-144" data-recalc-dims="1" decoding="async" height="495" loading="lazy" src="https://i0.wp.com/parottasalna.com/wp-content/uploads/2024/06/image-11.png?resize=796%2C495&amp;ssl=1" width="796"/></figure><p class="wp-block-paragraph">Usually, you don’t need to use a special QR app scanner — smartphones will link to the content in the QR code when you point your camera app at it. If you’re offline or think you’ll need to access the code again, taking a picture of it will make the QR code scan again when you view it later.</p><h3 class="wp-block-heading" id="heading-how-does-it-manage-damages">How does it manage damages ?</h3><p class="wp-block-paragraph">The QR code error correction is a unique feature that allows printed QR codes to withstand damage like scratches and smudging yet still work just fine.</p><p class="wp-block-paragraph">The error correction in QR codes comes in four levels, each capable of withstanding a different maximum amount of damage.</p><p class="wp-block-paragraph">And since the error correction works by adding extra modules, the QR code’s dimensions will increase as its error correction level rises.</p><p class="wp-block-paragraph">Online QR code generator platforms offer different levels of error correction, so it’s important to go for one that provides the level that suits your needs. Here are the four levels:</p><ol class="wp-block-list"><li>Level L (low) – 7% error correction</li><li>Level M (Medium) – 15% error correction</li><li>Level Q (Quartile) – 25% error correction</li><li>Level H (High) – 30% error correction</li></ol><figure class="wp-block-image size-large"><img alt="" class="wp-image-145" data-recalc-dims="1" decoding="async" height="1080" loading="lazy" src="https://i0.wp.com/parottasalna.com/wp-content/uploads/2024/06/image-12.png?resize=1080%2C1080&amp;ssl=1" width="1080"/></figure><p class="wp-block-paragraph">Higher the level, more dense the code looks.</p><p class="wp-block-paragraph">The magical ingredient on top of these error correction is Reed Solomon Error Correction.</p><p class="wp-block-paragraph">The Reed-Solomon encoder takes a block of digital data and adds extra “redundant” bits. Errors occur during transmission or storage for a number of reasons (for example noise or interference, scratches on a CD, etc). The Reed-Solomon decoder processes each block and attempts to correct errors and recover the original data. The number and type of errors that can be corrected depends on the characteristics of the Reed-Solomon code.</p><h3 class="wp-block-heading" id="heading-how-it-works">How it works ?</h3><p class="wp-block-paragraph">Let’s try the working using python library.
