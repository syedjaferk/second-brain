Operators</h4><p class="wp-block-paragraph">These operators compare two values and return either <code>True</code> or <code>False</code>.</p><ul class="wp-block-list"><li><strong>Equal to (==):</strong> Checks if two values are equal.</li></ul><pre class="wp-block-syntaxhighlighter-code">a = 5b = 3result = (a == b)  # result is False</pre><ul class="wp-block-list"><li><strong>Not equal to (!=):</strong> Checks if two values are not equal.</li></ul><pre class="wp-block-syntaxhighlighter-code">a = 5b = 3result = (a != b)  # result is True</pre><ul class="wp-block-list"><li><strong>Greater than (&gt;):</strong> Checks if one value is greater than another.</li></ul><pre class="wp-block-syntaxhighlighter-code">a = 5b = 3result = (a &gt; b)  # result is True</pre><ul class="wp-block-list"><li><strong>Less than (&lt;):</strong> Checks if one value is less than another.</li></ul><pre class="wp-block-syntaxhighlighter-code">a = 5b = 3result = (a &lt; b)  # result is False</pre><ul class="wp-block-list"><li><strong>Greater than or equal to (&gt;=):</strong> Checks if one value is greater than or equal to another.</li></ul><pre class="wp-block-syntaxhighlighter-code">a = 5b = 3result = (a &gt;= b)  # result is True</pre><ul class="wp-block-list"><li><strong>Less than or equal to (&lt;=):</strong> Checks if one value is less than or equal to another.</li></ul><pre class="wp-block-syntaxhighlighter-code">a = 5b = 3result = (a &lt;= b)  # result is False</pre><h4 class="wp-block-heading">Logical Operators</h4><p class="wp-block-paragraph">These operators are used to combine conditional statements.</p><ul class="wp-block-list"><li><strong>and:</strong> Returns <code>True</code> if both statements are true.</li></ul><pre class="wp-block-syntaxhighlighter-code">a = 5b = 3result = (a &gt; b and a &gt; 0)  # result is True</pre><ul class="wp-block-list"><li><strong>or:</strong> Returns <code>True</code> if one of the statements is true.</li></ul><pre class="wp-block-syntaxhighlighter-code">a = 5b = 3result = (a &gt; b or a &lt; 0)  # result is True</pre><ul class="wp-block-list"><li><strong>not:</strong> Reverses the result, returns <code>False</code> if the result is true.</li></ul><pre class="wp-block-syntaxhighlighter-code">a = 5result = not (a &gt; 0)  # result is False</pre><h3 class="wp-block-heading">What Are Conditionals?</h3><p class="wp-block-paragraph">Conditionals are like traffic signals for your code. They help your program decide which path to take based on certain conditions. The most common conditional statements in Python are <code>if</code>, <code>elif</code>, and <code>else</code>.</p><h4 class="wp-block-heading">1. The <code>if</code> Statement</h4><p class="wp-block-paragraph">The <code>if</code> statement checks a condition and executes the code block if the condition is <code>True</code>.</p><pre class="wp-block-syntaxhighlighter-code">a = 5b = 3if a &gt; b:    print("a is greater than b")</pre><h4 class="wp-block-heading">2. The <code>elif</code> Statement</h4><p class="wp-block-paragraph">The <code>elif</code> statement is short for “else if”. It checks another condition if the previous <code>if</code> condition was <code>False</code>.</p><pre class="wp-block-syntaxhighlighter-code">a = 5b = 5if a &gt; b:    print("a is greater than b")elif a == b:    print("a is equal to b")</pre><h4 class="wp-block-heading">3. The <code>else</code> Statement</h4><p class="wp-block-paragraph">The <code>else</code> statement catches anything that isn’t caught by the preceding conditions.</p><pre class="wp-block-syntaxhighlighter-code">a = 3b = 5if a &gt; b:    print("a is greater than b")elif a == b:    print("a is equal to b")else:    print("a is less than b")</pre><h3 class="wp-block-heading">Using <code>input()</code> to Get User Input</h3><p class="wp-block-paragraph">This function allows you to get input from the user. It’s like asking a question and waiting for the user to answer. </p><p class="wp-block-paragraph">The input you get is <strong>always a string (text)</strong>, so if you need a number, you have to convert it.</p><h4 class="wp-block-heading">Basic Usage of <code>input()</code></h4><p class="wp-block-paragraph">Here’s a simple example:</p><pre class="wp-block-syntaxhighlighter-code">name = input("What is your name? ")print("Hello, " + name + "!")</pre><p class="wp-block-paragraph">In this example, the program asks the user for their name and then prints the same.</p><h4 class="wp-block-heading">Converting Input to Numbers</h4><p class="wp-block-paragraph">If you want to work with numbers, you’ll need to convert the input from a string to an integer or a float.</p><pre class="wp-block-syntaxhighlighter-code">age = input("How old are you? ")age = int(age)print("You are " + str(age) + " years old.")</pre><h3 class="wp-block-heading">Putting It All Together</h3><p class="wp-block-paragraph">Let’s combine operators, conditionals, and <code>input()</code> in a simple example. Suppose you want to create a program that checks if a number entered by the user is positive, negative, or zero.</p><pre class="wp-block-syntaxhighlighter-code">number = input("Enter a number: ")number = float(number)  # Convert the input to a floatif number &gt; 0:    print("The number is positive.")elif number &lt; 0:    print("The number is negative.")else:    print("The number is zero.")</pre><p class="wp-block-paragraph">In this example, the program:</p><ol class="wp-block-list"><li>Asks the user to enter a number.</li><li>Converts the input to a float (to handle decimal numbers).</li><li>Uses conditionals to check if the number is positive, negative, or zero, and prints the result.</li></ol><p class="wp-block-paragraph"></p><h3 class="wp-block-heading">Quiz</h3><p class="wp-block-paragraph"><a href="https://docs.google.com/forms/d/e/1FAIpQLSdwRG3dEZBsjsFWy6nLzQqu5ksjjdtvy7OUXQg8Z0u3fvMXfw/viewform?usp=sf_link" rel="nofollow">https://docs.google.com/forms/d/e/1FAIpQLSdwRG3dEZBsjsFWy6nLzQqu5ksjjdtvy7OUXQg8Z0u3fvMXfw/viewform?usp=sf_link</a></p><h3 class="wp-block-heading">Tasks:</h3><figure class="wp-block-embed is-type-wp-embed is-provider-parotta-salna wp-block-embed-parotta-salna"><div class="wp-block-embed__wrapper"><blockquote class="wp-embedded-content" data-secret="eydvrmCEth"><a href="https://parottasalna.com/2024/07/15/task-3-operators-conditionals-input/">TASK 3 – Operators, Conditionals, Input()</a></blockquote><iframe class="wp-embedded-content" data-secret="eydvrmCEth" frameborder="0" height="282" marginheight="0" marginwidth="0" sandbox="allow-scripts" scrolling="no" security="restricted" src="https://parottasalna.com/2024/07/15/task-3-operators-conditionals-input/embed/#?secret=PxlEKZrqRp#?secret=eydvrmCEth" style="position: absolute;
