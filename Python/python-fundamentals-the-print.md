The Basics: Printing a String</h3><p class="wp-block-paragraph">To print text, you simply put the text inside double or single quotes and pass it to the <code>print</code> function.</p><pre class="wp-block-syntaxhighlighter-code">print("Hello, world!")</pre><figure class="wp-block-image size-large is-resized"><img alt="" class="wp-image-403" data-recalc-dims="1" decoding="async" height="160" loading="lazy" src="https://i0.wp.com/parottasalna.com/wp-content/uploads/2024/07/image-3.png?resize=474%2C160&amp;ssl=1" style="width:246px;height:auto" width="474"/></figure><p class="wp-block-paragraph">This will display: <code>Hello, world!</code></p><h3 class="wp-block-heading">2. Printing Variables</h3><p class="wp-block-paragraph">Variables are used to store data. You can print variables by passing them to the <code>print</code> function.</p><pre class="wp-block-syntaxhighlighter-code">name = "Parotta Salna"print(name)</pre><figure class="wp-block-image size-large"><img alt="" class="wp-image-406" data-recalc-dims="1" decoding="async" height="104" loading="lazy" src="https://i0.wp.com/parottasalna.com/wp-content/uploads/2024/07/image-4.png?resize=255%2C104&amp;ssl=1" width="255"/></figure><p class="wp-block-paragraph">This will display: `Parotta Salna`</p><h3 class="wp-block-heading">3. Printing Multiple Items</h3><p class="wp-block-paragraph">You can print multiple items by separating them with commas. Python will add a space between each item.</p><pre class="wp-block-syntaxhighlighter-code">age = 25city = "New York"name = "Parotta Salna"print("Name:", name, "Age:", age, "City:", city)</pre><figure class="wp-block-image size-large"><img alt="" class="wp-image-410" data-recalc-dims="1" decoding="async" height="150" loading="lazy" src="https://i0.wp.com/parottasalna.com/wp-content/uploads/2024/07/image-6.png?resize=498%2C150&amp;ssl=1" width="498"/></figure><p class="wp-block-paragraph">This will display: <code>Name: Parotta Salna Age: 25 City: New York</code></p><h3 class="wp-block-heading">4. Formatted Strings with f-strings</h3><p class="wp-block-paragraph">An f-string is a way to format strings in Python. You can insert variables directly into the string by prefixing it with an <code>f</code> and using curly braces <code>{}</code> around the variables.</p><pre class="wp-block-syntaxhighlighter-code">age = 25city = "New York"name = "Parotta Salna"print(f"Name: {name}, Age: {age}, City: {city}")</pre><figure class="wp-block-image size-large"><img alt="" class="wp-image-412" data-recalc-dims="1" decoding="async" height="150" loading="lazy" src="https://i0.wp.com/parottasalna.com/wp-content/uploads/2024/07/image-7.png?resize=498%2C150&amp;ssl=1" width="498"/></figure><p class="wp-block-paragraph">This will display: <code>Name: Parotta Salna Age: 25 City: New York</code></p><h3 class="wp-block-heading">5. Concatenation of Strings</h3><p class="wp-block-paragraph">You can also combine (concatenate) strings using the <code>+</code> operator.</p><pre class="wp-block-syntaxhighlighter-code">main_dish = "Idly"side_dish = "Sambar"print(main_dish + " " + side_dish + "!")</pre><figure class="wp-block-image size-large"><img alt="" class="wp-image-415" data-recalc-dims="1" decoding="async" height="127" loading="lazy" src="https://i0.wp.com/parottasalna.com/wp-content/uploads/2024/07/image-8.png?resize=424%2C127&amp;ssl=1" width="424"/></figure><p class="wp-block-paragraph">This will display: Idly Sambar!</p><h3 class="wp-block-heading">6. Using Escape Sequences</h3><p class="wp-block-paragraph">Escape sequences allow you to include special characters in a string. For example, <code>\n</code> adds a new line.</p><pre class="wp-block-syntaxhighlighter-code">print("Line1\nLine2\nLine3")</pre><figure class="wp-block-image size-large"><img alt="" class="wp-image-417" data-recalc-dims="1" decoding="async" height="80" loading="lazy" src="https://i0.wp.com/parottasalna.com/wp-content/uploads/2024/07/image-9.png?resize=311%2C80&amp;ssl=1" width="311"/></figure><p class="wp-block-paragraph">This will display: </p><figure class="wp-block-image size-large"><img alt="" class="wp-image-421" data-recalc-dims="1" decoding="async" height="150" loading="lazy" src="https://i0.wp.com/parottasalna.com/wp-content/uploads/2024/07/image-11.png?resize=90%2C150&amp;ssl=1" width="90"/></figure><h3 class="wp-block-heading">7. Printing Quotes Inside Strings</h3><p class="wp-block-paragraph">To print quotes inside a string, you can use either single or double quotes to enclose the string and the other type of quotes inside it.</p><pre class="wp-block-syntaxhighlighter-code">print('He said, "Hello, world!"')</pre><figure class="wp-block-image size-large"><img alt="" class="wp-image-424" data-recalc-dims="1" decoding="async" height="105" loading="lazy" src="https://i0.wp.com/parottasalna.com/wp-content/uploads/2024/07/image-12.png?resize=329%2C105&amp;ssl=1" width="329"/></figure><p class="wp-block-paragraph">This will display: He said, “Hello, world!”</p><h3 class="wp-block-heading">8. Raw Strings to Ignore Escape Sequences</h3><p class="wp-block-paragraph">Prefix the string with <code>r</code> to treat backslashes as literal characters.</p><pre class="wp-block-syntaxhighlighter-code">print(r"C:\Users\Name")</pre><figure class="wp-block-image size-large"><img alt="" class="wp-image-426" data-recalc-dims="1" decoding="async" height="104" loading="lazy" src="https://i0.wp.com/parottasalna.com/wp-content/uploads/2024/07/image-13.png?resize=236%2C104&amp;ssl=1" width="236"/></figure><p class="wp-block-paragraph">This will display: C:\Users\Name</p><h3 class="wp-block-heading">9. Printing Numbers</h3><p class="wp-block-paragraph">You can print numbers directly without quotes.</p><pre class="wp-block-syntaxhighlighter-code">print(12345)</pre><p class="wp-block-paragraph">This will display: <code>12345</code></p><h3 class="wp-block-heading">10. Printing Results of Expressions</h3><p class="wp-block-paragraph">You can also print the result of an expression.</p><pre class="wp-block-syntaxhighlighter-code">print(5 + 3)</pre><figure class="wp-block-image size-large"><img alt="" class="wp-image-428" data-recalc-dims="1" decoding="async" height="121" loading="lazy" src="https://i0.wp.com/parottasalna.com/wp-content/uploads/2024/07/image-14.png?resize=150%2C121&amp;ssl=1" width="150"/></figure><p class="wp-block-paragraph">This will display: 8</p><h3 class="wp-block-heading">11. Printing Lists and Dictionaries</h3><p class="wp-block-paragraph">You can print entire lists and dictionaries.</p><pre class="wp-block-syntaxhighlighter-code">fruits = ["apple", "banana", "cherry"]print(fruits)person = {"name": "Alice", "age": 25, "city": "New York"}print(person)</pre><figure class="wp-block-image size-large"><img alt="" class="wp-image-431" data-recalc-dims="1" decoding="async" height="190" loading="lazy" src="https://i0.wp.com/parottasalna.com/wp-content/uploads/2024/07/image-15.png?resize=570%2C190&amp;ssl=1" width="570"/></figure><p class="wp-block-paragraph">This will display:</p><p class="wp-block-paragraph" style="margin-top:0;margin-bottom:0;padding-top:0;padding-bottom:0">[‘apple’, ‘banana’, ‘cherry’]</p><p class="wp-block-paragraph" style="margin-top:0;margin-bottom:0;padding-top:0;padding-bottom:0">{‘name’: ‘Alice’, ‘age’: 25, ‘city’: ‘New York’}</p><h3 class="wp-block-heading">12. Using sep and end Parameters</h3><p class="wp-block-paragraph">The <code>sep</code> parameter changes the separator between items, and <code>end</code> changes the ending character (default is newline).</p><pre class="wp-block-syntaxhighlighter-code">print("Hello", "world", sep="-", end="!")</pre><p class="wp-block-paragraph">This will display: <code>Hello-world!</code></p><h3 class="wp-block-heading">13. Multiline Strings with Triple Quotes</h3><p class="wp-block-paragraph">Triple quotes allow you to print multiline strings easily.</p><pre class="wp-block-syntaxhighlighter-code">print("""This is amultilinestring""")</pre><p class="wp-block-paragraph">This will display:</p><figure class="wp-block-image size-large"><img alt="" class="wp-image-434" data-recalc-dims="1" decoding="async" height="129" loading="lazy" src="https://i0.wp.com/parottasalna.com/wp-content/uploads/2024/07/image-16.png?resize=105%2C129&amp;ssl=1" width="105"/></figure><h3 class="wp-block-heading">14. Printing in a Loop</h3><p class="wp-block-paragraph">You can use a loop to print multiple lines.</p><pre class="wp-block-syntaxhighlighter-code">for i in range(5):    print("Iteration", i)</pre><figure class="wp-block-image size-large"><img alt="" class="wp-image-436" data-recalc-dims="1" decoding="async" height="173" loading="lazy" src="https://i0.wp.com/parottasalna.com/wp-content/uploads/2024/07/image-17.png?resize=124%2C173&amp;ssl=1" width="124"/></figure><h3 class="wp-block-heading">15. String Multiplication</h3><p class="wp-block-paragraph">Multiply a string by an integer to repeat it.</p><pre class="wp-block-syntaxhighlighter-code">print("Hello " * 3)</pre><p class="wp-block-paragraph">This will display: <code>Hello Hello Hello</code></p><h3 class="wp-block-heading">16. Printing Boolean Values</h3><p class="wp-block-paragraph">Print boolean values directly.</p><pre class="wp-block-syntaxhighlighter-code">is_active = Trueprint(is_active)</pre><p class="wp-block-paragraph">This will display: <code>True</code></p><h3 class="wp-block-heading">17. Printing None</h3><p class="wp-block-paragraph">Print the <code>None</code> value directly.</p><pre class="wp-block-syntaxhighlighter-code">value = Noneprint(value)</pre><p class="wp-block-paragraph">This will display: <code>None</code></p><h3 class="wp-block-heading">18. Combining Strings and Variables</h3><p class="wp-block-paragraph">Combine strings and variables using <code>+</code> for simple cases or formatted strings for more complex scenarios.</p><pre class="wp-block-syntaxhighlighter-code">temperature = 22.5print("The temperature is " + str(temperature) + " degrees Celsius.")</pre><p class="wp-block-paragraph">This will display: <code>The temperature is 22.5 degrees Celsius.</code></p><h3 class="wp-block-heading">19. Using print for Debugging</h3><p class="wp-block-paragraph">You can use <code>print</code> to debug your code by printing variable values at different points.</p><pre class="wp-block-syntaxhighlighter-code">def add(a, b):    print(f"Adding {a} and {b}")    return a + bresult = add(5, 3)print("Result:", result)</pre><p class="wp-block-paragraph">This will display:</p><pre class="wp-block-preformatted"></pre><figure class="wp-block-image size-large"><img alt="" class="wp-image-440" data-recalc-dims="1" decoding="async" height="104" loading="lazy" src="https://i0.wp.com/parottasalna.com/wp-content/uploads/2024/07/image-18.png?resize=152%2C104&amp;ssl=1" width="152"/></figure><h3 class="wp-block-heading">20. Printing with .format()</h3><p class="wp-block-paragraph">Use the <code>.format()</code> method for string formatting.</p><pre class="wp-block-syntaxhighlighter-code">print("Name: {}, Age: {}, City: {}".format(name, age, city))</pre><p class="wp-block-paragraph">This will display: <code>Name: Alice, Age: 25, City: New York</code></p><p class="wp-block-paragraph"></p><h3 class="wp-block-heading">Excercises:</h3><figure class="wp-block-embed is-type-wp-embed is-provider-parotta-salna wp-block-embed-parotta-salna"><div class="wp-block-embed__wrapper"><blockquote class="wp-embedded-content" data-secret="jmAslQ9wKP"><a href="https://parottasalna.com/2024/07/04/task-1-python-print-exercises/">TASK 1: Python – Print exercises</a></blockquote><iframe class="wp-embedded-content" data-secret="jmAslQ9wKP" frameborder="0" height="282" marginheight="0" marginwidth="0" sandbox="allow-scripts" scrolling="no" security="restricted" src="https://parottasalna.com/2024/07/04/task-1-python-print-exercises/embed/#?secret=Hbxz7BG4wD#?secret=jmAslQ9wKP" style="position: absolute; visibility: hidden;" title="“TASK 1: Python – Print exercises” — Parottasalna" width="500"></iframe></div></figure><h3 class="wp-block-heading">Quiz:</h3><p class="wp-block-paragraph"><a href="https://docs.google.com/forms/d/e/1FAIpQLSeW7dGCYrvPXBK7llexbwa_yImFQWFiHHE4c4ATOk-NwJWxIw/viewform?usp=sf_link">https://docs.google.com/forms/d/e/1FAIpQLSeW7dGCYrvPXBK7llexbwa_yImFQWFiHHE4c4ATOk-NwJWxIw/viewform?usp=sf_link</a></p><h3 class="wp-block-heading">Infographics: </h3><figure class="wp-block-embed is-type-rich is-provider-embed-handler wp-block-embed-embed-handler"><div class="wp-block-embed__wrapper"><p><a href="https://parottasalna.com/wp-content/uploads/2024/07/print-method.pdf" rel="noopener noreferrer nofollow" target="_blank">Click to access print-method.pdf</a></p></div></figure><p class="wp-block-paragraph"></p>
