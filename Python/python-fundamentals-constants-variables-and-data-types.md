<h2 class="wp-block-heading">Variables</h2><p class="wp-block-paragraph">A variable in Python is a symbolic name that references or points to an object. </p><p class="wp-block-paragraph">Once a variable is assigned a value, it can be used to refer to that value throughout the program. </p><p class="wp-block-paragraph">Variables act as containers (eg: box) for storing data values. But ideally they are reference to a memory where the value is stored.</p><h3 class="wp-block-heading">How to name a variable ?</h3><p class="wp-block-paragraph">When naming variables in Python, there are a few rules and best practices to follow:</p><ol class="wp-block-list"><li><strong>Start with a letter or an underscore</strong>: Variable names must begin with a letter (a-z, A-Z) or an underscore (_).</li><li><strong>Followed by letters, digits, or underscores</strong>: After the first character, you can use letters, digits (0-9), or underscores.</li><li><strong>Case-sensitive</strong>: Variable names are case-sensitive. For example, <code>myVariable</code> and <code>myvariable</code> are different variables.</li><li><strong>Avoid Python keywords</strong>: Do not use Python reserved words or keywords as variable names (e.g., <code>class</code>, <code>def</code>, <code>for</code>, <code>while</code>).</li></ol><h3 class="wp-block-heading">Examples of Valid Variable Names:</h3><ul class="wp-block-list"><li><code>my_variable</code></li><li><code>variable1</code></li><li><code>_hidden_variable</code></li><li><code>userName</code></li></ul><h3 class="wp-block-heading">Examples of Invalid Variable Names:</h3><ul class="wp-block-list"><li><code>1variable</code> (starts with a digit)</li><li><code>my-variable</code> (contains a hyphen)</li><li><code>for</code> (a reserved keyword)</li></ul><h3 class="wp-block-heading">Assigning Values to Variables</h3><p class="wp-block-paragraph">In Python, the assignment operator <code>=</code> is used to assign values to variables. The syntax is straightforward: <code>variable_name = value</code>.</p><p class="wp-block-paragraph">Examples:</p><pre class="wp-block-syntaxhighlighter-code"># Assigning integer valueage = 25# Assigning string valuename = "John Doe"# Assigning float valueheight = 5.9# Assigning boolean valueis_student = True</pre><h3 class="wp-block-heading">Multiple Assignments</h3><p class="wp-block-paragraph">Python allows you to assign values to multiple variables in a single line. This can make your code more concise and readable.</p><p class="wp-block-paragraph">Example:</p><pre class="wp-block-syntaxhighlighter-code"># Assigning multiple variables in a single linea, b, c = 5, 10, 15# Swapping values of two variablesx, y = y, x</pre><h3 class="wp-block-heading">Unpacking Sequences</h3><p class="wp-block-paragraph">Python also supports unpacking sequences, such as lists or tuples, into variables. This feature is handy when working with collections of data.</p><p class="wp-block-paragraph">Example:</p><pre class="wp-block-syntaxhighlighter-code"># Unpacking a tupleperson = ("Alice", 30, "Engineer")name, age, profession = person# Unpacking a listnumbers = [1, 2, 3]one, two, three = numbers</pre><h3 class="wp-block-heading">Variable Types</h3><p class="wp-block-paragraph">Python is a dynamically typed language, which means you don’t need to declare the type of a variable when assigning a value to it. The type is inferred at runtime based on the assigned value.</p><p class="wp-block-paragraph">Example:</p><pre class="wp-block-syntaxhighlighter-code"># Dynamic typingmy_variable = 10        # my_variable is an integermy_variable = "Hello"   # my_variable is now a string</pre><p class="wp-block-paragraph">You can check the type of a variable using the <code>type()</code> function.</p><p class="wp-block-paragraph">Example:</p><pre class="wp-block-syntaxhighlighter-code">my_var = 42print(type(my_var))  # Output: &lt;class 'int'&gt;my_var = "Python"print(type(my_var))  # Output: &lt;class 'str'&gt;</pre><h2 class="wp-block-heading">Constants</h2><p class="wp-block-paragraph">In Python, constants are variables whose values are not meant to change. By convention, constants are typically written in all uppercase letters with underscores separating words. </p><blockquote class="wp-block-quote is-layout-flow wp-block-quote-is-layout-flow"><p class="wp-block-paragraph">Note: However, Python does not enforce this, so constants are not truly immutable.</p></blockquote><pre class="wp-block-syntaxhighlighter-code"># Defining a constantPI = 3.14159MAX_USERS = 100</pre><h2 class="wp-block-heading">Data Types</h2><p class="wp-block-paragraph">Data types are the different kinds of values that you can store and work with. </p><p class="wp-block-paragraph">Just like in your home, you have different categories of items like clothes, books, and utensils, in Python, you have different categories of data.</p><h3 class="wp-block-heading">1.
