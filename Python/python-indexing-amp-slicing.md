<p class="wp-block-paragraph">Indexing &amp; Slicing in general is a foundational concept which roots to the usage of all data structures or containers.</p><p class="wp-block-paragraph">Indexing &amp; Slicing is a fundamental concept in Python, especially when working with strings. </p><p class="wp-block-paragraph">If you’re just getting started with Python, understanding how to access individual characters in a string using indexing is important.</p><p class="wp-block-paragraph"></p><h3 class="wp-block-heading">What is indexing ?</h3><p class="wp-block-paragraph">Indexing is nothing but a position. Indexing refers to accessing individual elements of a sequence, such as a string. </p><p class="wp-block-paragraph">In Python, strings are <strong>sequences of characters</strong>, and each character in a string has a position, known as an index. Python uses zero-based indexing, which means the first character of a string has an index of 0, the second character has an index of 1, and so on.</p><p class="wp-block-paragraph">For Eg, Check the below “HELLOWORLD” and its index, </p><figure class="wp-block-image size-large"><img alt="" class="wp-image-685" data-recalc-dims="1" decoding="async" height="140" loading="lazy" src="https://i0.wp.com/parottasalna.com/wp-content/uploads/2024/07/image-54.png?resize=1022%2C140&amp;ssl=1" width="1022"/></figure><h3 class="wp-block-heading">Basic Indexing</h3><p class="wp-block-paragraph">Let’s start with a simple example:</p><pre class="wp-block-syntaxhighlighter-code"># Example Stringword = "Python"# Accessing individual charactersprint(word[0])  # Output: 'P'print(word[1])  # Output: 'y'print(word[2])  # Output: 't'print(word[3])  # Output: 'h'print(word[4])  # Output: 'o'print(word[5])  # Output: 'n'</pre><p class="wp-block-paragraph">In this example, we accessed each character of the string “Python” using its index.</p><h3 class="wp-block-heading">Negative Indexing</h3><p class="wp-block-paragraph">Python also supports negative indexing, which allows you to access characters from the end of the string. The last character has an index of -1, the second last character has an index of -2, and so on.</p><pre class="wp-block-syntaxhighlighter-code"># Example Stringword = "Python"# Accessing characters from the endprint(word[-1])  # Output: 'n'print(word[-2])  # Output: 'o'print(word[-3])  # Output: 'h'print(word[-4])  # Output: 't'print(word[-5])  # Output: 'y'print(word[-6])  # Output: 'P'</pre><h3 class="wp-block-heading">Combining Positive and Negative Indexing</h3><p class="wp-block-paragraph">You can mix positive and negative indexing to access different parts of a string. Here are some examples:</p><pre class="wp-block-syntaxhighlighter-code"># Example Stringword = "Indexing"# Accessing characters using positive and negative indicesprint(word[0])  # Output: 'I'print(word[-1])  # Output: 'g'print(word[2])  # Output: 'd'print(word[-3])  # Output: 'i'</pre><h3 class="wp-block-heading">Real-World Examples</h3><p class="wp-block-paragraph">Let’s look at some practical examples where indexing might be useful.</p><h4 class="wp-block-heading">Example 1: Initials of a Name</h4><p class="wp-block-paragraph">Suppose you have a person’s full name, and you want to extract the initials.</p><pre class="wp-block-syntaxhighlighter-code">full_name = "Parotta Salna"initials = full_name[0] + full_name[8]print(initials)  # Output: 'PS'</pre><p class="wp-block-paragraph">In this example, we used indexing to access the first letter of the first name and the first letter of the last name.</p><h4 class="wp-block-heading">Example 2: Accessing File Extensions</h4><p class="wp-block-paragraph">Consider a filename with an extension, and you want to extract the extension.</p><pre class="wp-block-syntaxhighlighter-code">filename = "document.pdf"extension = filename[-3:]print(extension)  # Output: 'pdf'</pre><p class="wp-block-paragraph">Here, we used negative indexing to get the last three characters of the string, which represent the file extension.</p><h3 class="wp-block-heading">What is Slicing ?</h3><p class="wp-block-paragraph">Slicing enables you to create a new string by extracting a subset of characters from an existing string. </p><p class="wp-block-paragraph">You specify a range of indices and, optionally, a step to determine how slicing should proceed.</p><p class="wp-block-paragraph">For eg, </p><p class="wp-block-paragraph">Below is the “HELLOWORLD” String referenced by variable <em>message</em>, and “LOWO” is a subset which can be represented as <em>message[3:7]</em></p><figure class="wp-block-image size-large"><img alt="" class="wp-image-691" data-recalc-dims="1" decoding="async" height="140" loading="lazy" src="https://i0.wp.com/parottasalna.com/wp-content/uploads/2024/07/image-55.png?resize=1022%2C140&amp;ssl=1" width="1022"/></figure><h3 class="wp-block-heading">Basic Slicing</h3><p class="wp-block-paragraph">The basic syntax for slicing is:</p><pre class="wp-block-syntaxhighlighter-code">string[start:stop]</pre><p class="wp-block-paragraph">Where:</p><ul class="wp-block-list"><li><code>start</code> is the index where the slice begins (inclusive).</li><li><code>stop</code> is the index where the slice ends (exclusive).</li></ul><h4 class="wp-block-heading"><strong>Example 1: Simple Slicing</strong></h4><pre class="wp-block-syntaxhighlighter-code"># Example Stringtext = "Hello, World!"# Slicing the first 5 charactersprint(text[0:5])  # Output: 'Hello'# Slicing characters from index 7 to 11print(text[7:12])  # Output: 'World'</pre><h3 class="wp-block-heading">Omitting Indices</h3><p class="wp-block-paragraph">You can omit the <code>start</code> or <code>stop</code> index to slice from the beginning or to the end of the string.</p><h4 class="wp-block-heading">Example 2: Omitting Start or Stop</h4><pre class="wp-block-syntaxhighlighter-code"># Example Stringtext = "Python Programming"# Slicing from the beginning to index 6print(text[:6])  # Output: 'Python'# Slicing from index 7 to the endprint(text[7:])  # Output: 'Programming'</pre><h3 class="wp-block-heading">Slicing with Step</h3><p class="wp-block-paragraph">You can include a <code>step</code> to specify the interval between characters in the slice. The syntax is:</p><pre class="wp-block-syntaxhighlighter-code">string[start:stop:step]</pre><h4 class="wp-block-heading"><strong>Example 3: Using Step</strong></h4><pre class="wp-block-syntaxhighlighter-code"># Example Stringtext = "abcdefghij"# Slicing every second characterprint(text[0:10:2])  # Output: 'acegi'# Slicing every third characterprint(text[0:10:3])  # Output: 'adgj'</pre><h3 class="wp-block-heading">Negative Indices and Step</h3><p class="wp-block-paragraph">Negative indices count from the end of the string, and a negative step allows you to slice in reverse order.</p><h4 class="wp-block-heading"><strong>Example 4: Negative Indices</strong></h4><pre class="wp-block-syntaxhighlighter-code"># Example Stringtext = "Python"# Slicing the last 3 charactersprint(text[-3:])  # Output: 'hon'# Slicing from the beginning to the second last characterprint(text[:-1])  # Output: 'Pytho'</pre><h4 class="wp-block-heading"><strong>Example 5: Reversing a String</strong></h4><pre class="wp-block-syntaxhighlighter-code"># Example Stringtext = "Reverse"# Reversing the stringprint(text[::-1])  # Output: 'esreveR'</pre><h3 class="wp-block-heading">Real-World Examples</h3><p class="wp-block-paragraph">Let’s explore some practical uses of string slicing.</p><h4 class="wp-block-heading">Example 6: Extracting File Extensions</h4><pre class="wp-block-syntaxhighlighter-code">filename = "report.pdf"extension = filename[-3:]print(extension)  # Output: 'pdf'</pre><h4 class="wp-block-heading">Example 7: Getting a Substring</h4><p class="wp-block-paragraph">Suppose you have a long string and want to extract a specific part of it.</p><pre class="wp-block-syntaxhighlighter-code">quote = "To be or not to be, that is the question."# Extracting 'not to be'substring = quote[9:17]print(substring)  # Output: 'not to be'</pre><h4 class="wp-block-heading">Example 8: Parsing Dates</h4><p class="wp-block-paragraph">Consider a date string in the format “YYYYMMDD” and you want to extract the year, month, and day separately.</p><pre class="wp-block-syntaxhighlighter-code">date = "20230722"year = date[:4]month = date[4:6]day = date[6:]print(f"Year: {year}, Month: {month}, Day: {day}")# Output: Year: 2023, Month: 07, Day: 22</pre><h3 class="wp-block-heading">Advanced Slicing Techniques</h3><h4 class="wp-block-heading">Example 9: Skipping Characters</h4><pre class="wp-block-syntaxhighlighter-code"># Example Stringtext = "abcdef"# Skipping every other characterprint(text[::2])  # Output: 'ace'</pre><h4 class="wp-block-heading">Example 10: Slicing with Negative Step</h4><pre class="wp-block-syntaxhighlighter-code"># Example Stringtext = "abcdefghij"# Reversing every second characterprint(text[::-2])  # Output: 'jhfdb'</pre>
