<p class="wp-block-paragraph"></p><p class="wp-block-paragraph"></p><p class="wp-block-paragraph">To my surprise, i came to know about that there is a stuff called as global ignore in git. In this blog i will jot down notes on setting up global .gitignore file. </p><p class="wp-block-paragraph"></p><p class="wp-block-paragraph">Git allows you to ignore certain files and directories using a <code>.gitignore</code> file. However, if you frequently work on multiple projects, you might want to configure a <strong>global </strong><code><strong>.gitignore</strong></code><strong> file</strong> to avoid repeating the same ignore rules across repositories.</p><p class="wp-block-paragraph"></p><h2 class="wp-block-heading has-large-font-size">Why Use a Global <code>.gitignore</code>?</h2><p class="wp-block-paragraph">A global <code>.gitignore</code> file is beneficial when you want to exclude common files across all Git repositories on your system. Some examples include, </p><ul class="wp-block-list"><li>OS-specific files (e.g., macOS <code>.DS_Store</code>, Windows <code>Thumbs.db</code>)</li><li>Editor/IDE-specific files (e.g., <code>.vscode/</code>, <code>.idea/</code>)</li><li>Common compiled files (e.g., <code>*.pyc</code>, <code>node_modules/</code>, <code>dist/</code>)</li><li>Personal configurations that should not be committed (e.g., <code>.env</code> files)</li><li>Or you can just define a format like *.ignore.* , which you can use to ignore any file needed. </li></ul><p class="wp-block-paragraph"></p><h2 class="wp-block-heading has-large-font-size">Setting Up a Global <code>.gitignore</code> File</h2><h3 class="wp-block-heading has-medium-font-size">1. Create the Global <code>.gitignore</code> File</h3><p class="wp-block-paragraph">Run the following command to create a global <code>.gitignore</code> file in your home directory:</p><pre class="wp-block-syntaxhighlighter-code"> touch ~/.gitignore_global</pre><p class="wp-block-paragraph">You can use any path, but <code>~/.gitignore_global</code> is commonly used.</p><p class="wp-block-paragraph"></p><h3 class="wp-block-heading has-medium-font-size">2. Configure Git to Use the Global <code>.gitignore</code></h3><p class="wp-block-paragraph">Tell Git to use this file globally by running</p><pre class="wp-block-syntaxhighlighter-code"> git config --global core.excludesFile ~/.gitignore_global</pre><p class="wp-block-paragraph"></p><h3 class="wp-block-heading has-medium-font-size">3. Add Rules to the Global <code>.gitignore</code></h3><p class="wp-block-paragraph">Edit the <code>~/.gitignore_global</code> file using a text editor</p><pre class="wp-block-syntaxhighlighter-code"> nano ~/.gitignore_global</pre><p class="wp-block-paragraph"></p><p class="wp-block-paragraph">Example content</p><pre class="wp-block-syntaxhighlighter-code"># Ignore system files.DS_StoreThumbs.db# Ignore editor/IDE settings.vscode/.idea/*.suo*.ntvs**.njsproj*.sln*.sw?# Ignore compiled files*.o*.pyc*.classnode_modules/dist/# Ignore environment files.env.env.local</pre><p class="wp-block-paragraph">Save the file and exit the editor.</p><p class="wp-block-paragraph"></p><h3 class="wp-block-heading has-medium-font-size">4. Verify the Global Ignore Configuration</h3><p class="wp-block-paragraph">To check if Git recognizes your global <code>.gitignore</code> file, run</p><pre class="wp-block-syntaxhighlighter-code"> git config --global core.excludesFile</pre><p class="wp-block-paragraph">It should return the path to your global ignore file, e.g., <code>~/.gitignore_global</code>.</p><p class="wp-block-paragraph"></p><h2 class="wp-block-heading has-large-font-size">Managing the Global <code>.gitignore</code></h2><ul class="wp-block-list"><li>To update the file, edit <code>~/.gitignore_global</code> and add/remove rules as needed.</li><li>If you ever want to remove the global <code>.gitignore</code> setting, run:<code>git config --global --unset core.excludesFile</code></li><li>To list all global configurations, use:<code>git config --global --list</code></li></ul><p class="wp-block-paragraph"></p><p class="wp-block-paragraph">Setting up a global <code>.gitignore</code> file is a simple yet powerful way to maintain cleaner repositories and avoid committing unnecessary files. By following these steps, you can streamline your workflow across multiple Git projects efficiently.</p>
