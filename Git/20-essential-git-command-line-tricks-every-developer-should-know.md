<p class="wp-block-paragraph"></p><p class="wp-block-paragraph">Git is a powerful version control system that every developer should master. Whether you’re a beginner or an experienced developer, knowing a few handy Git command-line tricks can save you time and improve your workflow. Here are 20 essential Git tips and tricks to boost your efficiency.</p><p class="wp-block-paragraph"></p><h2 class="wp-block-heading">1. Undo the Last Commit (Without Losing Changes)</h2><pre class="wp-block-syntaxhighlighter-code">git reset --soft HEAD~1</pre><p class="wp-block-paragraph">If you made a commit but want to undo it while keeping your changes, this command resets the last commit but retains the modified files in your staging area. </p><p class="wp-block-paragraph">This is useful when you realize you need to make more changes before committing. </p><p class="wp-block-paragraph">If you also want to remove the changes from the staging area but keep them in your working directory, use, </p><pre class="wp-block-syntaxhighlighter-code">git reset HEAD~1</pre><p class="wp-block-paragraph"></p><h2 class="wp-block-heading">2. Discard Unstaged Changes</h2><pre class="wp-block-syntaxhighlighter-code">git checkout -- &lt;file&gt;</pre><p class="wp-block-paragraph">Use this to discard local changes in a file before staging. Be careful, as this cannot be undone! If you want to discard all unstaged changes in your working directory, use, </p><pre class="wp-block-syntaxhighlighter-code">git reset --hard HEAD</pre><p class="wp-block-paragraph"></p><h2 class="wp-block-heading">3. Delete a Local Branch</h2><pre class="wp-block-syntaxhighlighter-code">git branch -d branch-name</pre><p class="wp-block-paragraph">Removes a local branch safely if it’s already merged. If it’s not merged and you still want to delete it, use <code>-D</code></p><pre class="wp-block-syntaxhighlighter-code">git branch -D branch-name</pre><p class="wp-block-paragraph"></p><h2 class="wp-block-heading">4. Delete a Remote Branch</h2><pre class="wp-block-syntaxhighlighter-code">git push origin --delete branch-name</pre><p class="wp-block-paragraph">Deletes a branch from the remote repository, useful for cleaning up old feature branches. If you mistakenly deleted the branch and want to restore it, you can use</p><pre class="wp-block-syntaxhighlighter-code">git checkout -b branch-name origin/branch-name</pre><p class="wp-block-paragraph">if it still exists remotely.</p><h2 class="wp-block-heading"></h2><h2 class="wp-block-heading">5. Rename a Local Branch</h2><pre class="wp-block-syntaxhighlighter-code">git branch -m old-name new-name</pre><p class="wp-block-paragraph">Useful when you want to rename a branch locally without affecting the remote repository. To update the remote reference after renaming, push the renamed branch and delete the old one,</p><pre class="wp-block-syntaxhighlighter-code">git push origin -u new-namegit push origin --delete old-name</pre><p class="wp-block-paragraph"></p><h2 class="wp-block-heading">6. See the Commit History in a Compact Format</h2><pre class="wp-block-syntaxhighlighter-code">git log --oneline --graph --decorate --all</pre><p class="wp-block-paragraph">A clean and structured way to view Git history, showing branches and commits in a visual format. If you want to see a detailed history with diffs, use</p><pre class="wp-block-syntaxhighlighter-code">git log -p</pre><p class="wp-block-paragraph"></p><h2 class="wp-block-heading">7. Stash Your Changes Temporarily</h2><pre class="wp-block-syntaxhighlighter-code">git stash</pre><p class="wp-block-paragraph">If you need to switch branches but don’t want to commit yet, stash your changes and retrieve them later with</p><pre class="wp-block-syntaxhighlighter-code">git stash pop</pre><p class="wp-block-paragraph">To see all stashed changes</p><pre class="wp-block-syntaxhighlighter-code">git stash list</pre><p class="wp-block-paragraph"></p><h2 class="wp-block-heading">8. Find the Author of a Line in a File</h2><pre class="wp-block-syntaxhighlighter-code">git blame file-name</pre><p class="wp-block-paragraph">Shows who made changes to each line in a file. Helpful for debugging or reviewing historical changes. If you want to ignore whitespace changes</p><pre class="wp-block-syntaxhighlighter-code">git blame -w file-name</pre><p class="wp-block-paragraph"></p><h2 class="wp-block-heading">9. View a File from a Previous Commit</h2><pre class="wp-block-syntaxhighlighter-code">git show commit-hash:path/to/file</pre><p class="wp-block-paragraph">Useful for checking an older version of a file without switching branches. If you want to restore the file from an old commit</p><pre class="wp-block-syntaxhighlighter-code">git checkout commit-hash -- path/to/file</pre><p class="wp-block-paragraph"></p><h2 class="wp-block-heading">10. Reset a File to the Last Committed Version</h2><pre class="wp-block-syntaxhighlighter-code">git checkout HEAD -- file-name</pre><p class="wp-block-paragraph">Restores the file to the last committed state, removing any local changes. If you want to reset all files</p><pre class="wp-block-syntaxhighlighter-code">git reset --hard HEAD</pre><p class="wp-block-paragraph"></p><h2 class="wp-block-heading">11. Clone a Specific Branch</h2><pre class="wp-block-syntaxhighlighter-code">git clone -b branch-name --single-branch repository-url</pre><p class="wp-block-paragraph">Instead of cloning the entire repository, this fetches only the specified branch, saving time and space. If you want all branches but don’t want to check them out initially:</p><pre class="wp-block-syntaxhighlighter-code">git clone --mirror repository-url</pre><p class="wp-block-paragraph"></p><h2 class="wp-block-heading">12. Change the Last Commit Message</h2><pre class="wp-block-syntaxhighlighter-code">git commit --amend -m "New message"</pre><p class="wp-block-paragraph">Use this to correct a typo in your last commit message before pushing. Be cautious—if you’ve already pushed, use</p><pre class="wp-block-syntaxhighlighter-code">git push --force-with-lease</pre><p class="wp-block-paragraph"></p><h2 class="wp-block-heading">13. See the List of Tracked Files</h2><pre class="wp-block-syntaxhighlighter-code">git ls-files</pre><p class="wp-block-paragraph">Displays all files being tracked by Git, which is useful for auditing your repository. To see ignored files</p><pre class="wp-block-syntaxhighlighter-code">git ls-files --others --ignored --exclude-standard</pre><p class="wp-block-paragraph"></p><h2 class="wp-block-heading">14. Check the Difference Between Two Branches</h2><pre class="wp-block-syntaxhighlighter-code">git diff branch-1..branch-2</pre><p class="wp-block-paragraph">Compares changes between two branches, helping you understand what has been modified. To see only file names that changed</p><pre class="wp-block-syntaxhighlighter-code">git diff --name-only branch-1..branch-2</pre><p class="wp-block-paragraph"></p><h2 class="wp-block-heading">15. Add a Remote Repository</h2><pre class="wp-block-syntaxhighlighter-code">git remote add origin repository-url</pre><p class="wp-block-paragraph">Links a remote repository to your local project, enabling push and pull operations. To verify remote repositories</p><pre class="wp-block-syntaxhighlighter-code">git remote -v</pre><p class="wp-block-paragraph"></p><h2 class="wp-block-heading">16. Remove a Remote Repository</h2><pre class="wp-block-syntaxhighlighter-code">git remote remove origin</pre><p class="wp-block-paragraph">Unlinks your repository from a remote source, useful when switching remotes.</p><p class="wp-block-paragraph"></p><p class="wp-block-paragraph"></p><h2 class="wp-block-heading">17. View the Last Commit Details</h2><pre class="wp-block-syntaxhighlighter-code">git show HEAD</pre><p class="wp-block-paragraph">Shows detailed information about the most recent commit, including the changes made. To see only the commit message</p><pre class="wp-block-syntaxhighlighter-code">git log -1 --pretty=%B</pre><p class="wp-block-paragraph"></p><h2 class="wp-block-heading">18. Check What’s Staged for Commit</h2><pre class="wp-block-syntaxhighlighter-code">git diff --staged</pre><p class="wp-block-paragraph">Displays changes that are staged for commit, helping you review before finalizing a commit.</p><p class="wp-block-paragraph"></p><h2 class="wp-block-heading">19. Fetch and Rebase from a Remote Branch</h2><pre class="wp-block-syntaxhighlighter-code">git pull --rebase origin main</pre><p class="wp-block-paragraph">Combines fetching and rebasing in one step, keeping your branch up-to-date cleanly. If conflicts arise, resolve them manually and continue with</p><pre class="wp-block-syntaxhighlighter-code">git rebase --continue</pre><p class="wp-block-paragraph"></p><h2 class="wp-block-heading">20. View All Git Aliases</h2><pre class="wp-block-syntaxhighlighter-code">git config --global --list | grep alias</pre><p class="wp-block-paragraph">If you’ve set up aliases, this command helps you see them all. Aliases can make your Git workflow faster by shortening common commands. For example</p><pre class="wp-block-syntaxhighlighter-code">git config --global alias.co checkout</pre><p class="wp-block-paragraph">allows you to use <code>git co</code> instead of <code>git checkout</code>.</p><p class="wp-block-paragraph"></p><p class="wp-block-paragraph">Try these tricks in your daily development to level up your Git skills!</p>
