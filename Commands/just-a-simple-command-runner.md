<p class="wp-block-paragraph"><div id="__next"><div class="bg-white dark:bg-slate-950"><div class="blog-post-area relative z-40"><main class="blog-post-detail-card pb-24"><article><div class="blog-content-wrapper article-main-wrapper container relative z-30 mx-auto grid grid-flow-row grid-cols-8 xl:gap-6 2xl:grid-cols-10"><section class="blog-content-main z-20 col-span-8 mb-10 px-4 md:z-10 lg:col-span-6 lg:col-start-2 lg:px-0 xl:col-span-6 xl:col-start-2 2xl:col-span-6 2xl:col-start-3"><div class="relative"><div class="relative mb-10 pb-14" id="post-content-parent"><div class="prose prose-lg mx-auto mb-10 min-h-30 break-words dark:prose-dark xl:prose-xl" id="post-content-wrapper"><p>As a developer, i usually want to run some set of commands to <br/>execute/run the application. Like building and running docker container <br/>or setting some environment variables before running application or <br/>setting up the development environment like activating envs, running <br/>db’s, opening vs_code like that.We can solve these using, alias command; but i need something more friendly with a text file.</p></div></div></div></section></div></article></main></div></div></div></p><h3 class="wp-block-heading">Solution</h3><p class="wp-block-paragraph">While attending one of the weekend <a href="https://ilugc.in/" rel="noreferrer noopener" target="_blank">https://ilugc.in/</a> talks, Sibi K was discussing on one open source tool. JUST.</p><p class="wp-block-paragraph"><strong>Just</strong> is a handy way to save and run project-specific commands. Commands are stored in a file called justfile or Justfile with syntax inspired by make:</p><p class="wp-block-paragraph">Reference: <a href="https://just.systems/man/en/chapter_20.html" rel="noreferrer noopener" target="_blank">https://just.systems/man/en/chapter_20.html</a></p><p class="wp-block-paragraph">Official Website: <a href="https://just.systems/" rel="noreferrer noopener" target="_blank"></a><strong><a href="https://just.systems" rel="noreferrer noopener" target="_blank">just.systems</a></strong></p><p class="wp-block-paragraph">Official Documentation: <a href="https://just.systems/" rel="noreferrer noopener" target="_blank"></a><strong><a href="https://just.systems/man/en" rel="noreferrer noopener" target="_blank">just.systems/man/en</a></strong></p><p class="wp-block-paragraph">Git Reposity: <a href="https://just.systems/" rel="noreferrer noopener" target="_blank"></a><strong><a href="https://github.com/casey/just" rel="noreferrer noopener" target="_blank">github.com/casey/just</a></strong></p><p class="wp-block-paragraph">Examples: <a href="https://just.systems/" rel="noreferrer noopener" target="_blank"></a><strong><a href="https://github.com/casey/just/tree/master/examples" rel="noreferrer noopener" target="_blank">github.com/casey/just/tree/master/examples</a></strong></p><h3 class="wp-block-heading" id="heading-how-it-works">How it works:</h3><ol class="wp-block-list"><li>We just need to create a file named <code>justfile</code> or <code>JustFile</code>.</li><li>Then we need to add command(s) in a groupwise manner under a name, as given below.</li></ol><pre class="wp-block-syntaxhighlighter-code">hello: # &lt;- Group Name    # List of commands to be executed in order.    echo "Hello !"    echo "This will be executed next"</pre><ol class="wp-block-list"><li>Execute the file using <code>just</code>.</li></ol><figure class="wp-block-image"><img alt="image.png" data-recalc-dims="1" decoding="async" src="https://i0.wp.com/cdn.hashnode.com/res/hashnode/image/upload/v1662877192733/wmHjpq7yH.png?ssl=1"/></figure><h3 class="wp-block-heading" id="heading-some-cool-features"><a href="https://parottasalna.com/handy-way-to-save-and-run-project-specific-commands#heading-some-cool-features"></a></h3><h3 class="wp-block-heading" id="heading-some-cool-features">Some cool features</h3><p class="wp-block-paragraph"><strong>1.</strong> We can have a default group, which would be executed when we aren’t specifying the group name.</p><pre class="wp-block-syntaxhighlighter-code">default:    echo "Default !!"hello: # &lt;- Group Name    # List of commands to be executed in order.    echo "Hello !"    echo "This will be executed next"</pre><figure class="wp-block-image"><img alt="image.png" data-recalc-dims="1" decoding="async" src="https://i0.wp.com/cdn.hashnode.com/res/hashnode/image/upload/v1662877609391/aQR0677Ev.png?ssl=1"/></figure><p class="wp-block-paragraph"><strong>2.</strong> Each group is called as recipe’s. We can have multiple recipe’s name in the default recipe to execute them in order.</p><pre class="wp-block-syntaxhighlighter-code">default: hello greethello: # &lt;- Group Name    # List of commands to be executed in order.    echo "Hello !"    echo "This will be excuted next"greet:    echo "Hi How are you"</pre><figure class="wp-block-image"><img alt="image.png" data-recalc-dims="1" decoding="async" src="https://i0.wp.com/cdn.hashnode.com/res/hashnode/image/upload/v1662877800430/6qYf88gKN.png?ssl=1"/></figure><p class="wp-block-paragraph"><strong>3.</strong> We can also use <a href="https://just.systems/man/en/chapter_24.html#dotenv-load" rel="noreferrer noopener" target="_blank"><strong>dotenv</strong></a> files with justfile.</p><p class="wp-block-paragraph"><code>.env</code></p><pre class="wp-block-syntaxhighlighter-code"># a comment, will be ignoredPOSTGRES=localhost:6379PORT=5004</pre><p class="wp-block-paragraph"><code>justfile</code></p><pre class="wp-block-syntaxhighlighter-code">set dotenv-loadserve:    echo "Starting the server with database $POSTGRES on port $PORT"</pre><figure class="wp-block-image"><img alt="image.png" data-recalc-dims="1" decoding="async" src="https://i0.wp.com/cdn.hashnode.com/res/hashnode/image/upload/v1662878283203/b_Rygexzz.png?ssl=1"/></figure><p class="wp-block-paragraph"><strong>4.</strong> Usually when an error happens in a sequence of commands, the next commands will not run. But with justfile we can ignore the errors using hypen as a prefix (<code>-cat</code>).</p><pre class="wp-block-syntaxhighlighter-code">foo:    -cat foo    echo "Done"</pre><figure class="wp-block-image"><img alt="image.png" data-recalc-dims="1" decoding="async" src="https://i0.wp.com/cdn.hashnode.com/res/hashnode/image/upload/v1662878474156/xW7VfCDdP.png?ssl=1"/></figure><p class="wp-block-paragraph"><strong>5.</strong> We can also use <a href="https://just.systems/man/en/chapter_32.html" rel="noreferrer noopener" target="_blank">conditional expressions</a> with just. </p><p class="wp-block-paragraph"><strong>6.</strong> Changing variable values from <a href="https://just.systems/man/en/chapter_34.html" rel="noreferrer noopener" target="_blank">command line</a> itself. </p><p class="wp-block-paragraph"><strong>7.</strong> Remember that each line will be executed in a fresh shell, so if you are changing directory in a line, it won’t affect the other line. </p><p class="wp-block-paragraph"><strong>8.</strong> By using @ symbol it won’t echo the commands that we wrote.</p><pre class="wp-block-syntaxhighlighter-code">hello:    @echo "Done"</pre><figure class="wp-block-image"><img alt="image.png" data-recalc-dims="1" decoding="async" src="https://i0.wp.com/cdn.hashnode.com/res/hashnode/image/upload/v1662879172071/FffEu6zhU.png?ssl=1"/></figure>
