<p class="wp-block-paragraph"></p><h2 class="wp-block-heading has-large-font-size">Introduction</h2><p class="wp-block-paragraph">Git is an essential tool for version control, and one of its underrated but powerful features is <code>git stash</code>. It allows developers to temporarily save their uncommitted changes without committing them, enabling a smooth workflow when switching branches or handling urgent bug fixes.</p><p class="wp-block-paragraph">In this blog, we will explore <code>git stash</code>, its varieties, and some clever hacks to make the most of it.</p><p class="wp-block-paragraph"></p><h2 class="wp-block-heading has-large-font-size">1. Understanding Git Stash</h2><p class="wp-block-paragraph">Git stash allows developers to temporarily save changes made to the working directory, enabling them to switch contexts without having to commit incomplete work. This is particularly useful when you need to switch branches quickly or when you are interrupted by an urgent task.</p><p class="wp-block-paragraph"></p><p class="wp-block-paragraph">When you run <code>git stash</code>, Git takes the uncommitted changes in your working directory (both staged and unstaged) and saves them on a stack called “stash stack”. This action reverts your working directory to the last committed state while safely storing the changes for later use.</p><p class="wp-block-paragraph"></p><h3 class="wp-block-heading has-medium-font-size">How It Works</h3><ul class="wp-block-list"><li>Git saves the current state of the working directory and the index (staging area) as a stash.</li><li>The stash includes modifications to tracked files, newly created files, and changes in the index.</li><li>Untracked files are not stashed by default unless specified.</li><li>Stashes are stored in a stack, with the most recent stash on top.</li></ul><p class="wp-block-paragraph"></p><h3 class="wp-block-heading has-medium-font-size">Common Use Cases</h3><ul class="wp-block-list"><li><strong>Context Switching:</strong> When you are working on a feature and need to switch branches for an urgent bug fix.</li><li><strong>Code Review Feedback:</strong> If you receive feedback and need to make changes but are in the middle of another task.</li><li><strong>Cleanup Before Commit:</strong> To stash temporary debugging changes or print statements before making a clean commit.</li></ul><p class="wp-block-paragraph"></p><p class="wp-block-paragraph">Git stash is used to save uncommitted changes in a temporary area, allowing you to switch branches or work on something else without committing incomplete work.</p><p class="wp-block-paragraph"></p><h3 class="wp-block-heading has-medium-font-size">Basic Usage</h3><p class="wp-block-paragraph">The basic <code>git stash</code> command saves all modified tracked files and staged changes. This does not include untracked files by default.</p><pre class="wp-block-syntaxhighlighter-code">git stash</pre><p class="wp-block-paragraph">This command performs three main actions</p><ul class="wp-block-list"><li><strong>Saves changes:</strong> Takes the current working directory state and index and saves it as a new stash entry.</li><li><strong>Resets working directory:</strong> Reverts the working directory to match the last commit.</li><li><strong>Stacks the stash:</strong> Stores the saved state on top of the stash stack.</li></ul><p class="wp-block-paragraph"></p><h3 class="wp-block-heading has-medium-font-size">Restoring Changes</h3><p class="wp-block-paragraph">To restore the stashed changes, you can use</p><pre class="wp-block-syntaxhighlighter-code">git stash pop</pre><p class="wp-block-paragraph">This does two things</p><ul class="wp-block-list"><li><strong>Applies the stash:</strong> Reapplies the changes to your working directory.</li><li><strong>Deletes the stash:</strong> Removes the stash entry from the stash stack.</li></ul><p class="wp-block-paragraph">If you want to keep the stash for future use</p><pre class="wp-block-syntaxhighlighter-code">git stash apply</pre><p class="wp-block-paragraph">This reapplies the changes without deleting the stash entry.</p><p class="wp-block-paragraph"></p><h3 class="wp-block-heading has-medium-font-size">Viewing and Managing Stashes</h3><p class="wp-block-paragraph">To see a list of all stash entries</p><pre class="wp-block-syntaxhighlighter-code">git stash list</pre><p class="wp-block-paragraph">This shows a list like</p><pre class="wp-block-syntaxhighlighter-code">stash@{0}: WIP on feature-branch: 1234567 Commit messagestash@{1}: WIP on master: 89abcdef Commit message</pre><p class="wp-block-paragraph">Each stash is identified by an index (e.g., <code>stash@{0}</code>) which can be used for other stash commands.</p><pre class="wp-block-syntaxhighlighter-code">git stash</pre><p class="wp-block-paragraph">This command stashes both tracked and untracked changes.</p><p class="wp-block-paragraph"></p><p class="wp-block-paragraph">To apply the last stashed changes back</p><pre class="wp-block-syntaxhighlighter-code">git stash pop</pre><p class="wp-block-paragraph">This applies the stash and removes it from the stash list.</p><p class="wp-block-paragraph"></p><p class="wp-block-paragraph">To apply the stash without removing it</p><pre class="wp-block-syntaxhighlighter-code">git stash apply</pre><p class="wp-block-paragraph"></p><p class="wp-block-paragraph">To see a list of all stashed changes</p><pre class="wp-block-syntaxhighlighter-code">git stash list</pre><p class="wp-block-paragraph"></p><p class="wp-block-paragraph">To remove a specific stash</p><pre class="wp-block-syntaxhighlighter-code">git stash drop stash@{index}</pre><p class="wp-block-paragraph"></p><p class="wp-block-paragraph">To clear all stashes</p><pre class="wp-block-syntaxhighlighter-code">git stash clear</pre><p class="wp-block-paragraph"></p><h2 class="wp-block-heading has-large-font-size">2. Varieties of Git Stash</h2><h3 class="wp-block-heading has-medium-font-size">a) Stashing Untracked Files</h3><p class="wp-block-paragraph">By default, <code>git stash</code> does not include untracked files. To include them</p><pre class="wp-block-syntaxhighlighter-code">git stash -u</pre><p class="wp-block-paragraph">Or:</p><pre class="wp-block-syntaxhighlighter-code">git stash --include-untracked</pre><p class="wp-block-paragraph"></p><h3 class="wp-block-heading has-medium-font-size">b) Stashing Ignored Files</h3><p class="wp-block-paragraph">To stash even ignored files</p><pre class="wp-block-syntaxhighlighter-code">git stash -a</pre><p class="wp-block-paragraph">Or:</p><pre class="wp-block-syntaxhighlighter-code">git stash --all</pre><p class="wp-block-paragraph"></p><h3 class="wp-block-heading has-medium-font-size">c) Stashing with a Message</h3><p class="wp-block-paragraph">To add a meaningful message to a stash</p><pre class="wp-block-syntaxhighlighter-code">git stash push -m "WIP: Refactoring user authentication"</pre><p class="wp-block-paragraph"></p><h3 class="wp-block-heading has-medium-font-size">d) Stashing Specific Files</h3><p class="wp-block-paragraph">If you only want to stash specific files</p><pre class="wp-block-syntaxhighlighter-code">git stash push -m "Partial stash" -- path/to/file</pre><p class="wp-block-paragraph"></p><h3 class="wp-block-heading has-medium-font-size">e) Stashing and Switching Branches</h3><p class="wp-block-paragraph">Instead of running <code>git stash</code> and <code>git checkout</code> separately, do it in one step</p><pre class="wp-block-syntaxhighlighter-code">git stash push -m "WIP: Bug Fix" &amp;&amp; git checkout other-branch</pre><p class="wp-block-paragraph"></p><h2 class="wp-block-heading has-large-font-size">3. Advanced Stash Hacks</h2><h3 class="wp-block-heading has-medium-font-size">a) Viewing Stashed Changes</h3><p class="wp-block-paragraph">To see the contents of a stash before applying</p><pre class="wp-block-syntaxhighlighter-code">git stash show -p stash@{0}</pre><p class="wp-block-paragraph"></p><h3 class="wp-block-heading has-medium-font-size">b) Applying a Stash to a Different Branch</h3><p class="wp-block-paragraph">You can stash on one branch and apply it to another</p><pre class="wp-block-syntaxhighlighter-code">git checkout other-branchgit stash apply stash@{0}</pre><p class="wp-block-paragraph"></p><h3 class="wp-block-heading has-medium-font-size">c) Creating a New Branch from a Stash</h3><p class="wp-block-paragraph">If you realize your stash should have been a separate branch</p><pre class="wp-block-syntaxhighlighter-code">git stash branch new-branch stash@{0}</pre><p class="wp-block-paragraph">This will create a new branch and apply the stashed changes.</p><p class="wp-block-paragraph"></p><h3 class="wp-block-heading has-medium-font-size">d) Keeping Index Changes</h3><p class="wp-block-paragraph">If you want to keep staged files untouched while stashing</p><pre class="wp-block-syntaxhighlighter-code">git stash push --keep-index</pre><p class="wp-block-paragraph"></p><h3 class="wp-block-heading has-medium-font-size">e) Recovering a Dropped Stash</h3><p class="wp-block-paragraph">If you accidentally dropped a stash, it may still be in the reflog</p><pre class="wp-block-syntaxhighlighter-code">git fsck --lost-found</pre><p class="wp-block-paragraph">Or, check stash history with:</p><pre class="wp-block-syntaxhighlighter-code">git reflog stash</pre><p class="wp-block-paragraph"></p><h3 class="wp-block-heading has-medium-font-size">f) Using Stash for Conflict Resolution</h3><p class="wp-block-paragraph">If you’re rebasing and hit conflicts, stash helps in saving progress</p><pre class="wp-block-syntaxhighlighter-code">git stash# Fix conflicts# Continue rebasegit stash pop</pre><p class="wp-block-paragraph"></p><h2 class="wp-block-heading has-large-font-size">4. When Not to Use Git Stash</h2><ul class="wp-block-list"><li>If your work is significant, commit it instead of stashing.</li><li>Avoid excessive stashing as it can lead to forgotten changes.</li><li>Stashing doesn’t track renamed or deleted files effectively.</li></ul><h2 class="wp-block-heading"></h2><p class="wp-block-paragraph">Git stash is an essential tool for developers to manage temporary changes efficiently. With the different stash varieties and hacks, you can enhance your workflow and avoid unnecessary commits. Mastering these techniques will save you time and improve your productivity in version control.</p><p class="wp-block-paragraph">Happy coding! 🚀</p>
