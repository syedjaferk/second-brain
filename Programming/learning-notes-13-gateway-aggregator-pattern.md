<p class="wp-block-paragraph"></p><p class="wp-block-paragraph">As part of cloud design patterns, today i learned about Gateway Aggregation Pattern. It seems like a motivation for GraphQL. In this blog, i write down the notes on Gateway Aggregation Pattern for my future self. </p><p class="wp-block-paragraph">In the world of microservices, applications are often broken down into smaller, independent services, each responsible for a specific functionality. </p><p class="wp-block-paragraph">While this architecture promotes scalability and maintainability, it can complicate communication between services. The Gateway Aggregation Pattern emerges as a solution, enabling streamlined interactions between clients and services. </p><p class="wp-block-paragraph"></p><h3 class="wp-block-heading"><strong>What is the Gateway Aggregation Pattern?</strong></h3><p class="wp-block-paragraph">The Gateway Aggregation Pattern involves introducing a gateway layer to handle requests from clients. Instead of the client making multiple calls to different services, the gateway aggregates the data by making calls to the relevant services and then returning a unified response to the client.</p><p class="wp-block-paragraph">This pattern is particularly useful for:</p><ul class="wp-block-list"><li>Reducing the number of round-trips between clients and services.</li><li>Simplifying client logic.</li><li>Improving performance by centralizing the communication and aggregation logic.</li></ul><figure class="wp-block-image aligncenter size-large"><img alt="" class="wp-image-1892" data-recalc-dims="1" decoding="async" height="372" loading="lazy" src="https://i0.wp.com/parottasalna.com/wp-content/uploads/2024/12/image-20.png?resize=783%2C372&amp;ssl=1" width="783"/></figure><h3 class="wp-block-heading"><strong>How It Works</strong></h3><ol class="wp-block-list" start="1"><li><strong>Client Request:</strong> The client sends a single request to the gateway.</li><li><strong>Gateway Processing:</strong> The gateway makes multiple requests to the required services, aggregates their responses, and applies any necessary transformation.</li><li><strong>Unified Response:</strong> The gateway sends a unified response back to the client.</li></ol><p class="wp-block-paragraph">This approach abstracts the complexity of service interactions from the client, improving the overall user experience.</p><p class="wp-block-paragraph"></p><h3 class="wp-block-heading"><strong>Example Use Case</strong></h3><p class="wp-block-paragraph">Imagine an e-commerce application where a client needs to display a product’s details, reviews, and availability. Without a gateway, the client must call three different microservices</p><ol class="wp-block-list" start="1"><li><strong>Product Service:</strong> Provides details like name, description, and price.</li><li><strong>Review Service:</strong> Returns customer reviews and ratings.</li><li><strong>Inventory Service:</strong> Indicates product availability.</li></ol><p class="wp-block-paragraph"></p><p class="wp-block-paragraph">Using the Gateway Aggregation Pattern, the client makes a single request to the gateway. The gateway calls the three services, aggregates their responses, and returns a combined result, such as</p><pre class="wp-block-syntaxhighlighter-code">{  "product": {    "id": "123",    "name": "Smartphone",    "description": "Latest model with advanced features",    "price": 699.99  },  "reviews": [    {      "user": "Alice",      "rating": 4,      "comment": "Great product!"    },    {      "user": "Bob",      "rating": 5,      "comment": "Excellent value for money."    }  ],  "availability": {    "inStock": true,    "warehouse": "Warehouse A"  }}</pre><p class="wp-block-paragraph"></p><h2 class="wp-block-heading">Tools to implement Gateway Aggregation Pattern</h2><p class="wp-block-paragraph">1. <strong>Kong Gateway</strong></p><p class="wp-block-paragraph">Kong is a popular API gateway that supports custom plugins for advanced use cases like aggregation.</p><p class="wp-block-paragraph"><strong>Example:</strong></p><p class="wp-block-paragraph">Implement a custom <strong>Lua plugin</strong> to fetch and aggregate data from multiple services.</p><p class="wp-block-paragraph">Use Kong’s <strong>Route and Upstream</strong> configurations to direct traffic.</p><p class="wp-block-paragraph"></p><p class="wp-block-paragraph">2. <strong>GraphQL</strong></p><p class="wp-block-paragraph">GraphQL can act as a natural gateway by fetching and aggregating data from multiple sources.</p><pre class="wp-block-syntaxhighlighter-code">const { ApolloServer, gql } = require('apollo-server');const { RESTDataSource } = require('apollo-datasource-rest');class ProductAPI extends RESTDataSource {  constructor() {    super();    this.baseURL = 'http://product-service/';  }  async getProduct(id) {    return this.get(`products/${id}`);  }}class ReviewAPI extends RESTDataSource {  constructor() {    super();    this.baseURL = 'http://review-service/';  }  async getReviews(productId) {    return this.get(`reviews/${productId}`);  }}const typeDefs = gql`  type Product {    id: ID!    name: String    description: String    price: Float  }  type Review {    user: String    rating: Int    comment: String  }  type AggregatedData {    product: Product    reviews: [Review]  }  type Query {    aggregatedData(productId: ID!): AggregatedData  }`;const resolvers = {  Query: {    aggregatedData: async (_, { productId }, { dataSources }) =&gt; {      const product = await dataSources.productAPI.getProduct(productId);      const reviews = await dataSources.reviewAPI.getReviews(productId);      return { product, reviews };    },  },};const server = new ApolloServer({  typeDefs,  resolvers,  dataSources: () =&gt; ({    productAPI: new ProductAPI(),    reviewAPI: new ReviewAPI(),  }),});server.listen().then(({ url }) =&gt; {  console.log(`Server ready at ${url}`);});</pre><p class="wp-block-paragraph"></p><p class="wp-block-paragraph"></p><p class="wp-block-paragraph">By consolidating service calls and centralizing the aggregation logic, this pattern enhances performance and reduces complexity. Open-source tools like Express.js, Apache APISIX, Kong Gateway, and GraphQL make it easy to implement the pattern in diverse environments.</p><p class="wp-block-paragraph"></p><p class="wp-block-paragraph"></p>
