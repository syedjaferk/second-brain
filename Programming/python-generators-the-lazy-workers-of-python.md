<p class="wp-block-paragraph"></p><p class="wp-block-paragraph">When you first learn Python, you’re introduced to functions and loops. As you go deeper, you meet one of Python’s coolest features,  <strong>Generators</strong>.</p><p class="wp-block-paragraph">But what is a generator? </p><p class="wp-block-paragraph">Why do developers say it’s memory efficient or lazy? </p><p class="wp-block-paragraph">In this blog, we are going to see where and how these generators are going to help us. </p><p class="wp-block-paragraph"></p><h2 class="wp-block-heading">🥘 Imagine a Buffet vs. a Waiter<br/></h2><p class="wp-block-paragraph">Let’s say you visit two types of restaurants</p><ul class="wp-block-list"><li><strong>Buffet Restaurant</strong> – All food is laid out at once. You take what you want.</li><li><strong>Waiter Served Restaurant</strong> – You order food, and the waiter brings one dish at a time.<br/></li></ul><p class="wp-block-paragraph">In programming terms,</p><ul class="wp-block-list"><li><strong>Buffet = List</strong> – Everything is prepared and loaded in memory at once.</li><li><strong>Waiter = Generator</strong> – Items are delivered one by one, only when you ask.<br/></li></ul><p class="wp-block-paragraph">This is <strong>exactly what generators do</strong>, they wait for you to ask for the next value, and then give it.</p><p class="wp-block-paragraph"></p><p class="wp-block-paragraph"></p><h2 class="wp-block-heading">So What is a Generator?</h2><p class="wp-block-paragraph">A <strong>generator</strong> is a special type of Python function that remembers its state and yields values one at a time using the <code>yield</code> keyword.</p><blockquote class="wp-block-quote is-layout-flow wp-block-quote-is-layout-flow"><p class="wp-block-paragraph">From the docs: <a href="https://wiki.python.org/moin/Generators">https://wiki.python.org/moin/Generators</a></p></blockquote><p class="wp-block-paragraph"></p><p class="wp-block-paragraph">This makes them <strong>lazy</strong> (they only compute when needed) and <strong>memory efficient</strong>.</p><p class="wp-block-paragraph"></p><h2 class="wp-block-heading">🛠️ Basic Example – Countdown</h2><p class="wp-block-paragraph">Let’s see a normal function first, </p><pre class="wp-block-syntaxhighlighter-code">def countdown_list(n):    result = []    while n &gt; 0:        result.append(n)        n -= 1    return resultprint(countdown_list(5))  # [5, 4, 3, 2, 1]</pre><p class="wp-block-paragraph"></p><p class="wp-block-paragraph">Now, let’s do the same with a generator, </p><pre class="wp-block-syntaxhighlighter-code">def countdown_gen(n):    while n &gt; 0:        yield n        n -= 1for number in countdown_gen(5):    print(number)</pre><p class="wp-block-paragraph"></p><p class="wp-block-paragraph"><strong>Output</strong></p><pre class="wp-block-syntaxhighlighter-code">54321</pre><p class="wp-block-paragraph">Notice: We <strong>did not return a full list</strong>, but we still got values one by one.</p><p class="wp-block-paragraph"></p><p class="wp-block-paragraph"></p><h2 class="wp-block-heading">⚡ What’s the Benefit?</h2><p class="wp-block-paragraph">Imagine <code>n = 1000000</code>. A normal function stores a <strong>list of 1 million numbers</strong> in memory.</p><p class="wp-block-paragraph">But the generator only <strong>generates one number at a time</strong>, using much less memory.</p><p class="wp-block-paragraph"></p><h2 class="wp-block-heading">🤔 What’s <code>yield</code>?</h2><ul class="wp-block-list"><li>Think of <code>yield</code> like <code>return</code>, but smarter.</li><li>When a function hits <code>yield</code>, it <strong>pauses</strong>.</li><li>The next time you ask for a value, it <strong>resumes from where it left off</strong>.</li></ul><p class="wp-block-paragraph"></p><figure class="wp-block-image size-large"><img alt="" class="wp-image-4522" data-recalc-dims="1" decoding="async" height="803" loading="lazy" src="https://i0.wp.com/parottasalna.com/wp-content/uploads/2025/07/image.png?resize=673%2C803&amp;ssl=1" width="673"/></figure><p class="wp-block-paragraph"></p><h2 class="wp-block-heading">🔁 Behind the Scenes</h2><p class="wp-block-paragraph">You can manually use a generator using the <code>next()</code> function,</p><pre class="wp-block-syntaxhighlighter-code">gen = countdown_gen(3)print(next(gen))  # 3print(next(gen))  # 2print(next(gen))  # 1# print(next(gen))  # Raises StopIteration</pre><p class="wp-block-paragraph"></p><h2 class="wp-block-heading">🧠 Real World Analogy</h2><p class="wp-block-paragraph">Imagine you’re delivering water bottles</p><ul class="wp-block-list"><li>With a list, you carry all 100 bottles at once — heavy and inefficient.</li><li>With a generator, you carry <strong>one bottle at a time</strong> – lighter, scalable.</li></ul><p class="wp-block-paragraph"></p><p class="wp-block-paragraph"></p><h2 class="wp-block-heading">🔍 Use Case – Reading Large Files</h2><p class="wp-block-paragraph">Imagine you’re reading a 2 GB log file. Don’t load the whole thing!</p><p class="wp-block-paragraph">Use a generator to read <strong>line by line</strong>,</p><pre class="wp-block-syntaxhighlighter-code">def read_large_file(file_path):    with open(file_path) as f:        for line in f:            yield linefor log in read_large_file("biglog.txt"):    print(log)</pre><p class="wp-block-paragraph"></p><p class="wp-block-paragraph"></p><p class="wp-block-paragraph">Only one line is loaded at a time. Fast and memory efficient.</p><p class="wp-block-paragraph"></p><h2 class="wp-block-heading">Infinite Sequence Generator</h2><pre class="wp-block-syntaxhighlighter-code">def infinite_counter(start=0):    while True:        yield start        start += 1counter = infinite_counter()print(next(counter))  # 0print(next(counter))  # 1print(next(counter))  # 2</pre><p class="wp-block-paragraph"></p><h2 class="wp-block-heading"><strong>Processing Large Data Streams (Logs, CSV, JSONL, etc.)</strong></h2><p class="wp-block-paragraph">Imagine processing a <strong>1 GB CSV file</strong>. Reading it all at once into memory is dangerous.</p><pre class="wp-block-syntaxhighlighter-code">def read_csv_line_by_line(file_path):    with open(file_path) as f:        for line in f:            yield line.strip().split(',')</pre><p class="wp-block-paragraph">✅ You can now process one row at a time without choking RAM.</p><p class="wp-block-paragraph"></p><p class="wp-block-paragraph"></p><p class="wp-block-paragraph"><strong>Streaming API Responses (e.g., Tweets, Logs, Events)</strong></p><p class="wp-block-paragraph">You can stream paginated or real-time API responses,</p><pre class="wp-block-syntaxhighlighter-code">import requestsdef paginated_fetch(base_url):    page = 1    while True:        resp = requests.get(f"{base_url}?page={page}")        data = resp.json()        if not data:            break        for item in data:            yield item        page += 1</pre><p class="wp-block-paragraph"><br/>✅ Useful for APIs with pagination or streaming endpoints.</p><p class="wp-block-paragraph"></p><h2 class="wp-block-heading">Video Frame Streaming (Using OpenCV)</h2><p class="wp-block-paragraph">Stream video frames for real-time processing,</p><pre class="wp-block-syntaxhighlighter-code">import cv2def video_frame_stream(path):    cap = cv2.VideoCapture(path)    while cap.isOpened():        ret, frame = cap.read()        if not ret:            break        yield frame    cap.release()</pre><p class="wp-block-paragraph"></p><p class="wp-block-paragraph">✅ Helps in object detection, surveillance, or motion tracking systems.</p><p class="wp-block-paragraph"></p><p class="wp-block-paragraph"></p><h2 class="wp-block-heading">🧮 Use Case: Processing Large Datasets with Generators</h2><p class="wp-block-paragraph"></p><p class="wp-block-paragraph"></p><p class="wp-block-paragraph">One of the <strong>most common challenges in data science</strong> is working with datasets that are <strong>too large to fit into memory</strong>.</p><p class="wp-block-paragraph">Instead of loading an entire 10 GB CSV file into a pandas DataFrame (which might crash your system), you can use <strong>generators to process the data line-by-line</strong>, <strong>efficiently</strong> and <strong>incrementally</strong>.</p><p class="wp-block-paragraph"></p><h2 class="wp-block-heading">📊 Scenario</h2><p class="wp-block-paragraph">💼 You have a <strong>10 GB CSV file</strong> of global sales data. You need to filter and process only records from the <strong>“South Asia”</strong> region.</p><p class="wp-block-paragraph"></p><pre class="wp-block-syntaxhighlighter-code"># 🚫 Not recommended for huge filesimport pandas as pddf = pd.read_csv('sales.csv')  # This loads the entire file in memory!</pre><p class="wp-block-paragraph"></p><h2 class="wp-block-heading">✅ Generator Pipeline to the Rescue</h2><p class="wp-block-paragraph"></p><pre class="wp-block-syntaxhighlighter-code">def read_large_csv(file_path):    with open(file_path) as f:        header = next(f).strip().split(',')  # Skip header line        for line in f:            yield dict(zip(header, line.strip().split(',')))def filter_region(rows, region_name):    for row in rows:        if row.get("region") == region_name:            yield rowdef total_sales(rows):    for row in rows:        yield float(row.get("sales", 0.0))# 🔄 Composing the pipelinefile_path = "sales.csv"rows = read_large_csv(file_path)filtered_rows = filter_region(rows, "South Asia")sales_values = total_sales(filtered_rows)# Calculate total sales for the regionprint("Total South Asia Sales:", sum(sales_values))</pre><p class="wp-block-paragraph"></p><h2 class="wp-block-heading">📌 Why is this better?</h2><ul class="wp-block-list"><li>✅ <strong>Memory efficient</strong>: Loads and processes one row at a time.</li><li>✅ <strong>Composable</strong>: Steps are cleanly separated and reusable.</li><li>✅ <strong>Scalable</strong>: Works even with 50 GB+ files.</li></ul><p class="wp-block-paragraph"></p><h2 class="wp-block-heading">Why Generators Are Data Science Friendly</h2><figure class="wp-block-table"><table class="has-fixed-layout"><thead><tr><th>Problem</th><th>Generator Benefit</th></tr></thead><tbody><tr><td>Large CSV/JSON files</td><td>Avoids memory crashes</td></tr><tr><td>ETL pipelines</td><td>Composable, readable, stream-friendly</td></tr><tr><td>Lazy filtering and transformations</td><td>Only processes what’s needed</td></tr><tr><td>Real-time sensor/data ingestion</td><td>Processes data as it arrives</td></tr></tbody></table></figure><p class="wp-block-paragraph"></p><h2 class="wp-block-heading">Stack Overflow Survey – Count Python Developers from India</h2><p class="wp-block-paragraph"><a href="https://colab.research.google.com/drive/1nFqkBu1zb-QPZXGSnNGrgV00CoZjK0Cp?usp=sharing">https://colab.research.google.com/drive/1nFqkBu1zb-QPZXGSnNGrgV00CoZjK0Cp?usp=sharing</a></p>
