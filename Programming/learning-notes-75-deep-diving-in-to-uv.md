Installing UV and Why It Doesn’t Need Python</h2><p class="wp-block-paragraph">UV is a fast Python package manager written in Rust and is a binary, designed to be a drop in replacement for <code>pip</code> and <code>virtualenv</code>.</p><p class="wp-block-paragraph">Since UV is a binary, it does <strong>not</strong> require Python to be installed for its core functionality.</p><p class="wp-block-paragraph"></p><h3 class="wp-block-heading has-medium-font-size" id="1-1-using-a-prebuilt-binary-recommended">1.1 Using a Prebuilt Binary (Recommended)</h3><pre class="wp-block-syntaxhighlighter-code">curl -LsSf https://astral.sh/uv/install.sh | sh</pre><p class="wp-block-paragraph">This installs <code>uv</code> globally on your system.</p><p class="wp-block-paragraph"></p><h3 class="wp-block-heading has-medium-font-size" id="1-2-using-homebrew-macos-linux">1.2 Using Homebrew (macOS &amp; Linux)</h3><pre class="wp-block-syntaxhighlighter-code">brew install astral-sh/uv/uv</pre><p class="wp-block-paragraph"></p><h3 class="wp-block-heading has-medium-font-size" id="1-3-using-cargo-if-you-have-rust-installed">1.3 <strong>Using Cargo (If You Have Rust Installed)</strong></h3><pre class="wp-block-syntaxhighlighter-code">cargo install --locked uv</pre><p class="wp-block-paragraph"></p><h3 class="wp-block-heading has-medium-font-size" id="manual-downloadyou-can-download-the-latest-binary-from-uv-github-releases">1.4 <strong>Manual Download</strong></h3><p class="wp-block-paragraph">You can download the latest binary from <a href="https://github.com/astral-sh/uv/releases">UV GitHub Releases</a>.</p><p class="wp-block-paragraph"></p><h2 class="wp-block-heading has-large-font-size" id="2-managing-python-versions-with-uv">2. id="3-running-python-scripts-with-uv">3. Running Python Scripts with uv</h2><p class="wp-block-paragraph"></p><h3 class="wp-block-heading has-medium-font-size" id="3-1-executing-scripts-without-dependencies">3.1 Executing Scripts Without Dependencies</h3><p class="wp-block-paragraph">For scripts that don’t require external packages, you can run them directly using uv</p><pre class="wp-block-syntaxhighlighter-code"># example.pyprint("Hello, world!")</pre><p class="wp-block-paragraph">Execute the script with</p><pre class="wp-block-syntaxhighlighter-code">uv run example.py</pre><p class="wp-block-paragraph">This command ensures the script runs in an appropriate Python environment managed by uv.</p><p class="wp-block-paragraph"></p><h3 class="wp-block-heading has-medium-font-size" id="3-2-handling-scripts-with-dependencies">3.2 Handling Scripts with Dependencies</h3><p class="wp-block-paragraph">When your script depends on external packages, uv allows you to declare these dependencies within the script itself using inline metadata. This approach eliminates the need for separate environment management tools.</p><p class="wp-block-paragraph">To initialize a script with inline metadata, use</p><pre class="wp-block-syntaxhighlighter-code">uv init --script example.py --python 3.12</pre><p class="wp-block-paragraph">This command adds a metadata block to your script, </p><pre class="wp-block-syntaxhighlighter-code"># /// script# dependencies = [#   "requests&lt;3",#   "rich",# ]# ///import requestsfrom rich.pretty import pprintresponse = requests.get("https://peps.python.org/api/peps.json")data = response.json()pprint([(k, v["title"]) for k, v in data.items()][:10])</pre><p class="wp-block-paragraph">The <code># /// script</code> block specifies the required dependencies. When you run the script, uv automatically creates an isolated environment with these dependencies</p><pre class="wp-block-syntaxhighlighter-code">uv run example.py</pre><p class="wp-block-paragraph"></p><h3 class="wp-block-heading has-medium-font-size" id="3-3-locking-dependencies-for-reproducibility">3.3 Locking Dependencies for Reproducibility</h3><p class="wp-block-paragraph">To ensure consistent behavior across different environments, it’s essential to lock your script’s dependencies. uv supports creating a lockfile for scripts.</p><pre class="wp-block-syntaxhighlighter-code">uv lock --script example.py</pre><p class="wp-block-paragraph">This command generates an <code>example.py.lock</code> file adjacent to your script, capturing the exact versions of the dependencies. Subsequent executions will reference this lockfile, ensuring reproducibility.</p><p class="wp-block-paragraph"></p><h3 class="wp-block-heading has-medium-font-size" id="3-4-specifying-python-versions">3.4 Specifying Python Versions</h3><p class="wp-block-paragraph">uv allows you to specify the Python version required for your script directly within the inline metadata</p><pre class="wp-block-syntaxhighlighter-code"># /// script# python = "3.10"# dependencies = [#   "requests",# ]# ///import requestsprint(requests.__version__)</pre><p class="wp-block-paragraph">Alternatively, you can specify the Python version at runtime</p><pre class="wp-block-syntaxhighlighter-code">uv run --python 3.10 example.py</pre><p class="wp-block-paragraph">This flexibility ensures your script runs with the intended Python interpreter.</p><p class="wp-block-paragraph"></p><h3 class="wp-block-heading has-medium-font-size" id="3-5-using-alternative-package-indexes">3.5 Using Alternative Package Indexes</h3><p class="wp-block-paragraph">If your dependencies are hosted on a custom package index, uv allows you to specify this in the inline metadata.</p><pre class="wp-block-syntaxhighlighter-code"># /// script# dependencies = [#   "custom-package",# ]# [tool.uv.index]# url = "https://example.com/simple"# ///</pre><p class="wp-block-paragraph">Alternatively, you can add the index via the command line</p><pre class="wp-block-syntaxhighlighter-code">uv add --index "https://example.com/simple" --script example.py 'custom-package'</pre><p class="wp-block-paragraph">This ensures uv resolves dependencies using the specified package index.</p><p class="wp-block-paragraph"></p><h2 class="wp-block-heading has-large-font-size" id="4-running-tools-with-uvx-in-uv">4. Running Tools with <code>uvx</code> in UV</h2><p class="wp-block-paragraph"><code>uvx</code> is a command within UV that runs Python tools in an isolated environment, handling dependencies automatically. This is particularly useful for running CLI-based Python tools without globally installing them or creating separate virtual environments.</p><p class="wp-block-paragraph"></p><h3 class="wp-block-heading has-medium-font-size" id="key-advantages-of-uvx">Key Advantages of <code>uvx</code></h3><ul class="wp-block-list"><li><strong>No Virtualenv Setup Required</strong>: <code>uvx</code> handles isolation automatically.</li><li><strong>Fast and Efficient</strong>: Uses UV’s dependency resolution, making it faster than pip-based approaches.</li><li><strong>Reproducible Environments</strong>: Ensures tools run with the correct dependencies every time.</li></ul><p class="wp-block-paragraph"></p><h3 class="wp-block-heading has-medium-font-size" id="4-1-running-a-one-time-command">4.1 Running a One-Time Command</h3><p class="wp-block-paragraph">Instead of manually installing a package globally, you can use <code>uvx</code> to run it in an isolated environment. For example, to run <code>black</code> (a Python code formatter)</p><pre class="wp-block-syntaxhighlighter-code">uvx black --version</pre><p class="wp-block-paragraph">If <code>black</code> isn’t installed, <code>uvx</code> will fetch and execute it automatically.</p><p class="wp-block-paragraph"></p><h3 class="wp-block-heading has-medium-font-size" id="4-2-running-tools-with-arguments">4.2 Running Tools with Arguments</h3><p class="wp-block-paragraph">You can pass arguments just like you would with a normally installed package. For instance, formatting a Python file</p><pre class="wp-block-syntaxhighlighter-code">uvx black my_script.py</pre><p class="wp-block-paragraph"></p><h3 class="wp-block-heading has-medium-font-size" id="4-3-running-multiple-commands">4.3 Running Multiple Commands</h3><p class="wp-block-paragraph">You can use <code>uvx</code> to run multiple commands without installing them globally</p><pre class="wp-block-syntaxhighlighter-code">uvx isort my_script.pyuvx ruff check my_script.py</pre><p class="wp-block-paragraph"></p><h3 class="wp-block-heading has-medium-font-size" id="4-4-using-uvx-in-a-project">4.4 Using <code>uvx</code> in a Project</h3><p class="wp-block-paragraph">If you have a project requiring multiple tools (like <code>pytest</code>, <code>ruff</code>, and <code>black</code>), instead of installing them globally, you can</p><pre class="wp-block-syntaxhighlighter-code">uvx pytest tests/uvx black .uvx ruff check .</pre><p class="wp-block-paragraph">This keeps your development workflow clean and avoids dependency conflicts.</p><p class="wp-block-paragraph"></p><p class="wp-block-paragraph"></p><h2 class="wp-block-heading has-large-font-size" id="5-manage-python-projects-with-uv">5. Manage Python projects with UV</h2><h3 class="wp-block-heading has-medium-font-size" id="5-1-setting-up-a-new-project">5.1 Setting Up a New Project</h3><p class="wp-block-paragraph">You can create a fresh Python project with <code>uv</code> using the <code>uv init</code> command</p><pre class="wp-block-syntaxhighlighter-code">uv init my-projectcd my-project</pre><p class="wp-block-paragraph">Alternatively, if you already have a directory, you can initialize the project there</p><pre class="wp-block-syntaxhighlighter-code">mkdir my-projectcd my-projectuv init</pre><p class="wp-block-paragraph">Once initialized, <code>uv</code> generates the following files</p><pre class="wp-block-syntaxhighlighter-code">.├── .python-version├── README.md├── main.py└── pyproject.toml</pre><p class="wp-block-paragraph">The <code>main.py</code> file contains a basic “Hello, World!” script, which you can execute with:</p><pre class="wp-block-syntaxhighlighter-code">uv run main.py</pre><h3 class="wp-block-heading has-medium-font-size" id="5-2-project-structure">5.2 Project Structure</h3><p class="wp-block-paragraph">A <code>uv</code>-managed project consists of several key components. Along with the files created during initialization, <code>uv</code> also sets up a virtual environment and a lockfile (<code>uv.lock</code>) the first time you run a command such as <code>uv run</code>, <code>uv sync</code>, or <code>uv lock</code>.</p><p class="wp-block-paragraph">Here’s what a complete project structure looks like:</p><pre class="wp-block-syntaxhighlighter-code">.├── .venv│   ├── bin│   ├── lib│   └── pyvenv.cfg├── .python-version├── README.md├── main.py├── pyproject.toml└── uv.lock</pre><h3 class="wp-block-heading has-medium-font-size" id="5-2-understanding-key-files">5.2 Understanding Key Files</h3><h4 class="wp-block-heading" id="pyproject-toml"><code>pyproject.toml</code></h4><p class="wp-block-paragraph">This file stores metadata about your project, including its name, version, description, and dependencies:</p><pre class="wp-block-syntaxhighlighter-code">[project]name = "my-project"version = "0.1.0"description = "Your project description here"readme = "README.md"dependencies = []</pre><p class="wp-block-paragraph">You can manually update this file or use <code>uv</code> commands like <code>uv add</code> and <code>uv remove</code> to manage dependencies more easily.<br/></p><h4 class="wp-block-heading" id="python-version"><code>.python-version</code></h4><p class="wp-block-paragraph">This file specifies the Python version that <code>uv</code> should use when creating the virtual environment.<br/></p><h4 class="wp-block-heading" id="venv"><code>.venv</code></h4><p class="wp-block-paragraph">The <code>.venv</code> directory contains an isolated Python environment where <code>uv</code> installs project dependencies, ensuring separation from system-wide packages.<br/></p><h4 class="wp-block-heading" id="uv-lock"><code>uv.lock</code></h4><p class="wp-block-paragraph">This lockfile ensures reproducible builds by storing exact dependency versions. Unlike <code>pyproject.toml</code>, which specifies broad requirements, <code>uv.lock</code> contains precise versions installed in the environment. It should be committed to version control.<br/></p><h3 class="wp-block-heading has-medium-font-size" id="5-3-managing-dependencies">5.3 Managing Dependencies</h3><p class="wp-block-paragraph">You can install dependencies with the <code>uv add</code> command</p><pre class="wp-block-syntaxhighlighter-code">uv add requests</pre><p class="wp-block-paragraph">To specify a version or install from an alternate source</p><pre class="wp-block-syntaxhighlighter-code"># Install a specific versionuv add 'requests==2.31.0'# Install directly from a Git repositoryuv add git+https://github.com/psf/requests</pre><p class="wp-block-paragraph">To remove a package</p><pre class="wp-block-syntaxhighlighter-code">uv remove requests</pre><p class="wp-block-paragraph">To upgrade a specific package while keeping the rest of the environment stable</p><pre class="wp-block-syntaxhighlighter-code">uv lock --upgrade-package requests</pre><h3 class="wp-block-heading has-medium-font-size" id="5-4-running-commands">5.4 Running Commands</h3><p class="wp-block-paragraph">Use <code>uv run</code> to execute scripts or commands within the project environment. Before running, <code>uv</code> ensures that the lockfile and environment are synchronized.</p><p class="wp-block-paragraph">Example: Running a Flask server on port 3000</p><pre class="wp-block-syntaxhighlighter-code">uv add flaskuv run -- flask run -p 3000</pre><p class="wp-block-paragraph">To run a Python script using project dependencies</p><pre class="wp-block-syntaxhighlighter-code"># example.pyimport flaskprint("Hello, World!")</pre><p class="wp-block-paragraph">Execute it with</p><pre class="wp-block-syntaxhighlighter-code">uv run example.py</pre><p class="wp-block-paragraph">Alternatively, update the environment manually with <code>uv sync</code>, then activate it before running commands.</p><p class="wp-block-paragraph"></p><h2 class="wp-block-heading has-large-font-size" id="6-how-uv-lock-works">6. How <code>uv.lock</code> Works</h2><p class="wp-block-paragraph">When you execute <code>uv resolve</code>, UV interacts with package indexes (such as PyPI) to find compatible versions of the requested dependencies.</p><p class="wp-block-paragraph">It then computes a resolution graph, ensuring that all dependencies are satisfied without conflicts. The resolved versions are stored in <code>uv.lock</code> in a structured format, which UV can later use to install the exact same versions efficiently.</p><p class="wp-block-paragraph">The <code>uv.lock</code> file contains</p><ul class="wp-block-list"><li><strong>Package Name</strong>: The name of the dependency.</li><li><strong>Exact Version</strong>: The resolved version pinned for consistency.</li><li><strong>Hashes</strong>: Cryptographic hashes for verifying the integrity of downloaded packages.</li><li><strong>Dependency Tree</strong>: A structured list of direct and transitive dependencies.</li><li><strong>Metadata</strong>: Additional details about the resolution process.<br/></li></ul><h2 class="wp-block-heading has-large-font-size" id="7-how-uv-lock-differs-from-other-lock-files">7. How <code>uv.lock</code> Differs from Other Lock Files</h2><p class="wp-block-paragraph"></p><h3 class="wp-block-heading has-medium-font-size" id="comparison-with-pip-s-requirements-txt">Comparison with Pip’s <code>requirements.txt</code></h3><ul class="wp-block-list"><li><code>requirements.txt</code> is often manually created and lacks strict version pinning unless explicitly specified.</li><li><code>uv.lock</code> ensures precise dependency resolution, making installations fully deterministic.</li><li><code>requirements.txt</code> does not store dependency hashes by default, whereas <code>uv.lock</code> includes them for security.</li></ul><p class="wp-block-paragraph"></p><h3 class="wp-block-heading has-medium-font-size" id="comparison-with-poetry-s-poetry-lock">Comparison with Poetry’s <code>poetry.lock</code></h3><ul class="wp-block-list"><li><code>poetry.lock</code> is used in Poetry-based projects, but dependency resolution can be slow.</li><li>UV optimizes dependency resolution, making <code>uv.lock</code> generation significantly faster.</li><li><code>uv.lock</code> is designed to work efficiently with both pip-based and UV-based workflows.</li></ul><p class="wp-block-paragraph"></p><h3 class="wp-block-heading has-medium-font-size" id="comparison-with-conda-s-environment-yml">Comparison with Conda’s <code>environment.yml</code></h3><ul class="wp-block-list"><li><code>environment.yml</code> is YAML-based and includes additional metadata for Conda environments.</li><li><code>uv.lock</code> focuses purely on Python dependencies and offers faster resolution.</li><li>Conda environments often include system-level dependencies, whereas <code>uv.lock</code> strictly manages Python packages.</li></ul><p class="wp-block-paragraph"></p><h2 class="wp-block-heading has-large-font-size" id="8-how-to-use-uv-lock">8. How to Use <code>uv.lock</code></h2><h3 class="wp-block-heading has-medium-font-size" id="1-generating-uv-lock">1. Generating <code>uv.lock</code></h3><p class="wp-block-paragraph">To generate a <code>uv.lock</code> file, run the following command</p><pre class="wp-block-syntaxhighlighter-code">uv resolve -o uv.lock</pre><p class="wp-block-paragraph">This will create or update the <code>uv.lock</code> file with the resolved dependencies, ensuring consistency across installations.</p><p class="wp-block-paragraph"></p><h3 class="wp-block-heading has-medium-font-size" id="2-installing-dependencies-from-uv-lock">2. Installing Dependencies from <code>uv.lock</code></h3><p class="wp-block-paragraph">Once the lock file is created, you can install dependencies from it using</p><pre class="wp-block-syntaxhighlighter-code">uv pip sync uv.lock</pre><p class="wp-block-paragraph">This ensures all dependencies are installed in a deterministic manner without deviations from the locked versions.</p><p class="wp-block-paragraph"></p><h3 class="wp-block-heading has-medium-font-size" id="3-updating-dependencies">3. Updating Dependencies</h3><p class="wp-block-paragraph">To update dependencies and regenerate the <code>uv.lock</code> file, use</p><pre class="wp-block-syntaxhighlighter-code">uv resolve --update -o uv.lock</pre><p class="wp-block-paragraph">This will attempt to fetch newer compatible versions while preserving package stability.</p><p class="wp-block-paragraph"></p><h3 class="wp-block-heading has-medium-font-size" id="4-verifying-dependency-integrity">4. Verifying Dependency Integrity</h3><p class="wp-block-paragraph">Since <code>uv.lock</code> includes cryptographic hashes, you can verify the integrity of installed dependencies by running</p><pre class="wp-block-syntaxhighlighter-code">uv verify uv.lock</pre><p class="wp-block-paragraph">This ensures that all installed packages match the recorded hashes, preventing tampering or corruption.</p><p class="wp-block-paragraph"></p><h2 class="wp-block-heading has-large-font-size" id="9-why-use-uv-lock">9. Why Use <code>uv.lock</code>?</h2><h3 class="wp-block-heading has-medium-font-size" id="1-faster-dependency-resolution">1. Faster Dependency Resolution</h3><p class="wp-block-paragraph">UV is optimized for speed, making <code>uv.lock</code> generation and dependency installation significantly faster than Pip and Poetry.</p><h3 class="wp-block-heading has-medium-font-size" id="2-deterministic-installs">2. Deterministic Installs</h3><p class="wp-block-paragraph">Ensuring that every developer and CI/CD pipeline installs the exact same dependencies reduces inconsistencies.</p><h3 class="wp-block-heading has-medium-font-size" id="3-better-compatibility">3. Better Compatibility</h3><p class="wp-block-paragraph">Unlike <code>requirements.txt</code>, <code>uv.lock</code> captures all transitive dependencies, reducing unexpected version conflicts.</p><h3 class="wp-block-heading has-medium-font-size" id="4-enhanced-security">4. Enhanced Security</h3><p class="wp-block-paragraph">Including hashes in <code>uv.lock</code> ensures that dependencies cannot be tampered with, adding an extra layer of security.</p><h3 class="wp-block-heading has-medium-font-size" id="5-efficient-ci-cd-workflows">5. Efficient CI/CD Workflows</h3><p class="wp-block-paragraph">By using <code>uv.lock</code>, continuous integration (CI) pipelines can reliably install dependencies without unexpected version shifts, leading to stable builds.</p><p class="wp-block-paragraph"></p>
