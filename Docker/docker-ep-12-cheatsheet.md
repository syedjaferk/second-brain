<p class="wp-block-paragraph">Here’s a Docker cheat sheet that covers the most commonly used Docker commands, organized by categories.</p><h3 class="wp-block-heading"><strong>Docker Basics</strong></h3><ul class="wp-block-list"><li><strong><code>docker --version</code></strong>: Show the Docker version installed on your system.</li><li><strong><code>docker info</code></strong>: Display system-wide information, including Docker version, number of containers, and images.</li><li><strong><code>docker help</code></strong>: Get help on Docker commands.</li></ul><h3 class="wp-block-heading"><strong>Docker Images</strong></h3><ul class="wp-block-list"><li><strong><code>docker images</code></strong>: List all Docker images on your system.</li><li><strong><code>docker pull &lt;image&gt;</code></strong>: Download an image from a Docker registry (e.g., Docker Hub).</li><li><strong><code>docker build -t &lt;image_name&gt; .</code></strong>: Build an image from a Dockerfile in the current directory and tag it with a name.</li><li><strong><code>docker tag &lt;image_id&gt; &lt;new_image_name&gt;</code></strong>: Tag an image with a new name.</li><li><strong><code>docker rmi &lt;image&gt;</code></strong>: Remove one or more images.</li><li><strong><code>docker history &lt;image&gt;</code></strong>: Show the history of an image (layers).</li></ul><h3 class="wp-block-heading"><strong>Docker Containers</strong></h3><ul class="wp-block-list"><li><strong><code>docker ps</code></strong>: List all running containers.</li><li><strong><code>docker ps -a</code></strong>: List all containers (running and stopped).</li><li><strong><code>docker run &lt;image&gt;</code></strong>: Run a container from an image.</li><li><strong><code>docker run -d &lt;image&gt;</code></strong>: Run a container in detached mode (in the background).</li><li><strong><code>docker run -it &lt;image&gt;</code></strong>: Run a container in interactive mode with a terminal.</li><li><strong><code>docker run -p &lt;host_port&gt;:&lt;container_port&gt; &lt;image&gt;</code></strong>: Map a port from the host to the container.</li><li><strong><code>docker stop &lt;container&gt;</code></strong>: Stop a running container.</li><li><strong><code>docker start &lt;container&gt;</code></strong>: Start a stopped container.</li><li><strong><code>docker restart &lt;container&gt;</code></strong>: Restart a running container.</li><li><strong><code>docker rm &lt;container&gt;</code></strong>: Remove a stopped container.</li><li><strong><code>docker logs &lt;container&gt;</code></strong>: View the logs of a container.</li><li><strong><code>docker exec -it &lt;container&gt; &lt;command&gt;</code></strong>: Execute a command inside a running container (e.g., <code>bash</code> to open a shell).</li></ul><h3 class="wp-block-heading"><strong>Docker Networks</strong></h3><ul class="wp-block-list"><li><strong><code>docker network ls</code></strong>: List all Docker networks.</li><li><strong><code>docker network create &lt;network_name&gt;</code></strong>: Create a new Docker network.</li><li><strong><code>docker network inspect &lt;network_name&gt;</code></strong>: View detailed information about a network.</li><li><strong><code>docker network connect &lt;network_name&gt; &lt;container&gt;</code></strong>: Connect a container to a network.</li><li><strong><code>docker network disconnect &lt;network_name&gt; &lt;container&gt;</code></strong>: Disconnect a container from a network.</li><li><strong><code>docker network rm &lt;network_name&gt;</code></strong>: Remove a Docker network.</li></ul><h3 class="wp-block-heading"><strong>Docker Volumes</strong></h3><ul class="wp-block-list"><li><strong><code>docker volume ls</code></strong>: List all Docker volumes.</li><li><strong><code>docker volume create &lt;volume_name&gt;</code></strong>: Create a new Docker volume.</li><li><strong><code>docker volume inspect &lt;volume_name&gt;</code></strong>: View detailed information about a volume.</li><li><strong><code>docker volume rm &lt;volume_name&gt;</code></strong>: Remove a Docker volume.</li><li><strong><code>docker run -v &lt;volume_name&gt;:&lt;container_path&gt; &lt;image&gt;</code></strong>: Mount a volume inside a container.</li></ul><h3 class="wp-block-heading"><strong>Docker Compose</strong></h3><ul class="wp-block-list"><li><strong><code>docker-compose up</code></strong>: Start the services defined in a <code>docker-compose.yml</code> file.</li><li><strong><code>docker-compose down</code></strong>: Stop and remove containers, networks, volumes, and images created by <code>docker-compose up</code>.</li><li><strong><code>docker-compose build</code></strong>: Build or rebuild services defined in a <code>docker-compose.yml</code> file.</li><li><strong><code>docker-compose ps</code></strong>: List containers managed by Docker Compose.</li><li><strong><code>docker-compose logs</code></strong>: View logs for services managed by Docker Compose.</li><li><strong><code>docker-compose exec &lt;service&gt; &lt;command&gt;</code></strong>: Execute a command in a running service.</li></ul><h3 class="wp-block-heading"><strong>Dockerfile Directives</strong></h3><ul class="wp-block-list"><li><strong><code>FROM</code></strong>: Specifies the base image.</li><li><strong><code>WORKDIR</code></strong>: Sets the working directory inside the container.</li><li><strong><code>COPY</code></strong>: Copies files from the host to the container.</li><li><strong><code>RUN</code></strong>: Executes a command in the container.</li><li><strong><code>CMD</code></strong>: Specifies the command to run when the container starts.</li><li><strong><code>EXPOSE</code></strong>: Specifies the port on which the container will listen.</li><li><strong><code>ENV</code></strong>: Sets environment variables.</li><li><strong><code>ENTRYPOINT</code></strong>: Configures the container to run as an executable.</li></ul><h3 class="wp-block-heading"><strong>Docker Cleanup Commands</strong></h3><ul class="wp-block-list"><li><strong><code>docker system prune</code></strong>: Remove unused data (stopped containers, unused networks, dangling images, etc.).</li><li><strong><code>docker container prune</code></strong>: Remove all stopped containers.</li><li><strong><code>docker image prune</code></strong>: Remove unused images.</li><li><strong><code>docker volume prune</code></strong>: Remove all unused volumes.</li><li><strong><code>docker network prune</code></strong>: Remove all unused networks.</li></ul><h3 class="wp-block-heading"><strong>Miscellaneous</strong></h3><ul class="wp-block-list"><li><strong><code>docker inspect &lt;container_or_image&gt;</code></strong>: Return low-level information on Docker objects (containers, images, volumes, etc.).</li><li><strong><code>docker stats</code></strong>: Display a live stream of container(s) resource usage statistics.</li><li><strong><code>docker top &lt;container&gt;</code></strong>: Display the running processes of a container.</li><li><strong><code>docker cp &lt;container&gt;:&lt;path&gt; &lt;local_path&gt;</code></strong>: Copy files from a container to the host or vice versa.</li></ul>
