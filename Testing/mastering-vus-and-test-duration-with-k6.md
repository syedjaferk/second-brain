class="wp-block-heading" id="defining-vus-and-duration-in-k6">Defining VUs and Duration in K6</h2><p class="wp-block-paragraph">K6 offers multiple ways to define VUs and test duration, primarily through options in the test script or the command line.</p><p class="wp-block-paragraph"></p><h2 class="wp-block-heading" id="basic-vu-and-duration-configuration">Basic VU and Duration Configuration</h2><p class="wp-block-paragraph">The simplest way to specify VUs and test duration is by setting them in the <code>options</code> object of your test script. </p><pre class="wp-block-syntaxhighlighter-code">import http from 'k6/http';import { sleep } from 'k6';export const options = {  vus: 10, // Number of virtual users  duration: '30s', // Duration of the test};export default function () {  http.get('https://test.k6.io/');  sleep(1);}</pre><p class="wp-block-paragraph">This script runs a load test with 10 virtual users for 30 seconds, making requests to the specified URL.</p><p class="wp-block-paragraph"></p><h2 class="wp-block-heading" id="specifying-vus-and-duration-from-the-command-line">Specifying VUs and Duration from the Command Line</h2><p class="wp-block-paragraph">You can also set the VUs and duration dynamically using command-line arguments without modifying the script. </p><pre class="wp-block-syntaxhighlighter-code">k6 run --vus 20 --duration 1m script.js</pre><p class="wp-block-paragraph">This command runs the test with 20 virtual users for 1 minute.</p><p class="wp-block-paragraph"></p><h2 class="wp-block-heading" id="ramp-up-and-ramp-down-with-stages">Ramp Up and Ramp Down with Stages</h2><p class="wp-block-paragraph">Instead of a fixed number of VUs, you can simulate user load variations over time using <code>stages</code>. This helps to gradually increase or decrease the load on the system.</p><pre class="wp-block-syntaxhighlighter-code">export const options = {  stages: [    { duration: '30s', target: 10 }, // Ramp up to 10 VUs    { duration: '1m', target: 50 },  // Ramp up to 50 VUs    { duration: '30s', target: 10 }, // Ramp down to 10 VUs    { duration: '20s', target: 0 },  // Ramp down to 0 VUs  ],};</pre><p class="wp-block-paragraph">This test gradually increases the load, sustains it, and then reduces it, simulating real-world traffic patterns.</p><p class="wp-block-paragraph"></p><h2 class="wp-block-heading" id="custom-execution-scenarios">Custom Execution Scenarios</h2><p class="wp-block-paragraph">For more advanced load testing strategies, K6 supports <code>scenarios</code>, allowing fine-grained control over execution behavior.</p><p class="wp-block-paragraph"></p><h3 class="wp-block-heading has-medium-font-size" id="syntax-of-custom-execution-scenarios">Syntax of Custom Execution Scenarios</h3><p class="wp-block-paragraph">A <code>scenarios</code> object defines different execution strategies. Each scenario consists of</p><ul class="wp-block-list"><li><strong>executor</strong>: Defines how the test runs (e.g., <code>ramping-vus</code>, <code>constant-arrival-rate</code>, etc.).</li><li><strong>vus</strong>: Number of virtual users (for certain executors).</li><li><strong>duration</strong>: How long the scenario runs.</li><li><strong>iterations</strong>: Total number of iterations per VU (for certain executors).</li><li><strong>stages</strong>: Used in <code>ramping-vus</code> to define load variations over time.</li><li><strong>rate</strong>: Defines the number of iterations per time unit in <code>constant-arrival-rate</code>.</li><li><strong>preAllocatedVUs</strong>: Number of VUs reserved for the test.</li></ul><p class="wp-block-paragraph"></p><h3 class="wp-block-heading has-medium-font-size" id="different-executors-in-k6">Different Executors in K6</h3><p class="wp-block-paragraph">K6 provides several executors that define how virtual users (VUs) generate load</p><ol class="wp-block-list" start="1"><li><code><strong>shared-iterations</strong></code> – Distributes a fixed number of iterations across multiple VUs.</li><li><code><strong>per-vu-iterations</strong></code> – Each VU runs a specific number of iterations independently.</li><li><code><strong>constant-vus</strong></code> – Maintains a fixed number of VUs for a set duration.</li><li><code><strong>ramping-vus</strong></code> – Increases or decreases the number of VUs over time.</li><li><code><strong>constant-arrival-rate</strong></code> – Ensures a constant number of requests per time unit, independent of VUs.</li><li><code><strong>ramping-arrival-rate</strong></code> – Gradually increases or decreases the request rate over time.</li><li><code><strong>externally-controlled</strong></code> – Allows dynamic control of VUs via an external API.</li></ol><p class="wp-block-paragraph"></p><h3 class="wp-block-heading has-medium-font-size" id="example-ramping-vus-scenario">Example: Ramping VUs Scenario</h3><pre class="wp-block-syntaxhighlighter-code">export const options = {  scenarios: {    ramping_users: {      executor: 'ramping-vus',      startVUs: 0,      stages: [        { duration: '30s', target: 20 },        { duration: '1m', target: 100 },        { duration: '30s', target: 0 },      ],    },  },};export default function () {  http.get('https://test-api.example.com');  sleep(1);}</pre><p class="wp-block-paragraph"></p><h3 class="wp-block-heading has-medium-font-size" id="example-constant-arrival-rate-scenario">Example: Constant Arrival Rate Scenario</h3><pre class="wp-block-syntaxhighlighter-code">export const options = {  scenarios: {    constant_request_rate: {      executor: 'constant-arrival-rate',      rate: 50, // 50 iterations per second      timeUnit: '1s', // Per second      duration: '1m', // Test duration      preAllocatedVUs: 20, // Number of VUs to allocate    },  },};export default function () {  http.get('https://test-api.example.com');  sleep(1);}</pre><p class="wp-block-paragraph"></p><h3 class="wp-block-heading has-medium-font-size" id="example-per-vu-iteration-scenario">Example: Per VU Iteration Scenario</h3><pre class="wp-block-syntaxhighlighter-code">export const options = {  scenarios: {    per_vu_iterations: {      executor: 'per-vu-iterations',      vus: 10,      iterations: 50, // Each VU executes 50 iterations      maxDuration: '1m',    },  },};export default function () {  http.get('https://test-api.example.com');  sleep(1);}</pre><p class="wp-block-paragraph"></p><h2 class="wp-block-heading" id="choosing-the-right-configuration">Choosing the Right Configuration</h2><ul class="wp-block-list"><li>Use <strong>fixed VUs and duration</strong> for simple, constant load testing.</li><li>Use <strong>stages</strong> for ramping up and down load gradually.</li><li>Use <strong>scenarios</strong> for more complex and controlled testing setups.</li></ul><p class="wp-block-paragraph"></p><p class="wp-block-paragraph"></p><h2 class="wp-block-heading" id="references">References</h2><ol
