<p class="wp-block-paragraph">Locust is an excellent load testing tool, enabling developers to simulate concurrent user traffic on their applications. One of its powerful features is <strong>wait times</strong>, which simulate the realistic user think time between consecutive tasks. By customizing wait times, you can emulate user behavior more effectively, making your tests reflect actual usage patterns.</p><p class="wp-block-paragraph">In this blog, we’ll cover,</p><ol class="wp-block-list"><li>What wait times are in Locust.</li><li>Built-in wait time options.</li><li>Creating custom wait times.</li><li>A full example with instructions to run the test.</li></ol><h3 class="wp-block-heading">What Are Wait Times in Locust?</h3><p class="wp-block-paragraph">In real-world scenarios, users don’t interact with applications continuously. After performing an action (e.g., submitting a form), they often pause before the next action. This pause is called a <strong>wait time</strong> in Locust, and it plays a crucial role in mimicking real-life user behavior.</p><p class="wp-block-paragraph">Locust provides several ways to define these wait times within your test scenarios.</p><h3 class="wp-block-heading">FastAPI App Overview</h3><p class="wp-block-paragraph">Here’s the FastAPI app that we’ll test,</p><pre class="wp-block-syntaxhighlighter-code">from fastapi import FastAPI# Create a FastAPI app instanceapp = FastAPI()# Define a route with a GET method@app.get("/")def read_root():    return {"message": "Welcome to FastAPI!"}@app.get("/items/{item_id}")def read_item(item_id: int, q: str = None):    return {"item_id": item_id, "q": q}</pre><h3 class="wp-block-heading">Locust Examples for FastAPI</h3><h4 class="wp-block-heading">1. Constant Wait Time Example</h4><p class="wp-block-paragraph">Here, we’ll simulate constant pauses between user requests</p><pre class="wp-block-syntaxhighlighter-code">from locust import HttpUser, task, constantclass FastAPIUser(HttpUser):    wait_time = constant(2)  # Wait for 2 seconds between requests    @task    def get_root(self):        self.client.get("/")  # Simulates a GET request to the root endpoint    @task    def get_item(self):        self.client.get("/items/42?q=test")  # Simulates a GET request with path and query parameters</pre><h4 class="wp-block-heading">2. Between wait time Example</h4><p class="wp-block-paragraph">Simulating random pauses between requests.</p><pre class="wp-block-syntaxhighlighter-code">from locust import HttpUser, task, betweenclass FastAPIUser(HttpUser):    wait_time = between(1, 5)  # Random wait time between 1 and 5 seconds    @task(3)  # Weighted task: this runs 3 times more often    def get_root(self):        self.client.get("/")    @task(1)    def get_item(self):        self.client.get("/items/10?q=locust")</pre><h4 class="wp-block-heading">3. Custom Wait Time Example</h4><p class="wp-block-paragraph">Using a custom wait time function to introduce more complex user behavior</p><pre class="wp-block-syntaxhighlighter-code">import randomfrom locust import HttpUser, taskdef custom_wait():    return max(1, random.normalvariate(3, 1))  # Normal distribution (mean: 3s, stddev: 1s)class FastAPIUser(HttpUser):    wait_time = custom_wait    @task    def get_root(self):        self.client.get("/")    @task    def get_item(self):        self.client.get("/items/99?q=custom")</pre><h3 class="wp-block-heading">Full Test Example</h3><p class="wp-block-paragraph">Combining all the above elements, here’s a complete Locust test for your FastAPI app.</p><pre class="wp-block-syntaxhighlighter-code">from locust import HttpUser, task, betweenimport random# Custom wait time functiondef custom_wait():    return max(1, random.uniform(1, 3))  # Random wait time between 1 and 3 secondsclass FastAPIUser(HttpUser):    wait_time = custom_wait  # Use the custom wait time    @task(3)    def browse_homepage(self):        """Simulates browsing the root endpoint."""        self.client.get("/")    @task(1)    def browse_item(self):        """Simulates fetching an item with ID and query parameter."""        item_id = random.randint(1, 100)        self.client.get(f"/items/{item_id}?q=test")</pre><p class="wp-block-paragraph"></p><p class="wp-block-paragraph"></p><h3 class="wp-block-heading">Running Locust for FastAPI</h3><ol class="wp-block-list"><li><strong>Run Your FastAPI App</strong><br/>Save the FastAPI app code in a file (e.g., <code>main.py</code>) and start the server</li></ol><pre class="wp-block-syntaxhighlighter-code">uvicorn main:app --reload</pre><p class="wp-block-paragraph">By default, the app will run on <code>http://127.0.0.1:8000</code>.</p><p class="wp-block-paragraph">2. <strong>Run Locust</strong><br/>Save the Locust file as <code>locustfile.py</code> and start Locust.</p><pre class="wp-block-syntaxhighlighter-code">locust -f locustfile.py</pre><p class="wp-block-paragraph">3. <strong>Configure Locust</strong><br/>Open <a data-proofer-ignore="" href="#">http://localhost:8089</a> in your browser and enter:</p><ul class="wp-block-list"><li><strong>Host</strong>: <code>http://127.0.0.1:8000</code></li><li><strong>Number of users</strong> and <strong>spawn rate</strong> based on your testing requirements.</li></ul><p class="wp-block-paragraph"><strong>4. Run in Headless Mode</strong> (Optional)<br/>Use the following command to run Locust in headless mode</p><pre class="wp-block-syntaxhighlighter-code">locust -f locustfile.py --headless -u 50 -r 10 --host http://127.0.0.1:8000`</pre><p class="wp-block-paragraph"><code>-u 50</code>: Simulate 50 users.</p><p class="wp-block-paragraph"><code>-r 10</code>: Spawn 10 users per second.</p><p class="wp-block-paragraph"></p>
