<p class="wp-block-paragraph"></p><p class="wp-block-paragraph"><strong>IndexedDB</strong> is a powerful client-side database API for storing structured data in browsers. However, its API is complex, requiring transactions, object stores, and cursors to manage data. <strong>LocalBase</strong> simplifies IndexedDB by providing an intuitive, promise-based API.</p><p class="wp-block-paragraph">In this blog, we’ll explore <strong>LocalBase</strong>, its features, and how to use it effectively in web applications.</p><p class="wp-block-paragraph"></p><h2 class="wp-block-heading has-large-font-size"><strong>What is LocalBase?</strong></h2><p class="wp-block-paragraph"><a href="https://github.com/samuk190/localbase">LocalBase</a> is an easy-to-use JavaScript library that simplifies IndexedDB interactions. It provides a syntax similar to Firestore, making it ideal for developers familiar with Firebase.</p><p class="wp-block-paragraph">✅ <strong>Key Features</strong></p><ul class="wp-block-list"><li>Promise based API</li><li>Simple CRUD operations</li><li>No need for manual transaction handling</li><li>Works seamlessly in modern browsers</li></ul><p class="wp-block-paragraph"></p><h2 class="wp-block-heading has-large-font-size"><strong>Installation</strong></h2><p class="wp-block-paragraph">You can install LocalBase via npm or use it directly in a script tag</p><p class="wp-block-paragraph"></p><h3 class="wp-block-heading has-medium-font-size"><strong>Using npm</strong></h3><pre class="wp-block-syntaxhighlighter-code">npm install localbase</pre><p class="wp-block-paragraph"></p><p class="wp-block-paragraph"><strong>Using CDN</strong></p><pre class="wp-block-syntaxhighlighter-code">https://cdn.jsdelivr.net/npm/localbase/dist/localbase.min.js</pre><p class="wp-block-paragraph"></p><h2 class="wp-block-heading has-large-font-size"><strong>Getting Started with LocalBase</strong></h2><p class="wp-block-paragraph">First, initialize the database</p><pre class="wp-block-syntaxhighlighter-code">let db = new Localbase('myDatabase')</pre><pre class="wp-block-preformatted"></pre><h3 class="wp-block-heading has-medium-font-size"><strong>Adding Data</strong></h3><p class="wp-block-paragraph">You can add records to a collection,</p><pre class="wp-block-syntaxhighlighter-code">db.collection('users').add({  id: 1,  name: 'John Doe',  age: 30})</pre><p class="wp-block-paragraph"></p><h3 class="wp-block-heading has-medium-font-size"><strong>Fetching Data</strong></h3><p class="wp-block-paragraph">Retrieve all records from a collection </p><pre class="wp-block-syntaxhighlighter-code">db.collection('users').get().then(users =&gt; {  console.log(users)})</pre><p class="wp-block-paragraph"></p><h3 class="wp-block-heading has-medium-font-size"><strong>Updating Data</strong></h3><p class="wp-block-paragraph">To update a record</p><pre class="wp-block-syntaxhighlighter-code">db.collection('users').doc({ id: 1 }).update({  age: 31})</pre><p class="wp-block-paragraph"></p><h3 class="wp-block-heading has-medium-font-size"><strong>Deleting Data</strong></h3><p class="wp-block-paragraph">Delete a specific document</p><pre class="wp-block-syntaxhighlighter-code">db.collection('users').doc({ id: 1 }).delete()</pre><p class="wp-block-paragraph"></p><p class="wp-block-paragraph">Or delete the entire collection</p><p class="wp-block-paragraph"></p><pre class="wp-block-syntaxhighlighter-code">db.collection('users').delete()</pre><p class="wp-block-paragraph"></p><h2 class="wp-block-heading has-large-font-size"><strong>Advanced LocalBase Functionalities</strong></h2><h3 class="wp-block-heading has-medium-font-size"><strong>1. Updating Data in LocalBase</strong></h3><p class="wp-block-paragraph">LocalBase allows updating specific fields in a document without overwriting the entire record.</p><p class="wp-block-paragraph"><strong>Basic Update Example</strong></p><pre class="wp-block-syntaxhighlighter-code">db.collection('users').doc({ id: 1 }).update({  age: 31})</pre><p class="wp-block-paragraph">🔹 This updates <strong>only</strong> the <code>age</code> field while keeping other fields unchanged.</p><p class="wp-block-paragraph"></p><p class="wp-block-paragraph"><strong>Updating Multiple Fields</strong></p><p class="wp-block-paragraph"></p><pre class="wp-block-syntaxhighlighter-code">db.collection('users').doc({ id: 1 }).update({  age: 32,  city: 'New York'})</pre><p class="wp-block-paragraph">🔹 The <code>city</code> field is added, and <code>age</code> is updated.</p><p class="wp-block-paragraph"></p><p class="wp-block-paragraph"><strong>Handling Non-Existing Documents</strong></p><p class="wp-block-paragraph">If the document doesn’t exist, <strong>LocalBase won’t create it automatically</strong>. You can handle this with <code>.get()</code></p><pre class="wp-block-syntaxhighlighter-code">db.collection('users').doc({ id: 2 }).get().then(user =&gt; {  if (user) {    db.collection('users').doc({ id: 2 }).update({ age: 25 })  } else {    db.collection('users').add({ id: 2, name: 'Alice', age: 25 })  }})</pre><p class="wp-block-paragraph"></p><h2 class="wp-block-heading has-large-font-size"><strong>2. Querying and Filtering Data</strong></h2><p class="wp-block-paragraph">You can fetch documents based on conditions.</p><h3 class="wp-block-heading has-medium-font-size"><strong>Get All Documents in a Collection</strong></h3><pre class="wp-block-syntaxhighlighter-code">db.collection('users').get().then(users =&gt; {  console.log(users)})</pre><p class="wp-block-paragraph"></p><h3 class="wp-block-heading has-medium-font-size"><strong>Get a Single Document</strong></h3><pre class="wp-block-syntaxhighlighter-code">db.collection('users').doc({ id: 1 }).get().then(user =&gt; {  console.log(user)})</pre><p class="wp-block-paragraph"></p><h3 class="wp-block-heading has-medium-font-size"><strong>Filter with Conditions</strong></h3><pre class="wp-block-syntaxhighlighter-code">db.collection('users').get().then(users =&gt; {  let filteredUsers = users.filter(user =&gt; user.age &gt; 25)  console.log(filteredUsers)})</pre><p class="wp-block-paragraph"></p><p class="wp-block-paragraph">🔹 Since LocalBase doesn’t support <strong>native where queries</strong>, you need to filter manually.</p><p class="wp-block-paragraph"></p><h2 class="wp-block-heading has-large-font-size"><strong>3. Handling Transactions</strong></h2><p class="wp-block-paragraph">LocalBase handles transactions internally, so you <strong>don’t need to worry about opening and closing them</strong>. However, you should use <code>.then()</code> to ensure operations complete before the next action.</p><p class="wp-block-paragraph"></p><h3 class="wp-block-heading has-medium-font-size"><strong>Example: Sequential Updates</strong></h3><pre class="wp-block-syntaxhighlighter-code">db.collection('users').doc({ id: 1 }).update({ age: 32 }).then(() =&gt; {  return db.collection('users').doc({ id: 1 }).update({ city: 'Los Angeles' })}).then(() =&gt; {  console.log('Update complete')})</pre><p class="wp-block-paragraph">🔹 This ensures that the <strong>age</strong> field is updated before adding the <strong>city</strong> field.</p><p class="wp-block-paragraph"></p><h2 class="wp-block-heading has-large-font-size"><strong>4. Clearing and Deleting Data</strong></h2><p class="wp-block-paragraph"></p><h3 class="wp-block-heading has-medium-font-size"><strong>Deleting a Single Document</strong></h3><pre class="wp-block-syntaxhighlighter-code">db.collection('users').doc({ id: 1 }).delete()</pre><p class="wp-block-paragraph"></p><p class="has-medium-font-size wp-block-paragraph"><strong>Deleting an Entire Collection</strong></p><pre class="wp-block-syntaxhighlighter-code">db.collection('users').delete()</pre><p class="wp-block-paragraph"></p><h3 class="wp-block-heading has-medium-font-size"><strong>Clearing All Data</strong></h3><pre class="wp-block-syntaxhighlighter-code">db.delete()</pre><p class="wp-block-paragraph"></p><p class="wp-block-paragraph">🔹 This removes <strong>everything</strong> from the database!</p><p class="wp-block-paragraph"></p><h2 class="wp-block-heading has-large-font-size"><strong>5. Using LocalBase in Real-World Scenarios</strong></h2><h3 class="wp-block-heading has-medium-font-size"><strong>Offline Caching for a To-Do List</strong></h3><pre class="wp-block-syntaxhighlighter-code">db.collection('tasks').add({ id: 1, title: 'Buy groceries', completed: false })</pre><p class="wp-block-paragraph">Later, when the app is online, you can sync it with a remote database.</p><p class="wp-block-paragraph"></p><h3 class="wp-block-heading has-medium-font-size"><strong>User Preferences Storage</strong></h3><pre class="wp-block-syntaxhighlighter-code">db.collection('settings').doc({ theme: 'dark' }).update({ fontSize: '16px' })</pre><p class="wp-block-paragraph"></p><p class="wp-block-paragraph">🔹 Stores user settings locally, ensuring a smooth UX.</p><p class="wp-block-paragraph"></p><p class="wp-block-paragraph">LocalBase makes IndexedDB <strong>developer-friendly</strong> with</p><p class="wp-block-paragraph"><br/>✅ <strong>Easy updates</strong> without overwriting entire documents<br/>✅ <strong>Simple filtering</strong> with JavaScript functions<br/>✅ <strong>Automatic transaction handling</strong><br/>✅ <strong>Efficient storage for offline-first apps</strong></p><p class="wp-block-paragraph">For more details, check out the official repository:<br/>🔗 <a href="https://github.com/samuk190/localbase">GitHub – LocalBase</a></p><p class="wp-block-paragraph"></p><p class="wp-block-paragraph">Got Inspired from 450dsa.com .</p>
