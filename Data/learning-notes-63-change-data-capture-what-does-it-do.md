<p class="wp-block-paragraph"></p><p class="wp-block-paragraph">Few days back i came across a concept of CDC. Like a notifier of database events. Instead of polling, this enables event to be available in a queue, which can be consumed by many consumers. In this blog, i try to explain the concepts, types in a theoretical manner. </p><p class="wp-block-paragraph"></p><p class="wp-block-paragraph">You run a library. Every day, books are borrowed, returned, or new books are added. What if you wanted to keep a live record of all these activities so you always know the exact state of your library?<br/></p><p class="wp-block-paragraph">This is essentially what Change Data Capture (CDC) does for your databases. It’s a way to track changes (like inserts, updates, or deletions) in your database tables and send them to another system, like a live dashboard or a backup system. (Might be a bad example. Don’t lose hope. Continue …)</p><p class="wp-block-paragraph"></p><p class="wp-block-paragraph">CDC is widely used in modern technology to power, </p><ul class="wp-block-list"><li><strong>Real-Time Analytics:</strong> Live dashboards that show sales, user activity, or system performance.</li><li><strong>Data Synchronization:</strong> Keeping multiple databases or microservices in sync.</li><li><strong>Event-Driven Architectures:</strong> Triggering notifications, workflows, or downstream processes based on database changes.</li><li><strong>Data Pipelines:</strong> Streaming changes to data lakes or warehouses for further processing.</li><li><strong>Backup and Recovery:</strong> Incremental backups by capturing changes instead of full data dumps.</li></ul><p class="wp-block-paragraph">It’s a critical part of tools like Debezium, Kafka, and cloud services such as AWS Database Migration Service (DMS) and Azure Data Factory. CDC enables companies to move towards real-time data-driven decision-making.</p><p class="wp-block-paragraph"></p><p class="wp-block-paragraph"></p><h2 class="wp-block-heading"><strong>What is CDC?</strong></h2><p class="wp-block-paragraph">CDC stands for <strong>Change Data Capture</strong>. It’s a technique that listens to a database and captures every change that happens in it. These changes can then be sent to other systems to, </p><ul class="wp-block-list"><li>Keep data in sync across multiple databases.</li><li>Power real-time analytics dashboards.</li><li>Trigger notifications for certain database events.</li><li>Process data streams in real time.</li></ul><p class="wp-block-paragraph">In short, CDC ensures your data is always up-to-date wherever it’s needed.</p><p class="wp-block-paragraph"></p><p class="wp-block-paragraph"></p><h2 class="wp-block-heading"><strong>Why is CDC Useful?</strong></h2><p class="wp-block-paragraph">Imagine you have an online store. Whenever someone, </p><ul class="wp-block-list"><li>Places an order,</li><li>Updates their shipping address, or</li><li>Cancels an order,<br/></li></ul><p class="wp-block-paragraph">you need these changes to be reflected immediately across,</p><ul class="wp-block-list"><li>The shipping system.</li><li>The inventory system.</li><li>The email notification service.<br/></li></ul><p class="wp-block-paragraph">Instead of having all these <strong>systems query the database</strong> (this is one of main reasons) constantly (which is slow and inefficient), CDC automatically streams these changes to the relevant systems. </p><p class="wp-block-paragraph">This means,</p><ol class="wp-block-list" start="1"><li><strong>Real-Time Updates:</strong> Systems receive changes instantly.</li><li><strong>Improved Performance:</strong> Your database isn’t overloaded with repeated queries.</li><li><strong>Consistency:</strong> All systems stay in sync without manual intervention.</li></ol><p class="wp-block-paragraph"></p><h2 class="wp-block-heading"><strong>How Does CDC Work?</strong></h2><blockquote class="wp-block-quote is-layout-flow wp-block-quote-is-layout-flow"><p class="wp-block-paragraph">Note: I haven’t yet tried all these. But conceptually having a feeling. </p></blockquote><p class="wp-block-paragraph">CDC relies on tracking changes in your database. There are a few ways to do this, <br/></p><h2 class="wp-block-heading">1. <strong>Query-Based CDC</strong></h2><p class="wp-block-paragraph">This method repeatedly checks the database for changes. For example:</p><ul class="wp-block-list"><li>Every 5 minutes, it queries the database: “What changed since my last check?”</li><li>Any new or modified data is identified and processed.</li></ul><p class="wp-block-paragraph"><strong>Drawbacks:</strong> This can miss changes if the timing isn’t right, and it’s not truly real-time (Long Polling). <br/><br/></p><h2 class="wp-block-heading">2. <strong>Log-Based CDC</strong></h2><p class="wp-block-paragraph">Most modern databases (like PostgreSQL or MySQL) keep logs of every operation. Log-based CDC listens to these logs and captures changes as they happen.</p><p class="wp-block-paragraph"><strong>Advantages</strong></p><ul class="wp-block-list"><li>It’s real-time.</li><li>It’s lightweight since it doesn’t query the database directly.<br/><br/></li></ul><h2 class="wp-block-heading">3. <strong>Trigger-Based CDC</strong></h2><p class="wp-block-paragraph">In this method, the database uses triggers to log changes into a separate table. Whenever a change occurs, a trigger writes a record of it.</p><p class="wp-block-paragraph"><strong>Advantages:</strong> Simple to set up. </p><p class="wp-block-paragraph"><strong>Drawbacks:</strong> Can slow down the database if not carefully managed.</p><p class="wp-block-paragraph"></p><p class="wp-block-paragraph"></p><h2 class="wp-block-heading"><strong>Tools That Make CDC Easy</strong></h2><p class="wp-block-paragraph">Several tools simplify CDC implementation. Some popular ones are, </p><ol class="wp-block-list" start="1"><li><strong>Debezium</strong>: Open-source and widely used for log-based CDC with databases like PostgreSQL, MySQL, and MongoDB.</li><li><strong>Striim</strong>: A commercial tool for real-time data integration.</li><li><strong>AWS Database Migration Service (DMS)</strong>: A cloud-based CDC service.</li><li><strong>StreamSets</strong>: Another tool for real-time data movement.</li></ol><p class="wp-block-paragraph">These tools integrate with databases, capture changes, and deliver them to systems like RabbitMQ, Kafka, or cloud storage.<br/><br/></p><p class="wp-block-paragraph">To help visualize CDC, think of, </p><ul class="wp-block-list"><li><strong>Social Media Feeds:</strong> When someone likes or comments on a post, you see the update instantly. This is CDC in action.</li><li><strong>Bank Notifications:</strong> Whenever you make a transaction, your bank app updates instantly. Another example of CDC.</li></ul><p class="wp-block-paragraph"></p><p class="wp-block-paragraph">In upcoming blogs, will include Debezium implementation with CDC.</p>
