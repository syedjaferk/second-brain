<p class="wp-block-paragraph"></p><p class="wp-block-paragraph">I have came across reading Bloom Filters when i wanted to implement <code>username check</code> likewise in instagram. Today i came back to refresh on bloom filters and note it for my future self. </p><p class="wp-block-paragraph"></p><h2 class="wp-block-heading">What is a Bloom Filter ?</h2><p class="wp-block-paragraph">A Bloom filter is a space-efficient, probabilistic data structure designed to test whether an element is part of a set. It can return two types of results</p><ul class="wp-block-list"><li><strong>True:</strong> The element is probably in the set.</li><li><strong>False:</strong> The element is definitely not in the set.</li></ul><p class="wp-block-paragraph">Notably, Bloom filters do not store the actual elements themselves, and there is a chance of false positives, but never false negatives.</p><blockquote class="wp-block-quote is-layout-flow wp-block-quote-is-layout-flow"><p class="wp-block-paragraph">If it says, the given word is not present then we can be 100% sure about it. This is the benefit we are getting out of Bloom Filters. </p></blockquote><p class="wp-block-paragraph"></p><p class="wp-block-paragraph">But setting up a bloom filter is not an easy task. You will soon get to know. </p><p class="wp-block-paragraph"></p><h2 class="wp-block-heading">How Does a Bloom Filter Work?</h2><p class="wp-block-paragraph">A Bloom filter uses a bit array of size and independent hash functions. Here’s how it operates, </p><ol class="wp-block-list" start="1"><li><strong>Adding an Element</strong><ul class="wp-block-list"><li>Compute the hash values for the element for each hash functions.</li><li>Map these hash values to positions in the bit array.</li><li>Set the corresponding bits to 1.</li></ul></li><li><strong>Querying an Element</strong><ul class="wp-block-list"><li>Compute the hash values for the element for each hash functions.</li><li>Check the corresponding bits in the bit array.</li><li>If all bits are 1, the element is probably in the set. If any bit is 0, the element is definitely not in the set.</li></ul></li></ol><p class="wp-block-paragraph"></p><p class="wp-block-paragraph">As you can imagine, when we are continously adding element to array (considering the array size is smaller), then the percentage of false positives will increase. On the other hand choosing the correct numbers of hash functions also matters. </p><h2 class="wp-block-heading"><strong>Setting Parameters</strong></h2><p class="wp-block-paragraph">To effectively use a Bloom filter, it’s important to set the parameters appropriately</p><ol class="wp-block-list"><li><strong>Bit Array Size (<em>m</em>):</strong><ul class="wp-block-list"><li>The size of the bit array determines the capacity and accuracy of the filter.</li><li>A larger <em>m</em> reduces the false positive rate but requires more memory.</li></ul></li><li><strong>Number of Hash Functions (<em>k</em>):</strong><ul class="wp-block-list"><li>The number of hash functions affects the distribution of bits set to 1.</li><li>An optimal <em>k</em> minimizes the false positive rate for a given <em>m</em> and number of elements (<em>n</em>).</li></ul></li><li><strong>Number of Elements (<em>n</em>):</strong><ul class="wp-block-list"><li>Estimate the number of elements to be stored to configure <em>m</em> and <em>k</em> appropriately.</li></ul></li></ol><p class="wp-block-paragraph"></p><h2 class="wp-block-heading">Someone derived a formula</h2><h3 class="wp-block-heading" id="1c2a">Bit Array Size</h3><p class="wp-block-paragraph" id="7c59">The false positive rate represents the probability that a non-existing element is incorrectly identified as present in the Bloom filter.
