<p class="wp-block-paragraph"></p><blockquote class="wp-block-quote is-layout-flow wp-block-quote-is-layout-flow"><p class="wp-block-paragraph">Telegram Group: <a href="https://t.me/parottasalna">https://t.me/parottasalna</a></p><p class="wp-block-paragraph">Github Repo: <a href="https://github.com/syedjaferk/daily_quiz_sender">https://github.com/syedjaferk/daily_quiz_sender</a></p></blockquote><p class="wp-block-paragraph"></p><p class="wp-block-paragraph">In this blog, I’ll walk you through the journey of transitioning from a PythonAnywhere server to GitHub Actions for automating the delivery of daily quizzes to a Telegram group <a href="https://t.me/parottasalna">https://t.me/parottasalna</a> . This implementation highlights the benefits of GitHub Actions to run a cronjob. </p><p class="wp-block-paragraph"></p><h4 class="wp-block-heading">Problem Statement</h4><p class="wp-block-paragraph">I wanted to send a daily quiz to a Telegram group to keep members engaged and learning. Initially, I hosted the solution on a PythonAnywhere server. </p><p class="wp-block-paragraph">Some of the limitations are, </p><ol class="wp-block-list"><li>Only one cron job is allowed for a free account. </li><li>For every x days, i need to visit the dashboard and reactive my account to make it work. </li></ol><p class="wp-block-paragraph">Recently, started learning the <a href="https://parottasalna.com/2024/12/19/learning-notes-01-github-actions/">Github Actions</a> .  So thought of leveraging the <strong>schedule</strong> mechanism in it for my usecase. </p><p class="wp-block-paragraph"></p><h4 class="wp-block-heading">Key Features of My Solution</h4><ul class="wp-block-list"><li><strong>Automated Scheduling</strong>: GitHub Actions triggers the script daily at a specified time.</li><li><strong>Secure Secrets Management</strong>: Sensitive information like Telegram bot tokens and chat IDs are stored securely using GitHub Secrets.</li><li><strong>Serverless Architecture</strong>: No server maintenance; everything runs on GitHub’s infrastructure.</li></ul><p class="wp-block-paragraph"></p><h4 class="wp-block-heading">Implementation Overview</h4><blockquote class="wp-block-quote is-layout-flow wp-block-quote-is-layout-flow"><p class="wp-block-paragraph">I am not explaining the code here. Please checkout the repo <a href="https://github.com/syedjaferk/daily_quiz_sender">https://github.com/syedjaferk/daily_quiz_sender</a></p></blockquote><p class="wp-block-paragraph">The core components of the implementation include</p><ol class="wp-block-list" start="1"><li>A Python script (populate_questions.py) to create questions and store each question in the respective directory. </li><li>A Python script (runner.py) which takes telegram_bot_url, chat_id and category as input to read the correct question from the category directory and send the message. </li><li>A GitHub Actions workflow to automate execution.</li></ol><p class="wp-block-paragraph"></p><h3 class="wp-block-heading">Workflow Yaml File</h3><pre class="wp-block-syntaxhighlighter-code">name: Docker Quiz Senderon:  schedule:    - cron: "30 4 * * *"  workflow_dispatch:jobs:  run-python:    runs-on: ubuntu-latest    steps:      - name: Checkout code        uses: actions/checkout@v3      - name: Set up Python        uses: actions/setup-python@v4        with:          python-version: '3.10'      - name: Install dependencies        run: |          python -m pip install --upgrade pip          if [ -f requirements.txt ]; then pip install -r requirements.txt; fi      - name: Run script with secrets0        run: python runner.py --telegram_url ${{ secrets.TELEGRAM_BOT_URL }} --chat_id ${{ secrets.CHAT_ID }} --category docker</pre><p class="wp-block-paragraph"></p><h3 class="wp-block-heading">Benefits of the New Implementation</h3><ol class="wp-block-list" start="1"><li><strong>Cost-Effectiveness</strong>: No server costs thanks to GitHub’s free tier for public repositories.</li><li><strong>Reliability</strong>: GitHub Actions ensures the script runs on schedule without manual intervention.</li><li><strong>Security</strong>: GitHub Secrets securely manages sensitive credentials.</li><li><strong>Centralization</strong>: All code, configuration, and automation reside in a single repository.</li></ol><h3 class="wp-block-heading">Lessons Learned</h3><ul class="wp-block-list"><li><strong>Environment Variables</strong>: Using environment variables for secrets keeps the code clean and secure.</li><li><strong>Error Handling</strong>: Adding error-handling mechanisms in the script helps debug issues effectively.</li><li><strong>Time Zones</strong>: GitHub Actions uses UTC; be mindful when scheduling tasks for specific time zones.</li></ul><p class="wp-block-paragraph"></p><h3 class="wp-block-heading">Future Enhancements</h3><ol class="wp-block-list" start="1"><li><strong>Dynamic Quizzes</strong>: Automate quiz generation from a database (sqlite3) or external API.</li><li><strong>Logging</strong>: Store logs as GitHub Actions artifacts for better debugging and tracking.</li><li><strong>Failure Notifications</strong>: Notify via Telegram or email if the workflow fails.</li><li>Extend for other categories</li></ol><p class="wp-block-paragraph"></p><p class="wp-block-paragraph">You can check out the project <a href="https://github.com/syedjaferk/daily_quiz_sender">here</a>. Feel free to fork it and adapt it to your needs!</p><p class="wp-block-paragraph"></p>
