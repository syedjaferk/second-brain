<p class="wp-block-paragraph"></p><p class="wp-block-paragraph">Today morning, i started with a video on E-Tags (came as first in youtube suggestion). In this blog i jot down my notes on E-Tags and how it helps in saving bandwidth. Also how Last-Modified header is better than E-Tags. </p><p class="wp-block-paragraph"></p><p class="wp-block-paragraph">In the world of web development, ensuring efficient resource management and improved performance is crucial. Two key mechanisms that help in achieving this are <strong>E-Tags</strong> (Entity Tags) and the <strong>Last-Modified</strong> header. </p><p class="wp-block-paragraph">These HTTP features facilitate caching and conditional requests, reducing bandwidth usage and improving user experience.</p><p class="wp-block-paragraph"></p><h2 class="wp-block-heading"><strong>What is an E-Tag?</strong></h2><p class="wp-block-paragraph">An <strong>Entity Tag (E-Tag)</strong> is an HTTP header used for web cache validation. It acts as a unique identifier for a specific version of a resource on the server. When a resource changes, its E-Tag also changes, enabling clients (e.g., browsers) to determine if their cached version of the resource is still valid.</p><p class="wp-block-paragraph"></p><h2 class="wp-block-heading"><strong>How E-Tags Work</strong></h2><p class="wp-block-paragraph">1. <strong>Response with E-Tag</strong>: When a client requests a resource, the server responds with the resource and an E-Tag in the HTTP header.</p><pre class="wp-block-syntaxhighlighter-code">HTTP/1.1 200 OKETag: "abc123"Content-Type: application/jsonContent-Length: 200</pre><p class="wp-block-paragraph"></p><p class="wp-block-paragraph">2. <strong>Subsequent Requests</strong>: On subsequent requests, the client includes the E-Tag in the <code>If-None-Match</code> header.</p><p class="wp-block-paragraph"></p><pre class="wp-block-syntaxhighlighter-code">GET /resource HTTP/1.1If-None-Match: "abc123"</pre><p class="wp-block-paragraph"></p><p class="wp-block-paragraph">3. <strong>Server Response</strong></p><p class="wp-block-paragraph">If the resource hasn’t changed, the server responds with a <code>304 Not Modified</code> status, saving bandwidth, </p><pre class="wp-block-syntaxhighlighter-code">HTTP/1.1 304 Not Modified</pre><p class="wp-block-paragraph"></p><p class="wp-block-paragraph">If the resource has changed, the server responds with a <code>200 OK</code> status and a new E-Tag, </p><pre class="wp-block-syntaxhighlighter-code">HTTP/1.1 200 OKETag: "xyz789"</pre><p class="wp-block-paragraph"></p><h2 class="wp-block-heading"><strong>Benefits of E-Tags</strong></h2><ul class="wp-block-list"><li>Precise cache validation based on resource version.</li><li>Reduced bandwidth usage as unchanged resources are not re-downloaded.</li><li>Improved user experience with faster loading times for unchanged resources.</li></ul><p class="wp-block-paragraph"></p><h2 class="wp-block-heading"><strong>What is the Last-Modified Header?</strong></h2><p class="wp-block-paragraph">The <strong>Last-Modified</strong> header indicates the last time a resource was modified on the server. It’s a simpler mechanism compared to E-Tags but serves a similar purpose in caching and validation.</p><p class="wp-block-paragraph"></p><h2 class="wp-block-heading"><strong>How Last-Modified Works</strong></h2><p class="wp-block-paragraph">1. <strong>Response with Last-Modified</strong>: When a client requests a resource, the server includes the <code>Last-Modified</code> header in its response,</p><pre class="wp-block-syntaxhighlighter-code">HTTP/1.1 200 OKLast-Modified: Wed, 17 Jan 2025 10:00:00 GMTContent-Type: image/pngContent-Length: 1024</pre><ol class="wp-block-list" start="1"></ol><p class="wp-block-paragraph"></p><p class="wp-block-paragraph">2. <strong>Subsequent Requests</strong>: On future requests, the client includes the <code>If-Modified-Since</code> header. </p><pre class="wp-block-syntaxhighlighter-code">GET /image.png HTTP/1.1If-Modified-Since: Wed, 17 Jan 2025 10:00:00 GMT</pre><p class="wp-block-paragraph"></p><p class="wp-block-paragraph">3. <strong>Server Response</strong></p><p class="wp-block-paragraph">If the resource hasn’t changed, the server responds with a <code>304 Not Modified</code> status, </p><pre class="wp-block-syntaxhighlighter-code">HTTP/1.1 304 Not Modified</pre><p class="wp-block-paragraph">If the resource has changed, the server sends the updated resource with a new <code>Last-Modified</code> value,</p><p class="wp-block-paragraph"></p><pre class="wp-block-syntaxhighlighter-code">HTTP/1.1 200 OKLast-Modified: Thu, 18 Jan 2025 12:00:00 GMT</pre><p class="wp-block-paragraph"></p><p class="wp-block-paragraph"></p><p class="wp-block-paragraph"></p><p class="wp-block-paragraph">E-Tags and Last-Modified headers are powerful tools for improving web application performance. By enabling conditional requests and efficient caching, they reduce server load and bandwidth usage while enhancing the user experience. Remember, these 2 are pretty old mechanisms, which are been used tilldate. </p>
