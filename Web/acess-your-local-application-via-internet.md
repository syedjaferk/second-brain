<p class="wp-block-paragraph">In this blog post, we’ll explore how to set up a simple web server using Caddy to serve an HTML page over HTTPS. </p><p class="wp-block-paragraph">Additionally, we’ll configure port forwarding on your router to make the server accessible from the internet using your WAN IP address. </p><p class="wp-block-paragraph">Caddy is an excellent choice for this task because of its ease of use, automatic HTTPS, and modern web technologies support. </p><h3 class="wp-block-heading">What You’ll Need</h3><ul class="wp-block-list"><li>Your WAN IP address (You can get this from your router)</li><li>A computer or server running Linux, macOS, or Windows</li><li>Caddy or any related web server (nginx, etc…) installed on your machine</li><li>An HTML file to serve.</li><li>Access to your router’s administration interface</li></ul><h3 class="wp-block-heading">Step 1: Install Caddy </h3><h4 class="wp-block-heading">Linux</h4><p class="wp-block-paragraph">To install Caddy on Linux, you can use the following commands:</p><pre class="wp-block-syntaxhighlighter-code"># Download Caddywget https://github.com/caddyserver/caddy/releases/download/v2.6.4/caddy_2.6.4_linux_amd64.tar.gz# Extract the downloaded filetar -xzf caddy_2.6.4_linux_amd64.tar.gz# Move Caddy to a directory in your PATHsudo mv caddy /usr/local/bin/# Give execute permissionssudo chmod +x /usr/local/bin/caddy</pre><h3 class="wp-block-heading">macOS</h3><p class="wp-block-paragraph">On macOS, you can install Caddy using Homebrew,</p><pre class="wp-block-syntaxhighlighter-code">brew install caddy</pre><h3 class="wp-block-heading">Windows</h3><p class="wp-block-paragraph">For Windows, download the Caddy binary from the <a data-proofer-ignore="" href="#">official website</a> and add it to your system PATH.</p><h3 class="wp-block-heading">Step 2: Create an HTML Page</h3><p class="wp-block-paragraph">Create a simple HTML page that you want to serve with Caddy. For example, create a file named <code>index.html</code> with the following content:</p><pre class="wp-block-syntaxhighlighter-code">&lt;!DOCTYPE html&gt;&lt;html lang="en"&gt;&lt;head&gt;    &lt;meta charset="UTF-8"&gt;    &lt;meta name="viewport" content="width=device-width, initial-scale=1.0"&gt;    &lt;title&gt;ParottaSalna&lt;/title&gt;&lt;/head&gt;&lt;body&gt;    &lt;h1&gt;Hello Soldiers !&lt;/h1&gt;    &lt;p&gt;Vanakkam&lt;/p&gt;&lt;/body&gt;&lt;/html&gt;</pre><h3 class="wp-block-heading">Step 3: Configure Caddy</h3><p class="wp-block-paragraph">Create a Caddyfile in the same directory as your <code>index.html</code> file. This file will tell Caddy how to serve your HTML page.</p><p class="wp-block-paragraph">Here’s a simple Caddyfile configuration:</p><pre class="wp-block-syntaxhighlighter-code">:8080 {    root * .    file_server}</pre><p class="wp-block-paragraph">Replace <code>. (current directory)</code> with the path to the directory containing your <code>index.html</code> file.</p><h4 class="wp-block-heading">Explanation</h4><ul class="wp-block-list"><li><code>:8080</code>: This tells Caddy to listen on port 8080 on your local machine.</li><li><code>root * /path/to/your/html</code>: This specifies the directory containing your HTML files.</li><li><code>file_server</code>: This directive enables the file server to serve static files.</li></ul><h3 class="wp-block-heading">Step 4: Run Caddy</h3><p class="wp-block-paragraph">Navigate to the directory where your <code>Caddyfile</code> is located and start Caddy with the following command:</p><pre class="wp-block-syntaxhighlighter-code">caddy run</pre><p class="wp-block-paragraph">Caddy will read the <code>Caddyfile</code> and start serving your HTML page on the specified port (8080 in this example).</p><h3 class="wp-block-heading">Step 5: Access Your Server Locally</h3><p class="wp-block-paragraph">Open a web browser and go to the following URL to view your HTML page:</p><blockquote class="wp-block-quote is-layout-flow wp-block-quote-is-layout-flow"><p class="wp-block-paragraph"><code>https://localhost:8080</code></p></blockquote><figure class="wp-block-image size-large"><img alt="" class="wp-image-863" data-recalc-dims="1" decoding="async" height="342" loading="lazy" src="https://i0.wp.com/parottasalna.com/wp-content/uploads/2024/08/image-10.png?resize=1076%2C342&amp;ssl=1" width="1076"/></figure><h3 class="wp-block-heading">Step 6: Configure Port Forwarding</h3><p class="wp-block-paragraph">To make your server accessible from the internet, you’ll need to set up port forwarding on your router.</p><h4 class="wp-block-heading">Find Your Local IP Address</h4><p class="wp-block-paragraph">First, find your local IP address. You can do this by running:</p><ul class="wp-block-list"><li><strong>Linux/macOS</strong>: <code>ifconfig</code> or <code>ip addr</code></li><li><strong>Windows</strong>: <code>ipconfig</code></li></ul><figure class="wp-block-image size-large"><img alt="" class="wp-image-866" data-recalc-dims="1" decoding="async" height="527" loading="lazy" src="https://i0.wp.com/parottasalna.com/wp-content/uploads/2024/08/image-11.png?resize=1381%2C527&amp;ssl=1" width="1381"/></figure><h4 class="wp-block-heading">Access Your Router’s Admin Interface</h4><ol class="wp-block-list"><li>Open a web browser and enter your router’s IP address (commonly <code>192.168.0.1</code> or <code>192.168.1.1</code>). I am using D-Link Router (<a data-proofer-ignore="" href="http://192.168.0.1">http://192.168.0.1</a>)</li><li>Log in with your router’s admin credentials.</li></ol><h4 class="wp-block-heading">Set Up Port Forwarding (Usual steps)</h4><ol class="wp-block-list"><li>Locate the port forwarding section in your router’s interface.</li><li>Create a new port forwarding rule:<ul class="wp-block-list"><li><strong>Service Name</strong>: Caddy (or any name you prefer)</li><li><strong>External Port</strong>: 80 and 443 (for HTTP and HTTPS)</li><li><strong>Internal Port</strong>: 80 and 443</li><li><strong>Internal IP Address</strong>: Your computer’s local IP address</li><li><strong>Protocol</strong>: TCP</li></ul></li><li>Save the changes.</li></ol><p class="wp-block-paragraph">The above steps are subjected to change based on the router. I am using D-Link 615 router and i followed this <a href="https://www.cfos.de/en/cfos-personal-net/port-forwarding/d-link-dir-615.htm">https://www.cfos.de/en/cfos-personal-net/port-forwarding/d-link-dir-615.htm</a> to enable port forwarding.</p><h3 class="wp-block-heading">Step 7: Access Your Server</h3><p class="wp-block-paragraph">Now, you can access your server from anywhere using WAN IP address (you can find the WAN IP from in your router). Enter the address in your browser to see your HTML page served over HTTPS!</p><p class="wp-block-paragraph"></p><figure class="wp-block-image size-large"><img alt="" class="wp-image-870" data-recalc-dims="1" decoding="async" height="524" loading="lazy" src="https://i0.wp.com/parottasalna.com/wp-content/uploads/2024/08/image-12.png?resize=1569%2C524&amp;ssl=1" width="1569"/></figure><h3 class="wp-block-heading">Step 8: NO-IP dynamic dns.</h3><p class="wp-block-paragraph">You can have a free domain (mostly a subdomain/a random generated domain) from no-ip and assign your ip:port to a domain. </p><p class="wp-block-paragraph">or if you own a domain, you can assign it. I created a subdomain named home.parottasalna.com</p><figure class="wp-block-image size-large"><img alt="" class="wp-image-873" data-recalc-dims="1" decoding="async" height="323" loading="lazy" src="https://i0.wp.com/parottasalna.com/wp-content/uploads/2024/08/image-14.png?resize=1357%2C323&amp;ssl=1" width="1357"/></figure><p class="wp-block-paragraph">and i am able to access my item via <a data-proofer-ignore="" href="http://home.parottasalna.com:8080" rel="nofollow">http://home.parottasalna.com:8080</a> as below, </p><figure class="wp-block-image size-large"><img alt="" class="wp-image-875" data-recalc-dims="1" decoding="async" height="323" loading="lazy" src="https://i0.wp.com/parottasalna.com/wp-content/uploads/2024/08/image-15.png?resize=1357%2C323&amp;ssl=1" width="1357"/></figure><p class="wp-block-paragraph">Here i haven’t specified any reverse proxy. You can try setting them aswell so that you don’t need to specify port in the domain. </p><p class="wp-block-paragraph"></p>
