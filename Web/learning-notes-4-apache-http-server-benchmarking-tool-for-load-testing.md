<p class="wp-block-paragraph"></p><h3 class="wp-block-heading"><strong>How i came across this Apache Bench aka AB tool ?</strong></h3><p class="wp-block-paragraph">When i need to load test to check the rate limiting in my previous blog on <a href="https://parottasalna.com/2024/12/21/learning-notes-3-gatekeeper-design-pattern/">Gatekeeper Cloud Pattern</a>, i was searching a new tool to load test. Usually i prefer <a href="https://parottasalna.com/2024/11/21/locust-ep-5-how-to-use-test_start-and-test_stop-events-in-locust/">Locust</a>, but this time i wanted to search new tool. That’s how i came across <code>ab</code>  . </p><p class="wp-block-paragraph"></p><h3 class="wp-block-heading"><strong>Apache Bench</strong></h3><p class="wp-block-paragraph">Apache Bench (ab) is a simple and powerful command-line tool for performance testing web servers. It helps developers measure the performance of HTTP services by simulating multiple requests and analyzing the results.</p><p class="wp-block-paragraph">In this blog, we’ll cover everything you need to get started, with examples for various use cases which i tried. </p><h3 class="wp-block-heading">0. <strong>Output </strong></h3><pre class="wp-block-syntaxhighlighter-code">Server Software:        Werkzeug/3.1.3Server Hostname:        localhostServer Port:            8090Document Path:          /Document Length:        16 bytesConcurrency Level:      10Time taken for tests:   2.050 secondsComplete requests:      2000Failed requests:        0Total transferred:      378000 bytesHTML transferred:       32000 bytesRequests per second:    975.61 [#/sec] (mean)Time per request:       10.250 [ms] (mean)Time per request:       1.025 [ms] (mean, across all concurrent requests)Transfer rate:          180.07 [Kbytes/sec] receivedConnection Times (ms)              min  mean[+/-sd] median   maxConnect:        0    0   0.0      0       1Processing:     2   10   2.3     10      37Waiting:        2   10   2.2     10      37Total:          3   10   2.3     10      37</pre><p class="wp-block-paragraph"></p><p class="wp-block-paragraph">It gives a detailed output on time taken, data transferred and other stress details. </p><p class="wp-block-paragraph"></p><h3 class="wp-block-heading"><strong>1. Basic Load Testing</strong></h3><p class="wp-block-paragraph">To send 100 requests to a server with 10 concurrent connections</p><pre class="wp-block-syntaxhighlighter-code">ab -n 100 -c 10 http://example.com/</pre><ul class="wp-block-list"><li><code>-n 100</code> :  Total 100 requests.</li><li><code>-c 10</code> :  Concurrent 10 requests at a time.</li><li><code>http://example.com/</code>: The URL to test.</li></ul><p class="wp-block-paragraph"></p><h3 class="wp-block-heading">2. <strong>Testing with POST Requests</strong></h3><p class="wp-block-paragraph">For testing POST requests, we can use the <code>-p</code> option to specify the data file and <code>-T</code> to set the content type.</p><pre class="wp-block-syntaxhighlighter-code">ab -n 50 -c 5 -p post_data.txt -T "application/x-www-form-urlencoded" http://example.com/api</pre><ul class="wp-block-list"><li><code>-p post_data.txt</code> – File containing POST data.</li><li><code>-T "application/x-www-form-urlencoded"</code> – Content type of the request.</li></ul><p class="wp-block-paragraph"></p><h3 class="wp-block-heading">3. <strong>Testing with Custom Headers</strong></h3><p class="wp-block-paragraph">To add custom headers to your request</p><pre class="wp-block-syntaxhighlighter-code">ab -n 100 -c 20 -H "Authorization: Bearer &lt;token&gt;" http://example.com/api</pre><ul class="wp-block-list"><li><code>-H "Authorization: Bearer &lt;token&gt;"</code> –  Adds an Authorization header.</li></ul><p class="wp-block-paragraph"></p><h3 class="wp-block-heading">4. <strong>Benchmarking with Keep-Alive</strong></h3><p class="wp-block-paragraph">By default, ab closes the connection after each request. Use <code>-k</code> to enable keep-alive</p><pre class="wp-block-syntaxhighlighter-code">ab -n 500 -c 50 -k http://example.com/</pre><ul class="wp-block-list"><li><code>-k</code>  Enables HTTP Keep-Alive.</li></ul><p class="wp-block-paragraph"></p><h3 class="wp-block-heading">5. <strong>Outputting Detailed Results</strong></h3><p class="wp-block-paragraph">To write the results to a file for analysis</p><pre class="wp-block-syntaxhighlighter-code">ab -n 200 -c 20 http://example.com/ &gt; results.txt</pre><ul class="wp-block-list"><li><code>&gt; results.txt</code> – Saves the results in a text file.</li></ul><p class="wp-block-paragraph"></p><h3 class="wp-block-heading">6. C<strong>onfiguring Timeout Values</strong></h3><p class="wp-block-paragraph">To set a custom timeout,</p><pre class="wp-block-syntaxhighlighter-code">ab -n 100 -c 10 -s 60 http://example.com/</pre><ul class="wp-block-list"><li><code>-s 60</code>: Sets a 60-second timeout for each request.</li></ul><p class="wp-block-paragraph"></p><p class="wp-block-paragraph">Apache Bench outputs key metrics such as</p><ul class="wp-block-list"><li><strong>Requests per second:</strong> Average number of requests handled.</li><li><strong>Time per request:</strong> Average time per request.</li><li><strong>Transfer rate:</strong> Data transfer rate.</li></ul><p class="wp-block-paragraph"></p>
