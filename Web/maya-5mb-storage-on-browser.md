<p class="wp-block-paragraph">Maya, a developer working on a new website, was frustrated with slow load times caused by using cookies to store user data. One night, she discovered the Web Storage API, specifically Local Storage, which allowed her to store data directly in the browser without needing constant communication with the server.</p><figure class="wp-block-image size-large"><img alt="" class="wp-image-1130" data-recalc-dims="1" decoding="async" height="566" loading="lazy" src="https://i0.wp.com/parottasalna.com/wp-content/uploads/2024/08/image-49.png?resize=536%2C566&amp;ssl=1" width="536"/></figure><p class="wp-block-paragraph">She starts to explore, </p><p class="wp-block-paragraph">The localStorage is property of the window (browser window object) interface allows you to access a storage object for the Document’s origin; the stored data is saved <strong>across browser sessions.</strong></p><ol class="wp-block-list"><li>Data is kept for a longtime in local storage (with no expiration date.). This could be one day, one week, or even one year as per the developer preference ( Data in local storage maintained even if the browser is closed).</li><li>Local storage only stores strings. So, if you intend to store objects, lists or arrays, you must convert them into a string using JSON.stringfy()</li><li>Local storage will be available via the window.localstorage property.</li><li>What’s interesting about them is that the data survives a page refresh (for sessionStorage) and even a full browser restart (for localStorage).</li></ol><p class="wp-block-paragraph">Excited with characteristics, she decides to learn more on the localStorage methods,</p><h4 class="wp-block-heading"><strong>setItem(key, value)</strong></h4><p class="wp-block-paragraph"><strong>Functionality:</strong> </p><ul class="wp-block-list"><li>Add key and value to localStorage. </li><li>setItem returns undefined. </li><li>Every key, value pair stored is converted to a string. So it’s better to convert an object to string using JSON.stringify()</li></ul><p class="wp-block-paragraph"><strong>Examples:</strong></p><ul class="wp-block-list"><li>For a simple key, value strings.</li></ul><pre class="wp-block-syntaxhighlighter-code">// setItem normal stringswindow.localStorage.setItem("name", "maya");</pre><ul class="wp-block-list"><li>Inorder to store objects, we need to convert them to JSON strings using JSON.stringify()</li></ul><pre class="wp-block-syntaxhighlighter-code">// Storing an Object without JSON stringifyconst data = {  "commodity":"apple",  "price":43};window.localStorage.setItem('commodity', data);var result = window.localStorage.getItem('commodity');console.log("Retrived data without jsonified, "+ result);</pre><h4 class="wp-block-heading">getItem(key)</h4><p class="wp-block-paragraph"><strong>Functionality:</strong> This is how you get items from localStorage. If the given key is not present then it will return null.</p><p class="wp-block-paragraph"><strong>Examples</strong><br/>Get a simple key value pair</p><pre class="wp-block-syntaxhighlighter-code">// setItem normal stringswindow.localStorage.setItem("name", "goku");// getItem const name = window.localStorage.getItem("name");console.log("name from localstorage, "+name);</pre><h4 class="wp-block-heading">removeItem(key)</h4><p class="wp-block-paragraph"><strong>Functionality:</strong> Remove an item by key from localStorage. If the given key is not present then it wont do anything.</p><p class="wp-block-paragraph"><strong>Examples:</strong></p><ul class="wp-block-list"><li>After removing the value will be null.</li></ul><pre class="wp-block-syntaxhighlighter-code">// remove item window.localStorage.removeItem("commodity");var result = window.localStorage.getItem('commodity');console.log("Data after removing the key "+ result);</pre><h4 class="wp-block-heading">clear()</h4><p class="wp-block-paragraph"><strong>Functionality:</strong> Clears the entire localStorage<br/><strong>Examples:</strong></p><ul class="wp-block-list"><li>Simple clear of localStorage</li></ul><pre class="wp-block-syntaxhighlighter-code">// clearwindow.localStorage.clear();console.log("length of local storage - after clear " + window.localStorage.length);</pre><h4 class="wp-block-heading">length</h4><p class="wp-block-paragraph"><strong>Functionality:</strong> We can use this like the property access. It returns number of items stored.<br/>**Examples: **</p><pre class="wp-block-syntaxhighlighter-code">//lengthconsole.log("length of local storage " + window.localStorage.length);</pre><h3 class="wp-block-heading">When to use Local Storage</h3><ol class="wp-block-list"><li>Data stored in Local Storage can be easily accessed by third party individuals.</li><li>So its important to know that any sensitive data must not sorted in Local Storage.</li><li>Local Storage can help in storing temporary data before it is pushed to the server.</li><li>Always clear local storage once the operation is completed.</li></ol><h3 class="wp-block-heading">localStorage browser support</h3><p class="wp-block-paragraph">localStorage as a type of web storage is an HTML5 specification. It is supported by major browsers including IE8. To be sure the browser supports localStorage, you can check using the following snippet:</p><pre class="wp-block-syntaxhighlighter-code">if (typeof(Storage) !== "undefined") {    // Code for localStorage    } else {    // No web storage Support.}</pre><p class="wp-block-paragraph">Maya is also curious to know where it gets stored ?</p><h3 class="wp-block-heading">Where the local storage is saved ?</h3><h4 class="wp-block-heading">Windows</h4><ul class="wp-block-list"><li>**Firefox: **C:\Users\\AppData\Roaming\Mozilla\Firefox\Profiles\\webappsstore.sqlite, %APPDATA%\Mozilla\Firefox\Profiles\\webappsstore.sqlite</li><li>**Chrome: **%LocalAppData%\Google\Chrome\User Data\Default\Local Storage\</li></ul><h4 class="wp-block-heading">Linux</h4><ul class="wp-block-list"><li><strong>Firefox:</strong> ~/.mozilla/firefox//webappsstore.sqlite</li><li><strong>Chrome:</strong> ~/.config/google-chrome/Default/Local Storage/</li></ul><h4 class="wp-block-heading">Mac</h4><ul class="wp-block-list"><li><strong>Firefox:</strong> ~/Library/Application Support/Firefox/Profiles//webappsstore.sqlite, ~/Library/Mozilla/Firefox/Profiles//webappsstore.sqlite</li><li><strong>Chrome:</strong> ~/Library/Application Support/Google/Chrome//Local Storage/, ~/Library/Application Support/Google/Chrome/Default/Local Storage/</li></ul><h3 class="wp-block-heading">Simple Hands-On</h3><p class="wp-block-paragraph"><a href="https://syedjafer.github.io/localStrorage/index.html">https://syedjafer.github.io/localStrorage/index.html</a></p><h3 class="wp-block-heading">Limitations:</h3><ol class="wp-block-list"><li>Do not store sensitive user information in localStorage</li><li>It is not a substitute for a server based database as information is only stored on the browser</li><li>localStorage is limited to 5MB across all major browsers</li><li>localStorage is quite insecure as it has no form of data protection and can be accessed by any code on your web page</li><li>localStorage is synchronous, meaning each operation called would only execute one after the other</li></ol><p class="wp-block-paragraph">Now, Maya is able to resolve her quest of making her website faster, with the awareness of limitations
